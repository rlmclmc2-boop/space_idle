# 站体装甲候选：完整态局部连续相位

源码固定于 `feat/planet-single-side-ui@5424683b662a5a47068d4bda84bcf89c469d02d9`，其中站体模型修改为 `b25e8b30`。Godot 4.7.2、2048×768，四设施均 owned / built。原始[采集脚本](capture.gd)、[运行日志](capture.log)、[25 张原图](frames/)与[SHA256SUMS](SHA256SUMS)在此目录；[短片](local-motion.mp4)由原图按 4 fps 编码，25 帧，播放时长 6.25 秒。
