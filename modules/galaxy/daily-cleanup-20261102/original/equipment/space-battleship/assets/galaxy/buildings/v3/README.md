# Historical Galaxy G1 building sprites — v3

Retired from runtime. Current 3D assets and pipeline: [Galaxy GLB](../../v3/README.md).

Thirty static RGBA PNGs for Galaxy colony slots. Generated with the built-in ImageGen tool from the user-provided v3 brief; each upgrade references the preceding approved level. Original generated alpha is preserved. Source images are square, 1254 × 1254 pixels. [Generation manifest](generation_manifest.json) records prompts, reference assets and hashes.

These sources retain their original lossless 2D import settings for reference. Galaxy now uses GLB models; no current renderer consumes this sprite set.
