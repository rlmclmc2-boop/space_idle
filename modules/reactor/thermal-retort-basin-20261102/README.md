# 炼铁炉热内衬与机械腔

运行源见manifest.json/source-closure.json；安装以installation.json为准，整套消费私有GLB、layout、Stage与共用工作/表面shader，不能只换模型。共同宿主/装备/Owner不在替换范围。

三层分段耐火实体、承压口领及导料件形成有厚度的内腔；本版同时将承接盆外壁/耐火底部收束成真实桶体，实体铸肋贴壁、脚鞋落在承托架上，原贯通出口及液面不变。热内衬材质与腔内灯光在既有炼铁局部采样中捕获，真零保留冷材质，实际负载混合热态；没有增加正常三维采样或局部图格。入料起终点与炉腔光锚点从同一构造源导出，物料按安装帧实际移动，保留机壳深度遮挡。

四路/单炼铁各12秒1×实际Session连续片，含真实鼠标轨道/均分/暂停恢复；2/3路仅零/正整页及输入。少态和钱包/开放受控，不是自然解锁。八态图、全时段0.25秒联系图、2/4/8秒原帧、原始日志和驱动同源保存。25fps为录像采样率，不是游戏FPS。

source-closure.json含每源文件blob/SHA及压缩包分块顺序；media-parts.json描述大视频分块。JPEG低于1MiB。性能准确范围见performance.md，作者整页判断见author-review.md。无独审/用户/最终整页通过结论，不合main。
