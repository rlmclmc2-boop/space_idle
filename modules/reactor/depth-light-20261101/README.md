# 原图还原：舱壁进深、实体反射与核心能量

## 实际改动

装甲大面不再是共面三角扇，而是有真实浅拱的连续折面。房间增加独立凹进壁板、返回面、顶凹井、侧部加强件；核心后大块蓝色托板改为延续舱室的分叶后壁及承重座。均由同一GLB编辑源生成，不叠矩形背景盖片。

查实旧surface shader的自定义light函数取代了内建BRDF，使六类材质的粗糙度/金属度不能按内建反射模型响应。本轮移除该函数，使用Godot实际表面反射与一次初始化的冷舱/暖地环境，保留结构阴影、实际法线和六种材质角色。结构仍仅在设备范围变化时采样两份颜色及一份深度，正常工作只混合既有缓存。

核心能量外层增加可见光学密度，汇聚束有独立前后层；中心改为透明约束单元及真实发光边，替代白色实心球。管路端口不变。炉口至承接池的方截面亮带改为连续圆润流体截面，真实法线参与热亮度；不靠水波贴层。四路/单路分配的百分比共用固定轨内右端读数位，滑块和填充同步留出读数净空，100%不再跑到条头。

## 同版媒体与输入范围

four/single的zero/active是完整1440×900实机图，JPEG保持相同尺寸且小于1MiB。两段12秒影片均25fps、300帧、完整解码，真实Session时钟1×；开放/钱包与单炼铁Owner配置受控，不是自然解锁或通关证据。visual-driver沿既有驱动，实际鼠标命中修改后的原生滑杆，Owner接纳50%分配；再恢复零态并以实际均分按钮开始工作。日志含固定百分比锚点、均分结果、原生暂停/恢复及核心相位/反光冻结。没有重跑未改的购级/MAX或扩展状态矩阵。

phases是覆盖完整时段的每0.25秒联系图，2/4/8s是关键原帧。原图并置只供整页比较，不能将局部改善等同成品还原通过。ports.log核同一GLB八个接口和单路变换的元数据位置/轴向，不能代替视觉端接判断。

installation.json/source-closure.json定义原子替换范围，GLB、metadata、Stage、shader和Scene必须同版；不取旧main/公共壳或其他模块。若源码闭包大于Git小文件读取限制，按source-closure.json顺序拼接part，再核archive_sha256后解包。媒体哈希见manifest.json。
