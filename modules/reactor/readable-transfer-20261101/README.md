# 核心汇入至接收端的同版实机候选

生产SHA与媒体哈希见manifest.json；最小源码闭包见installation.json及source-closure.tar.gz。当前为作者候选，待父/既有审核同壳判断；未作为用户确认稿或main验收。

本轮仅处理核心过程与管内接收：去掉泛蓝斑纹，由少量有前后色阶/遮挡的实体汇入；压缩收为纵向紧束，释放为定向伸展能量体；管内亮包更亮且有尾部，按实际累计弧长前进；套筒内接收光面在亮包到达时短回应，继续受真实金属深度遮挡。核心保留低细节持续体积，未让全管常亮。已认可的设备主体、单路居中、台面和原生操作锚点保持。

four/single-zero/active是当前原尺寸整页及同尺寸JPEG；四路是受控开放后的真实Session Owner，单路使用同一Reactor类的受控炼铁参数Owner。两片均1440×900、25fps、12秒300帧，Session时钟正常1×，未做真实解锁/通关测试。原生点击均分、暂停/恢复有当前日志，钱包受控供展示。没有重跑未修改的升级/MAX或扩展测试矩阵。

两片完整解码通过；作者看半秒时间序列和关键原尺寸整页。midpipe约四路片5秒，暂停冻结时可看管腔亮包位置；contact约6.2秒，恢复后亮包到入口。时间仅帮助定位，不能把局部截图/实现代码当整页通过。录像x11grab单条采集警告保留原日志，成片可完整解码，无所查引导遮挡。当前仍是本地旧顶部，整体应接现行公共壳后审全页。

视觉时序为4.8游戏秒一轮：0–43%汇入，43–60%压缩，60–72%向已开放出口释放，72–100%管路输送/接收。首次正载从汇入开始；暂停冻结，未开分支无外部输出包。仅美术阶段，不改变资源结算或设备准入。归一弧长及接收位置由几何导出，不按屏幕猜路径。

性能口径见performance.md；没有目标机通过结论。基准/单路端口位置轴线检查与主入口检查正常，几何检查不替代视觉判断。未合main；内部交接仅Git。
