# 反应堆分面材质／空间收口候选

本目录是当前同源码实机证据，生产SHA、模型及媒体哈希见manifest.json；原生接入闭包见installation.json。只有作者检查，不代表根／独审或用户通过，未合main。

## 本版实际制作

- 连续舰体壁面替代通高立柱/整宽托架，设备各自局部支承；场景投影收敛为较浅、短的结构阴影，保留核心主次。
- 四机装甲有实际内收边、转折面与受光变化；接收座后端与机体相交，管道入口中心/轴向/口径/插入量仍与前候选相同。
- 台壳边缘和厚度减轻；1/2/3路台面与全部原生控件消费同一导出坐标整体上移，单路不再由大梯形通道拉开。
- 核心按汇聚→压缩→释放周期变化，盾面由发射器向外建立曲面，炉内暗腔、入料、熔料床、承接池和出口分别表达；晶体生长和武器蓄能释放保留。工作几何仍以真实源深度遮挡，不重回整图覆盖动画。
