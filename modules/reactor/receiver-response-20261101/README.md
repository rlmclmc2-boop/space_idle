# 接收端与设备回应：当前实机候选

源版本与媒体/模型哈希见manifest.json。当前为作者候选，待父/既有审同壳检查，不代表用户通过或main验收。

本轮保持已成立的主体、单路居中、操作关系、核心汇入/压缩/释放及管内输送。接收座采用真实内嵌观察窗：外壳开窗、玻璃底和发光面共享轴向与曲面，原孔内小光面已替换。亮包到达后窗内沿轴充亮、保持、回落；武器储能段、盾环、炉内热区、晶体根部分别短响应，不以整机通用闪白替代。光面仍受金属深度遮挡，零载/首次到达前不显示接收完成。

four/single-zero/active为当前完整原尺寸页面；four/single-12s.mp4各1440×900、25fps、12秒300帧，完整解码正常。真实Session时钟1×，开放/钱包与单路Reactor Owner参数受控，未测试自然解锁/通关。片内原生均分、暂停/恢复有日志。没有重跑未修改的升级/MAX或扩大测试矩阵。

half-second-phases覆盖两片全12秒；one-arrival约单路6.4秒，one-response约6.9秒，four-response约四路6.6秒，为当前片原尺寸定位帧。可见亮包进套筒后接收窗仍充亮，炉口随后短促增强，再回落。截图只辅助定位，不能替代完整动态判断。作者看两片时间序列和关键原尺寸帧，未宣称逐帧独立审。x11grab单条采集警告保留日志，成片完整可解码，无所查引导遮挡。
