# B01 R12：炉液暗壳与移动热锋同版作者证据

运行资产固定于 `implement/reactor-centered-godot@0bc17ae48107972c88a84069cf5221bf5c1cbb0f`。本版只调整炉液工作 shader：热锋间的熔池表面显著压暗，让受热区自落流附近沿池面向右移动；设备造型、端口、管路、其他工作材质、Owner 和配置均不变。证据来自本地 Godot 4.7.2、1440×900 桌面窗口。

`reactor-r12-controlled-{1,2,3,4}-{zero,active}-1440x900.png` 为受控模块数的八张完整整屏。预览脚本只隔离可见模块并由 Owner 接纳分配，证明对应数量的显隐和工作响应，不证明自然解锁。`reactor-r12-edge-{mixed-zero,low-positive,reopened-low-positive}-1440x900.png` 为盾路归零、1% 低正载和隐藏重开，另存 `all-active` 起点；`edge.log` 记录盾负载 0.01、隐藏前后视觉相位均为 4.8、重开后为 5.35。

`reactor-r12v-final-1x-250frames.mp4` 是四路正载正常 1× 录屏，FFprobe 读得 1440×900、30 fps、250 帧、实际 8.333333 秒。`reactor-r12v-final-phase-{2,3,4,5,9}.png` 与 `whole-{zero,active}` 是同轮整屏观察。脚本与运行日志同包；录屏不能作为目标硬件性能报告。

作者看完录屏 250 帧的十张炉体顺序接触表，并查看原尺寸整屏与零载、正载、混合零和盾低正载画面。R11 的常亮橙面已变成暗壳承接池与移动热区，落流、池面和右缘排液的方向比 R11 更容易沿时间读出；静态某一帧仍不能充分交代全部过程。外伸盾壳的空间体量、四机与核心/舱室的材质统一及整页品质仍需独立审查，**本包不记录 V3 通过**。自然解锁、最终公共组合和目标硬件性能未在本版验收。

`SHA256SUMS` 覆盖本目录除自身外全部文件。归档仅属于 Git archive，不进入制作树或 Library。
