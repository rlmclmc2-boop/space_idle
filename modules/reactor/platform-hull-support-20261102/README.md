# 平台至舱壁承托

运行源和20份私有安装源码见source-closure.json，成套替换路径见installation.json；保留公共宿主、装备、Owner。源码压缩闭包按JSON顺序重组分块并核SHA，JPEG低于1MiB，影片分块如有见media-parts.json。

平台原薄片支架替换为封闭工字截面梁、台底键和舱壁后锚铸座。前端进入现有台底，后端进入铸座，座背接入壁板厚度，螺栓依座面布置。支承属于设备组，隐去该设备时整套隐去；不新增横贯房间的框格/覆盖阴影/面板。端口、设备/控制坐标、核心过程和既有炉盆等保持。

现有1/2/3/4路零/正整页及四路/单炼铁各12秒正常Session录像同版保存；少态与开放/钱包受控，真实Owner受控参数/测试接纳发布器不等自然解锁或跨系统发布。轨道50%、均分/真零及1/4暂停恢复有日志，2/3仅静态/输入，未扩购级/MAX矩阵。

影片完整解码，人工看全时段0.25秒联系图与2/4/8秒原帧，未声称逐帧人工审。实际帧数/时长见video-probe.json，间隔和逐帧时间戳见video-timestamps.json，按原始结果保存不补帧。采集请求25fps不等游戏FPS。

作者判断见author-review.md，性能范围见performance.md。本版无独审/用户/最终整页通过结论，不合main。
