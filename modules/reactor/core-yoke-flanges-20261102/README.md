# 核心侧约束壳与管根分件

运行源/文件blob见source-closure.json，最小成套安装见installation.json；私有GLB/layout/生成器及既有Stage、表面/工作材质一并闭包，公共宿主/装备/Owner不在替换范围。

左右约束件由真正镜像的承力轭和两片厚装甲构成，背返面朝各自外侧，叶片间是露出后轭的检修缝；扣件和沉孔按实体表面落位。原同向背移的前盖及画在其上的缝被替换，不另加遮盖板。核心出口变截面法兰属于原套筒同一闭合网格，孔径/轴线/端点不变，铜色紧固件共享该轴。分件以当前真实灯光/法线/遮蔽参与缓存，不新加发光边/逐帧三维渲染。前版热内衬、炉盆、凝聚端及核心能量过程保持。

八态整页及四路/单炼铁各12秒1×实际Session录像同源；少路数受控组合及测试接纳发布器，不称自然解锁。2/3路只有静态/输入，未扩购级/MAX矩阵。录像25fps为采样率，不是游戏FPS。整片解码/探针、全时段0.25秒联系图、2/4/8秒原帧及驱动日志在同目录。

20份源码压缩闭包的大blob由source-closure.json说明分块顺序/SHA；JPEG低于1MiB，若视频超限见media-parts.json。作者判断见author-review.md，性能范围见performance.md。不宣告独审/用户/整页最终通过，不main。

本版实际录像：四路12秒300帧/25fps，单路12秒298帧/平均24.833fps；采集请求25fps，按原始实际结果保存，不补帧，不作为游戏FPS。
