## 本轮实作

武器采用三个独立电容筒、裸露金属端帽、开口护壳和检修/散热分件；储能与释放使用青白工作光。护盾增加后承力壳、轴承金属圈和检修装甲。炉口改为有外金属边、耐火内衬和深返回的八边开口，保留连续熔流/承接池。凝聚采用分段罩壳、独立玻璃腔、实体六棱晶体和真正位于前面的收集槽/轨道碎晶。核心前约束壳分件/金属接触面同步完善；设备与工作层仍共用同一安装姿态，接口坐标/轴向/口径不变。

静态表面由模型材质名选择六类实际表面角色：涂层装甲、裸合金、深漆、耐火内衬、玻璃、铜件；分别控制宽反射与高光。核心反光位置设于实际能量体前部，照向相邻机件的真实法线；随蓄能、压缩、释放与输送后回落，仅改变既有两份颜色缓存的混合系数，不每帧重采三维场景。暂停/隐藏保持原规则，无新玩法/等待时间。
