# 宽装甲面分件：公共原尺寸作者判断

本轮两GLB、设施材质参数与spine_opaque shader同时进入当前公共壳，十件星球依赖逐blob同源；背景、主体包络、planet_panel业务/UI修复、反应堆cfcc9a35完整闭包及装备保持。原尺寸判断是新增面板在近侧船体上盖/翼片和少数屋面细缝可辨，制造地板的中灰/象牙差异有进入画面；但多数服务舱立面、制造台宽面仍先读成均匀浅块，面板提升很弱，详情展开主体缩小后更难读出。native-surfaces-comparison.jpg保留前后相同原坐标不放大的证据；没有以放大看见细线就判材料层次完成。

整页构图保持：开放泊位、两端服务舱与主吊架可分辨，环球负空间完整，设施/人员/征服不同高度底台下未见新碰顶栏、压台或越导航。主体转动序列连续，固定环境无矩形跳变；近弧电车可辨，远弧/详情展开后弱。这些技术与空间保持不足以替代整页还原判断。

与批准图同球径看，两前设施的壳体、内腔、机械件仍缺中尺度明暗和连续接触阴影，浅装甲/深结构/金属和玻璃的区分没有在整页建立。当前船坞虽开放，泊位/服务舱仍偏方块堆叠；制造作业面与黄梁仍偏平亮，暗井深度不强。应先用实际尺寸的宽反射、暗腔、厚边和光源关系建立层次，再让细接缝辅助；不继续靠提高线密度替代体积。后方建筑小件和金顶受光仍简化，背景是宽蓝云团，原图深黑空间中的细气体丝/远近层次仍缺。当前公共控件没有新增明确缺陷，无需另缩主体、叠框或盖背景来掩盖这些差距。
