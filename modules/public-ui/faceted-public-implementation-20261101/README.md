# 已认可分面方向：公共源首轮实机接入

固定源 `design/clear-zone-host@b28a0be19139298bd666df040be317fa1dcff2bf`。用户对24db2a9c全屏概念方向的选择已落入13与M3；本批是公共源和现有原生界面的实施件。

## 实际变化与最小消费

`faceted-controls.svg` 是可编辑的单一分面涂装图集，提供深青普通键、暖金执行键、冷灰不可用、选中及light/dark板面。BridgeTheme用原生StyleBoxTexture消费该图集，替换旧装备材质裁图、自绘九块循环和主题默认圆角底板。公共顶轨、标题牌、导航、勾选框和步进箭头在原资源位置替换；焦点沿同一切角。没有新增Control节点或覆盖旧控件。main只改公共页面底色/分隔色，ZoneShell改公共色阶与导航字级；Owner、装备操作结构和战斗投影不变。

模块最小新依赖为 `src/ui/bridge_theme.gd` 与 `assets/ui/public_shell/faceted-controls.svg`。原有字体、箭头/单选图标依赖保留；共享壳其余变更路径及接口见 `consumption.json`。模块在原节点用 `apply_operation_button/select`，板面可用 `operation_plate(padding,"dark")` 配合dark数字角色；默认light保留当前装备字底关系。现有装备会设置 `face.state`，本源已保留该实际选择端口。模块组只消费指定公共源，宿主main/ZoneShell由整体组维护。

## 同版实际画面

`public-states/` 14张1440×900原PNG及同尺寸JPEG：设置常态/真实hover/焦点/勾选不可用、资源弹层、顶部按住、执行按住/不可用、SpinBox只读/只读焦点/恢复，以及装备、装备选择弹层、舰船页。驱动为既有公共源取图流程的本轮受影响扩展：部分状态由程序设置，按住使用根窗口鼠标事件，装备选择通过原Button信号打开。只读/不可用状态是本轮受控呈现。

`select-states/` 5张整屏为当前源实际点击倍速展开、键盘高亮/Enter确认、重开Escape；按钮/菜单对齐，确认后原生选值与Owner一致。两次最终运行日志无脚本/资源错误，Godot4.7.2导入与入口check-only退出0。运行发生于本轮工作树，`runtime-source.json`逐件核其内容与固定b28源相同；截图都是该公共源。

作者实际查看14+5张完整画面：普通深青/执行暖金/不可用冷灰角色可辨，白字落深面、主键墨字落暖面，切角焦点和只读箭头随状态变化，资源弹层与装备选择的字底可读。公共轨、导航及战场边界保持现行位置。当前装备机库/战场背景仍为原资产，反应堆/星球成套造型正在原组实施；本包交父级看公共源与受影响界面，后续接同版主体后再判断整屏统一。

本轮曾发现新板面类型缺少装备使用的.state端口，已在公共源修正并重出上述最终画面；旧失败轮未混入本包。PNG/JPEG对应关系见images.json，各文件SHA256见sha256.json。
