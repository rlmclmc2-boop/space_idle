# 当前公共整页与核心过程判断

作者已实际看五张1440×900整页、四路及单路各12秒的全部逐帧总览（各360帧），另看四路37/58/95/155帧及单路42/50/53/56/65帧原尺寸画面。当前共同安装成立，核心汇入/紧束压缩/定向释放及管内移动已能区分，但接收端闭环仍弱，本轮作为继续制作/审核候选，不直接作用户最终确认。

整页构图：四路核心与设备的体积、深浅截面和操作关系保持，单路仍以核心/炼铁组成共同重心。总量/均分在同一组，分配与等级费用两键的锚点保持，五页未见新越台、挤导航、重复公共层或截字。设备运行强色仍在功能区域，公共深青切角语言和舰船硬轮廓没有新增明显冲突。返回装备结构保持。本轮没有修改这些主体和操作来替代过程可读性。

实际过程：四路约3.0–4.5秒和单路约2.1–3.7秒，前侧亮白、后侧深青的少量能量体逐渐靠近中心，前后层次与汇入方向比薄蓝斑纹清楚。四路约0–0.3秒/4.8–5.1秒、单路约0–0.2秒/4.5–4.8秒可读出中心由宽到窄的紧束，随后向出口拉开，形态不再只是同一光球改变透明度。四路约0.8–1.9秒/5.6–6.7秒，亮包从核心侧沿黑色管腔移动，有白头及青尾，路径与外壳可分；不是全管同时常亮。单路短管约0.8–1.4秒也可见一段定向移动。

当前明确不足在末端：四路第37帧（1.2秒）能同时找到移动亮包，第58帧（1.9秒）只剩盾侧接收口附近一小块青光；单路第42帧（1.37秒）的接收座只在宽套筒边缘露出很小亮点，50/53/56帧已回到暗口。整页连续读序容易停在“亮包进套筒消失”，接收响应不够明确；持续炉火/热池和晶体工作又独立运行，无法靠其存在确认这一包已经接收。源码接收相位存在不等于整页可读。

给原反应堆组的下一项应只收口这个末端：保留真实套筒遮挡与既有设备体积，在可见接收座上建立有明确起落、与到达相接的短响应，让玩家从亮包进入口腔自然读到接收成立。可调整现有接收光面的可见轮廓/保持节拍，不要全管常亮或穿透金属外壳，也无需重做当前核心/设备/单路总成和控制台。
