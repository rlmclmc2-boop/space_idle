# 公共菜单承载轮廓修正

固定源 `design/clear-zone-host@9034af81`，最小改动为 `src/ui/bridge_theme.gd`。父级在b28原屏看到倍速菜单外框圆润，与切角按钮/输入槽不同族，本轮针对该承载修正。

实际读取发现菜单内部承载已使用自定义StyleBoxTexture，但背景来自按钮面区域(0,0,256,96)。当前改为共享dark板面(256,96,256,192)，使用其完整切角和内容内距；显式下拉设线性过滤。公共默认Theme与专用OptionButton helper统一调用同一配置，因此舰船等原生继承菜单同样得到共享板面。无新增承载Control或遮盖层。

本版7张1440×900完整原PNG及同尺寸JPEG：设置常态、实际点击展开、键盘高亮、确认回填、重开Escape退出，以及舰船选择实际展开/关闭。作者逐张看完整页面：倍速和舰船菜单的外轮廓为明确切角，边光与相邻输入/按键同族；文字/单选标记在内腔留有净空，菜单在模块内。倍速确认2后原生选值与Owner一致；舰船菜单读取到共享板面，诊断explicit_menu_theme=false证明其来自公共继承主题。

Godot4.7.2当前主入口，日志无脚本/资源错误。states.json记录倍速状态，ship-menu.json记录舰船菜单承载，driver.gd.txt为既有取图流程本轮扩展。截图工作树已与固定源BridgeTheme逐字节核对。模块消费当前BridgeTheme和b28同源图集，路径见consumption.json。当前包交父级看公共菜单轮廓，主体新资产继续由模块原组制作。
