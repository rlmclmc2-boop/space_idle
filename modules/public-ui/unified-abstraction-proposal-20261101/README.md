## 方向与依据

现有整屏的写实舱室/设备、硬轮廓卡通舰船、浅平面控件缺少共同造型与渲染层级。提案选择适度简化的装甲科幻：清楚的大体块、中尺度分件、相近轮廓线强度、三至四层主要明暗，以及宽而受控的材质反射。反应堆降低细密写实金属反光，舰船保留可辨外形而统一分面/边缘处理；控制台同样具有简明实体厚度。共同语言由轮廓、明暗、密度和承托建立，青/金色只承担身份和主辅强调。

以舰船现有可辨的象牙装甲/深色分件为身份锚点，设备、台体和空间建筑一起向同一简化程度靠拢。环境采用冷蓝，顶部柔暖入射与局部能量光解释相邻表面的明暗；金属、保护面与玻璃通过宽窄反射和透射区分。设备轮廓在整页尺寸下先可读，细节集中在工作口/连接/抓手。战场保留当前主体空间，风格统一只涉及已有元素的外观。

## 控制区构图

一个完整台体承载三段：上部为总量读数、比例条与均分；中部四路按身份、滑条、百分比、增益共列；底部将等级/费用与数量短键、升级长键组织成同一事务带。均分从嵌金色凹槽里贴另一套边框，改为总控带自身的操作区。升级键和数量键共基线、等高，整组左右/底部有可见留白；费用和等级不再挤在独立窄井。普通键深青，升级暖金，边框与倒角同族。实施仍使用原生字体、数量循环和Owner读写关系。
