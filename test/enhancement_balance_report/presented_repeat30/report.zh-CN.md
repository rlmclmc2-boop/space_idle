# 正式五发入口：连发30窄比较

## 结论
正式PresentedBattleGame路径也支持保留30B的20%系数。固定前置AA、三目标时，B整波平均TTK为18.99秒，A为22.58秒，缩短15.9%，8个配对种子中6个更快；20秒持续DPS高9.9%。单目标两组的持续DPS和平均TTK仍偏向A。不改任何生产代码、配置或概率，不扩大矩阵。

无前置的三目标结果接近：B持续DPS高2.6%，平均TTK快4.5%，仅4/8配对更快。不能把固定AA的较强结果写成所有组合都稳定获胜。

## 入口与既有结论范围
实际主场景main.tscn→battlefield.gd→PresentedBattleGame。该类克隆玩家数据库后将导弹改为5发、2.4秒间隔、基础伤害×2，并采用0.28秒排队出膛与实际加速/转向/失效弹体。每一弹仍走共享命中和强化路径；5发不是装饰动画。

原基准继承基础BattleGame：所谓“生产导弹”仅是生产基础装备表4发/1秒，没走上述投影。相关原表述现已更正为“基础表导弹”，数值保留但不覆盖正式发射器。原重炮也没走PresentedBattleGame的12倍弹速，启动/飞行/TTK比较不能直接推广正式入口。全部受影响旧行在prior_projection_scope_flags.csv逐行标范围；这与前一补充的出界几何失效列表是不同问题，基础路径本身仍有研究价值。

此前其他节点/武器/联合组合未在本次正式路径重跑，仍保留基础路径局限。单目标和source-ID专用防御的核心机制证据没有因此作废，但它们不是全正式入口通关保证。
