# 解锁跳过与反应炉整数费用
基准 main f578e4a2。用户授权：解锁页直接勾“跳过”，勾选3秒继续；资源不得有小数。
- 解锁页新增复用现有持久化设置的 CheckBox，仅写“跳过”。与操作指南设置同步；默认关闭。读了很久再勾选时重新起算3秒，下一张独立3秒，取消立即停止自动确认。
- 反应炉每级费用在唯一报价函数向上取整：10/13.5/18.225变为10/14/19；显示、可负担、MAX与批量实际扣款共同使用该函数。未改成长指数。未修改玩家已有存档余额；旧版已留下的小数余额不在本次自动迁移。
- 定点验证：跳过12项0失败；反应炉109项0失败，包含100个等级整数、13不足买14、50买两级扣14+19余17。UI文案表检查通过2373条。
