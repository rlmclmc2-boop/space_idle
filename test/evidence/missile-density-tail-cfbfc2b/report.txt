Reproduction
Keep probe.py, dynamic.gd, density.gd, render150.gd, thread_clock.c and draw_clock_wrapper.gd.txt together. Requires Python with tarfile data filter, Git and Godot; for the optional precise CPU clock, Linux plus cc. It extracts tracked scripts/data/dev/assets/addons into a new isolated directory, imports them, isolates userdata and rejects script/parse errors. Use a working GUI display; --godot selects the engine executable.
  python probe.py --repo /path/to/space_idle --ref d3e89f1 --out /tmp/dynamic-base --mode dynamic --thread-clock
  python probe.py --repo /path/to/space_idle --ref cfbfc2b --out /tmp/dynamic-mesh --mode dynamic --thread-clock
On Windows omit --thread-clock. For another repetition choose a new --out. The driver remains game.speed1 / upgrade amount1 with fixed1/60 steps. No MAX/high-speed configuration is used. run_gui.py and xorg.conf capture the exact local Linux invocation for the archived data; these paths are local-run specific. The portable helper's setup and script execution were validated through the equivalent isolated local run; the last CLI extension is syntax-checked, not claimed as an additional measured run.
