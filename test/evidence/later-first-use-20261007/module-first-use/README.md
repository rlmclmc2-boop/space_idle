# 挂载模块首次使用修订

依据：父线程自然首白实机反馈，管理挂载模块显示0/0却允许空应用，随机副本、本轮、重铸等文字无法解释下一步。本提交未启动游戏，父线程继续实机验收。

原句「挂载模块未通过领域校验」改为「未能安装模块，请检查挂载槽和已解锁模块。」；槽位帮助先引导添加槽、勾选模块、应用，不提前讲传说与究极。没有槽、没有解锁模块各有当前原因与下一步；无有效选择禁用应用。尚未满足解锁条件的模块名称隐藏。究极、封存、重铸提醒仅在相应状态出现。

核对既有实现：拆解按品质获得若干次随机模块抽取，每次对现有五种配置等概率独立抽取，不能指定种类。首次获得只解锁0级且没有加成；再次获得同种模块，在当前经验配置下升到1级。文案不展示概率表，不修改抽取、等级、材料或战斗规则。

范围：hyperspace_commands.gd的本地窗口状态、共享文案及合同、异空间无人机改造指南。保留既有模块选项对象数量，仅隐藏不可用名称；领域校验仍由既有attach_hangings执行。逐键文案前后对照见ui-text-key-diff.json。

验证：仅静态文案合同核对与git diff --check；未新增或运行测试，未另开实机。960×600布局、勾选后按钮变化和首次解锁实际体验待父线程验收。
