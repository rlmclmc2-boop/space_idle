# 跨页奖励入口与中断恢复

触发来自父实际Gamma5：完成后仍停在装备页，后续新机只有异空间内部回执，导航没有提示。本提交复用既有异空间导航按钮和ActivationBadge红点，未读时显示“新无人机”或“新奖励”；点击打开回执。后台进度和隐藏页不清未读，不抢页签，不重复首机弹窗。看见实际回执或该无人机详情后解除；原容量阻塞／待领取红点仍独立有效。

可恢复UI状态仅新增顶层hyperspaceReceipt四字段：round、run、drone_id、unread。与当前已结算round/run匹配时才恢复未读；按ID从既有库存读取无人机，不生成或重发奖励。普通保存／加载通过既有portable_save_data和load_progress_data，标记改变时调用现有save_progress保存。真实导出／导入还经过save_transfer.schema/clean/prepare与导入事务；52b4122遗漏该schema，父审查发现后补齐，见transfer-fix.md。旧档缺字段、无效标记安静兼容；没有改SAVE_VERSION、异空间结算协议、费用、RNG或库存。

重开恢复只显示库存可核查的新机及一般回执，不伪造或重复显示上次材料增加数。初始空档不冒充材料已领取。旧档没有足够信息判断历史奖励是否已看过，因此不补提醒已经存在的旧无人机。
