# 太空战舰前三关独立玩家评测

**评测对象**：`def6185e02784e91a6c84a4e6f87382be2a691e1`，远端 `origin/main` 当时回读同值；独立分支 `review/first-three-def6185e`。评分前未阅读其他评测结论、制作结论或战点实现。没有改生产代码、资源、时钟、速度或关卡进度。

**实玩口径**：Godot 4.6.3 原生窗口，Xorg dummy 显示、Mesa OpenGL 4.5 llvmpipe；工程要求的 Windows 4.7.2 引擎在本 Linux 云机上不可用。这是实际渲染和点击路径，不是逻辑模拟。两个隔离用户数据目录各从新档以默认 1 倍速经可见 UI 玩到第四关 1/5：第一次约 20:41:40–20:47:02 UTC，第二次约 20:47:50–20:53:12 UTC；另用第三个新档短看首关前段。[第 4 关到达画面](screenshots/12-stage4-arrival.png)只用于证明截止位置，不参与评分。实际帧率顶部显示约 29–39 FPS，声音因云机无 ALSA 设备降级到 dummy，音效不评分。所有存档、缓存和启动工具均留在 `/tmp`，不提交。截图为未经修饰的原生窗口截屏。

**玩法与卡点**：首次在 1-4 撤退一次；免费装上第二脉冲激光、第三追踪导弹和第二装甲槽，再将 W01 升至 2 级，通过 1-5。第二关 3/6 时曾只剩 41/2000 生命，5/6 再次撤退，升级 W02、W03 与 D01 后通过混合精英 6/6。第三关在 5/7 后换装偏转护盾和磁轨火炮；换盾立即把最大生命从 2200 降至 1200，7/7 曾剩 27/1200 后撤退，火炮升级到 3 级后通过，通关一刻为 18/1200 生命、护盾 500/500。第二档在第 1 关较早补满防御槽，可无撤退通过；第 2、3 关仍有撤退。上述是 UI 直接观察；“提前补槽导致无撤退”只是两次体验的合理推断，未作控制变量实验。

## 最多三项关键问题与下一批方向

1. **教学/阅读与自动推进冲突（高）**：打开教程、装备详情、解锁说明时战斗继续，首次边读边配期间在 1-4 撤退，第二档在详情中从 3-3 推到 3-5。下一批让首次教学和解锁说明停在安全间隙，玩家明确关闭或完成动作后再推进；至少保留当前波的结果与下一波准备时间。
2. **战点重复和战中无选择（高）**：2-2/2-3 是多排同型小机，3-2/3-4 等装甲机形态相近；真正的选择几乎只发生在解锁与撤退后。下一批在前 18 点加入少量有清楚预兆的目标优先、护盾破除或临时防御决策，并把这些机制分散引入每关，而非主要靠多刷同类敌人。
3. **战斗读数与画面分配（中高）**：狭窄战场使密集敌群、弹体、伤害字叠在一起，右侧大面板占比过高。下一批优先扩大交战视野，给受击来源、敌方护盾/生命、我方武器命中分别建立稳定且不重叠的视觉层级；把 `FPS` 从玩家常驻顶栏移到调试信息。

**边界**：没有读取游戏实现找通关答案；战点成因、数值平衡与版本间表现不作代码推断。首波及 3-3 的敌阵只有限覆盖；音效和第四关之后完全不评价。引擎版本与软件渲染可能影响性能和字体观感，但不改变上文可见交互事实。
