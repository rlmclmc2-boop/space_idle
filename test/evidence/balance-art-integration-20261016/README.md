同机串行、相同 Godot/DLL/驱动脚本、固定随机种子、15 敌压力布置、真实主场景与 UI、原生 rich15、保留敌机显示、统计缓存开启、无存档。每侧 240 逻辑步预热，再采 240 步约 4 秒；速度 1×、目标上限 60 FPS、VSync=0；采样首尾有焦点，逐帧 unfocused=0；战斗事件一致（797 次开火、4527 次受击）、handoffs=0。原始每帧数据及全部配置在 `balance-art-{before,after}-full-frame.json`。

## 交接结论

目前证据支持美术在上述开局战点通过原生通路显示，短时实例复用正确，且这次同条件完整场景采样未见逻辑节奏或帧墙时恶化。样本不足以替代长时试玩、跨硬件性能验收，亦不能证明强化高等级及 18 关经济已平衡。父在放行前需重读其专用 `PROJECT_CONSTRAINTS.md`。
