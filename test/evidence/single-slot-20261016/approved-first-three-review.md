## 验收限制

本执行环境的桌面控制接口对已启动的隔离游戏窗口仍返回空应用列表，无法进行真实鼠标点击式的 18 点 UI 试玩。已完成无存档的原生连续逻辑路线和正式 UI 场景截图；父审后仍需在可操作的桌面窗口完成一次人工式 UI 单槽成长试玩，重点核对换装、升级、拾取时点与失败恢复的交互。
