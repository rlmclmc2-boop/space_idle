# Current visual motion and main startup

Source `wip/planet-thread-resume-20261101@ece6e462`, Godot 4.7.2 OpenGL3, Mesa llvmpipe. `planet-resume-motion.mp4` is a 4-second accelerated author capture of a fully owned type-1 planet through 32 sampled runtime visual advances (2.0 seconds each), encoded at 8 fps. It shows rotation and depth masking but is not natural construction or final art acceptance. The facilities still look box-like from some phases.

The main game also started after a local-only Linux native extension rebuild with dynamic libstdc++/libgcc linking. `planet-main-window4.png` shows the initial equipment screen. This does not verify the planet page, which is not exposed in the initial campaign state. No production source or gameplay state was changed for this check.
