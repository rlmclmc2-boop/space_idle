持续分支：`impl/domain-architecture-20261022`。唯一实现线程；父级 dot 与现有方案线程独立对照审计；双方审同一候选并完成真实产品验收后才可合 main。本线程不合 main。

## 契约

- Game 只编排命令、外部时间与活动会话。经济独占余额；装备、科研、船员、反应炉、星球、星系持有各自状态，退出共享 profile 任意写入。
- 跨域业务先准备，全部提交后通知。报价与扣费同源；随机结果与成本、奖励与领取事实一起提交。使用具体业务边界，不建立通用事务框架。
- 属性组合、取整和生效时点唯一。成长只提供贡献；缓存随实际输入版本变更。外部时间只有一个入口，保留领域固定步算法；暂停、倍速、失焦语义明确，UI 可见性不影响业务。
- 优先复用 native 常驻热路径、出生配置、批处理、GPU 绘制；明确缺失能力和数值范围，替代前保留必要保护，最终不保留双重状态权威。
- 异空间在完整逻辑结算点清空原战场；普通关返回原关起点，驻守按原选择重新开局，防御与冷却按正常新开局。保留长期成长、已结算收益和待领奖励，放弃未完成关内推进；清场不算击杀/通关/奖励。不引入费用、冷却或耐久限制。删除半场 actor 图、快照、return_state/battle_json/loaded_return 及仅为恢复所做 native→legacy 转换；只留返回目标与挑战凭据。
- 保存随领域迁移，读取完整提交快照；验证成功后才安装；保留文件写入、备份恢复、单写入者保护；退出构造完整 Game 做验证。无需旧档兼容，当前格式必须保存恢复正确。
- 资源允许有限精度，不恢复千位精确扣费；不把近似无条件扩展到材料整数。保留有效美术、配置与独立算法；未知玩法改变先交证据和损益。
