## Scope and provenance

All new code/data is under `stages/S12/p1_proto/`; no game script, native DLL, personal save or main branch was edited. The standalone Godot project uses a typed `CurrencyValue` for an experimental resource-only balanced base-10000 ledger, a separate price probe, a finite research-order probe and a read-only MAX query. Its resource encoding `{v:4,blocks:[[position,digit],...]}` is **experimental**, not a save-format approval. `reference_integer.gd` is an exact Git-byte copy of main blob `45b806e2d9fa914a906fd5bbebd3847114e73a5e` for S11 decimal-factor reference. The Python `ledger.py` is an independent arbitrary-exponent mathematical experiment, not a game implementation or fixed-platform performance substitute. `run_probe.py` launches headless Godot with a per-run isolated `APPDATA`/`LOCALAPPDATA` under ignored `.runtime`; it captures raw output, exit code, SHA-256, process-family RSS sampling and host metadata. Native DLL is N/A.

Host from runner metadata: Windows 10 build 19044, Intel Core i7-10700K (8 physical/16 logical), 34,272,337,920 bytes RAM; Godot `4.7.2.stable.official.ed1daf0bf`, console executable SHA-256 `c8f0a6bc45a19b33541501e57f6f7cd972ab18453743266339d495cbbe846643`. Every run used `--headless --path <p1_proto> --script <probe>`; exact commands, cwd and isolation paths are in each `.meta.json`. The sandbox denied WMI/CIM read of CPU/OS data; registry and Python `platform`/`psutil` supplied the recorded facts. Godot printed a root-certificate-store error under isolation on each run; exit 0 probes still completed. MAX harness also reports leaked test-only SceneTree objects at shutdown. Neither warning is hidden or treated as a product result.
