## 1. 确定性的切换规则：MAX-APPROX-v1

本版本每槽 MAX 的精确前缀为256次升级：只需沿现有逐级规则检验最多257次升级的资源和材料。如果第257次不能支付，返回原规则精确 MAX（0..256）；能够支付才进入极端候选路径。256是模式切换工作量，不是等级/购买数量上限；高起始等级的小跨度仍可精确。时间预算只能暂停/取消计算，不能改变模式、取整或价格。零费用、材料限制按原规则处理，不用除零求数量。

极端候选通过固定顺序的指数括界/二分或等价确定性搜索，选择保守安全数量；候选总费用采用下述单调上界 U(n)。不得用随机采样、机器速度、超时截断决定扣费。区间精度升级顺序固定，达到本规则误差要求的首次结果即为报价，不能随帧剩余时间选择精度。同一输入、配置及规则版本得到相同数量和费用。

若极端上界对257次暂不可支付，保留已准确证明可支付的256次作为保守批量，标明“约可购买256级，费用按准确报价”；不得返回0或不足额。它不证明原最大数量等于256。不得为了多买几级恢复全等级逐级累计。

## 2. 费用规则和可检验偏差

对所选连续 n 次升级，C(n) 是按既有单级规则取整后相加的准确资源费用，M(n) 是原材料累计。计算向外舍入的 L(n) <= C(n) <= U(n)，L非负、U为整数；**仅极端 MAX 按 U(n) 报价并实际扣费**，不另算一个隐藏提交价。

收费偏差上限冻结为：C=0 时 U=0；否则要求 `U <= ceil(28*L/25)`。由此 `C <= U <= ceil(1.12*C)`，即至多12%加整数取整尾差，禁止任意多扣。实际应尽量缩紧区间；12%是保守最大界，不是固定加价12%。L/U重合时直接收准确费用。此12%为本版可检查工程规格，不伪称用户逐字指定。收费界按同一 n 核验，与保守数量偏差分开，旧数量1/10提案不设为默认目标或新全域门槛。

建议最小算法：对未取整几何和使用定向上下界，再按旧价格分支的舍入包络求和；低金额/零/有限float兼容段单独处理，不能把理想实数几何和冒充旧float报价。数学两位有效数字高额分支的单级舍入相对误差至多约5%，正项求和可直接传播包络，上下界比约1.05/0.95≈1.1053，为12%留出计算界余量。这个说明是路线，不是对全部finite分支的自动证明：必须把旧float运算误差及ceil纳入证书；区间不足时提高精度或分段，不能无证明套用5%。不要求枚举所有等级，不以逐级精确最终验证作为提交前提。

U(n)必须为单调费用包络，材料M(n)仍按旧解锁和阶段公式准确累计，可用等价闭式。仅当 U(n)<=当前资源且 M(n)<=当前材料时可提交；不越过材料int64域，不把余额夹零或用float实际扣款。搜索要找到该保守费用规则下的支付边界，不能任意返回一个很小数量冒充完成。若当前合法配置尚不能生成满足费用界的结果，明确报告该配置未支持，不擅自放宽误差或恢复无界遍历；交回本阶段处理，不追加全域研究门槛。

## 3. 报价、提交、退款和显示

报价固定 `{rule_version, mode, start_level, count, resource_debit=U, material_debit=M, bound_certificate, dependency_snapshot}`。余额、材料、等级、配置、解锁、profile身份/代次变化使其失效；提交重验同一对象、精确减去已展示费用后一次写入，禁止重新报价却沿用旧预览。计算pending/取消/失效不改live。单槽交易原子，多槽按原顺序允许逐槽部分成功，整批退款原子性保持。

退款继续原等级规则，不返还极端上界溢价；不为此新增逐笔溢价存档或退款账本。用户已接受差额。UI明确“极端 MAX：约可购买 N 级；本次扣费 X；材料 Y；总费用为保守估算，至多高于逐级费用12%（另有整数取整尾差）；退款按原等级规则，可能有差额”。展示数值若格式化省略尾数，内部报价仍是同一准确U，必要时可查看完整值。

256/257切换按固定工作量决定，同输入跨机器结果一致；切换不重定价旧等级，不累积额外存档状态。近似模式可以少买，不得透支；边界费用差受上述界约束，不能承诺数量完全连续。未完成、失效、不可支付必须区分，不以pending冒充0。
