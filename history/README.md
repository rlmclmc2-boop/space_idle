# R17 historical local verification files

This branch preserves the 100 tracked files under the former R17 local candidate directories, as they stood at source `48bd506b`. They are earlier station, refinery, ring-end, four-node and simulated-motion observations; their READMEs state the original scope. No current runtime or approved concept asset is included in this migration. `r17-local-files.sha256` records each complete relative path and source content SHA256. The current production entry remains in its original location.
