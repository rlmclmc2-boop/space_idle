# 星球建筑与环整体概念稿

这是独立的完整建筑设计可视稿，不引用 `facilities_v5/v6` 的网格。先确立共同承力截面、四个设施的体量与功能空间，再考虑落入 Godot 的资产和动画枢轴。用户认可的整屏分面装甲概念见 `archive/design-docs-before-cleanup-20261031@24db2a9c:modules/public-ui/unified-abstraction-proposal-20261101/`。

共同结构是暗蓝承压环脊、两侧暖象牙装甲轨和中部机械槽。四设施的装甲根部直接跨接这三层；青色只表示服务与能源，金色只表示热工和作业。空间站是环形控制枢，冶炼厂是双料斗向中央压力炉输送的热工堡垒，工坊是敞口双门架下的制造台，船坞是有门架与中央发射脊的敞开泊位。四种用途在完整画面宽度下应靠主轮廓和工作空间区分。

`build_concept.py` 以 Blender 4.3.2 和已有星球表面贴图生成独立场景与 1600×900 主构图，不消费图像生成额度。概念图不是当前游戏实机资产或美术验收结果。
