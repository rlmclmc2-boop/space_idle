# 星球建筑与环整体概念稿

这是独立的建筑整体概念草案，不引用 `facilities_v5/v6` 的网格。先确立共同承力截面、四个设施的体量与功能空间，再考虑落入 Godot 的资产和动画枢轴。用户认可的整屏分面装甲概念见 `archive/design-docs-before-cleanup-20261031@24db2a9c:modules/public-ui/unified-abstraction-proposal-20261101/`。

共同结构是暗蓝承压环脊、两侧暖象牙装甲轨和中部机械槽。四设施的装甲根部直接跨接这三层；青色只表示服务与能源，金色只表示热工和作业。空间站是环形控制枢，冶炼厂是双料斗向中央压力炉输送的热工堡垒，工坊是敞口双门架下的制造台，船坞是有门架与中央发射脊的敞开泊位。四种用途在完整画面宽度下应靠主轮廓和工作空间区分。

`build_concept.py` 以 Blender 4.3.2 和已有星球表面贴图生成独立场景与 1600×900 主构图，不消费图像生成额度。`concept-complete.png` / `.jpg` 是同版可评价构图：左上空间站、右上热工、左下船坞、右下工坊。可见四处扩口装甲跨入同一承力环，热工有封闭炉、料斗与出料槽；船坞有敞开泊位和船；工坊有压制外壳、天窗与制造槽。材质细节和实机比例尚需继续制作，此概念图不是实机美术验收。

`export_runtime.py` 从本目录的 `concept.blend` 直接导出 `assets/planets/facilities_v8/` 四件新 GLB，不读取 v5/v6 的建筑网格。四设施保留运行端所需的运动枢轴名称，Godot 环脊的上表面同步改为深色机械通道和两侧窄装甲承力面。概念的四分之一节点位置仅用于整体构图，运行端仍由已有轨道角度、独立建造段和球后遮挡控制。
