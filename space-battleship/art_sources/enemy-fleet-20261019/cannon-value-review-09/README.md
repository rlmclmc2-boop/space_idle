## 明度改动

中央凸起炮机顶面由近黑连续面提升为清楚的中亮钢灰大面；白色侧甲保持更亮，形成两级亮面。较暗部用于机体侧面、连接缝和炮口。没有增加中心小矩形、多重套框或细亮边，仍通过宽面/侧面体现高低，未用白顶盖覆盖炮机。

相同源图区域RGB中值：炮机顶面由08的45/49/60提升至09的147/157/174；白色侧甲为244/248/253，连接缝约3/3/4。以上是源图取样，不代替正常窗口视觉判断。正常窗口八舰/转向自查时，钢灰主体与更亮侧甲能够分别读到，暗侧面和连接层次保留；最终外观待父审/用户确认。
