# Equipment icons

`cartoon_armour.svg` and `cartoon_shield.svg` are original repository-native vectors for the equipment panel. They reuse the navy outline, cream panels and cyan accents of the existing `cartoon_*` weapon icons. Armour uses stacked plates; shield uses a shield enclosure and emitter. Source canvas: 128×128; shared card display box: 64×64. `equipment_tab.gd:icon_for` also uses them in the selected-module inspector. No external artwork, font, or license dependency was added. The original `armour.svg` and `shield.svg` remain available to other consumers.
