# Shell icons

Original repository-native SVG silhouettes for `shell_presentation.gd`. Navy outlines, cream pads and teal fills match the approved equipment cards. System icons use a 64×64 canvas displayed at 28×28 logical pixels. They are presentation-only and do not encode unlock state. No external asset or license dependency.

Resource icons use the same 64×64 source canvas, displayed at 27×27 logical pixels in `resource_strip_presentation.gd`: iron ingots and a uranium cell. Names come from existing localized resource bindings; these icons never replace the full readable resource caption.
