# 当前分件反应炉资产

制作、坐标和交付关系见 `docs/game-design/art/modules/reactor-asset-contract.md`。实际安装保持808×835内容口，使用同源端口、安装帧和路径，不依赖整张概念图裁切。

`generate_faceted_reactor.py`由本地Blender生成独立机体/核心/房间/机台、压力管路和真实工作Mesh，写出GLB及layout。命令：`blender -b -t 4 --python assets/ui/reactor/b01/generate_faceted_reactor.py -- --export-glb`。分件倒角和法线在合并固定结构前解析。

`generate_plasma_atlas.py`用本地NumPy/Pillow作确定性三维发射/吸收积分，输出32个原始体积帧到`/tmp/reactor-plasma-clean`；`pack_plasma_atlas.py`只打包完整且配方哈希一致的32帧，写入`plasma-volume.png/json`。依次运行两脚本即可重建。它只含独立等离子体，不含机壳/文字/管道；运行时在原等离子体网格上以发光材质采样邻帧，不做实时体积步进，也不新增覆盖控件。软件无生成次数配额，不调用云端收费接口。

工作Shader共用`faceted-work-common.gdshaderinc`；普通工作面使用混合材质，等离子体使用发光材质。几何源深度负责真实机壳遮挡，安装帧负责热区/生长/输送坐标。所有原生文字、费用、滑杆与按钮由Scene保留。

结构受光由真实核心、盾场、炉池和凝聚腔点光参与缓存，入射位置与设备使用同源安装变换。源几何按像素单位制作，点光衰减能量按该尺度标定；分配仅混合独立灯光差值，不随拖动重采样三维场景；局部图集按已开放灯源数量打包。凝聚端的聚焦、种子和辐照锚点与对应GLB标记随layout交付，生长、聚焦孔和收集开口都来自本生成器。

固定结构以本地BVH射线烘焙逐刚性分件的自身凹隙遮蔽，导出COLOR_0供表面材质使用；不包含别的数量预制件或运动工作Mesh，跨分件投影仍由当前组合灯光决定。地面板与设备脚座共用deck_level，单路不再移动另一块共面背景地板。

炉口由承压口领与三层分段实体耐火砖构成，内壁保留真实深度和接缝。固定COLOR_0.R仍为自身遮蔽；炼铁分件G记录制作空间受热场，仅热内衬材质消费。热色和腔内入射在既有炼铁局部光采样中一并捕获，随后复位，不增加常态三维重采样或局部图格。work_paths.smelting导出入料起终点和腔内照明锚点；入料网格在同一安装帧中沿实际路径移动，保留源深度遮挡。

承接炉盆的外铸壁与耐火底部沿同一盆沿向下收束成桶体；外肋和脚鞋为实体，出口缺口贯通桶壁，液面/出液起终点不随装饰分件移动。

核心侧约束件使用左右同源但方向相反的承力轭、厚装甲叶片、真实开放检修接缝和嵌入式紧固件；不再用同一背移方向的前平板。核心出口套筒在原孔径/轴线上形成一体变截面法兰，螺栓按同一端口轴安装；各数量态仅保留实际开放支路。所有受光仍由现有静态/局部灯光缓存承担。

上层平台由底部承力键、具有封闭工字截面的斜梁和后锚铸座接至舱壁；替换原薄三角片支架。锚座背面与壁板相交，前端键进入现有台底，螺栓落在座面，不另画接触阴影。该支承与设备同组，隐藏该设备时整套隐藏；设备/端口/控制坐标保持。

舱顶灯具为封闭变截面壳、内凹口缘/灯片和真实承挂杆。room_luminaires把GLB的口/灯片/出光点标记及照明参数同源导出；Stage消费固定bay源坐标，不随设备移位；灯头、玻璃、承挂端及出光轴共用0.30弧度倾角。出光点沿口法线前置12源单位，使用原有两盏灯/缓存，灯片为常亮发光材质，不新增工作特效层或常态三维采样。

玻璃为原节点替换：武器/凝聚采用有内外界面与封边的半筒网格，核心加深外表面并按薄壳厚度处理。glass_materials提供镀膜反射率/厚度/吸收；顶点阶段读取现有天空、主光和两房间灯，片元沿原深度合成透射，非屏幕折射/光线追踪，不新增屏幕拷贝或叠层。静态玻璃保留在零载，不写无用phase/formation/load/powered_at，实际工作体独立运行。
