The shader checks those masks and the accepted module loads before evaluating each conduit waveform or machine signature. A fixed-phase, full reactor-area pixel comparison before the edge treatment was identical, so the optimization leaves the work effect itself intact. The shader's final color now also tapers its left and right 24px to the shared navy edge, including the console ends; it does not place a new layer over the host.
