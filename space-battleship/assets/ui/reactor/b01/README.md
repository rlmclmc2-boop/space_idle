# B01 current reactor assets

Current implementation: `src/ui/reactor_scene.gd` + `src/ui/reactor_stage.gd` on `implement/reactor-centered-godot`. The active delivery/status is [the B01 entry](../../../../docs/verification/reactor-centered-godot/evidence/b01-redesign/README.md); independent visual review remains open. Earlier whole-plate shader and ImageGen variants remain historical assets and do not define the running composition.

The running stage uses separate `modular-bay-background.png`, `modular-core.png`, four `modular-{weapons,defence,smelting,condensation}.png` device surfaces, eight tightly cropped physical pipe shell/front layers, twelve paired rear/front gimbal frames, and two side clamp sprites. `modular-core-unbanded-source.png` is the isolated transparent core source, edited from the original core to remove the baked cross-sphere belt; the former sheet is retained as `modular-core-source.png`. The paired Blender gimbal renders bracket that globe from behind and in front, while the actuating clamps sit on its outer sockets. The clamps use the same machined silver face, recessed guide and brass contact language as the moving hoop; they can be rendered alone with `-- --only-clamps`, then cropped to `190×75+395+285` and `190×75+603+285`. The full assembly script requires all Blender layers freshly rendered on source canvases. `reactor_pipe_view.gd` builds a separate arc-length lumen mesh on each route; `modular-pipe-lumen.gdshader` moves light packets from core socket to device socket. `modular-core-field.gdshader` generates constrained core events within the sphere, and each `reactor_module_view.gd` owns its local work effect. Accepted Owner load gates these effects; zero, pause, hidden and restart use the stage clock. No text, values, buttons, slider hit areas or economic logic are baked into these images.

The four `modular-*-lit-source.png` files preserve the original device renders. `python assets/ui/reactor/b01/split_work_surfaces.py` derives each neutral mechanical `modular-*.png` and tightly cropped transparent `modular-*-work.png`. It selects emissive pixels only within the matching device's shield face, furnace throat, crystal chamber or gun muzzle, retaining metal and glass texture in the idle surface. `reactor_module_view.gd` samples each work surface in its own shader bounds and scales it by accepted Owner load; the same shader adds local moving muzzle, shield, molten flow or crystal detail. These work textures are image material, not a stage overlay or a source of UI text. Run the split script after changing any of the preserved lit source renders, then inspect both zero and active in Godot at 1× size.

Source coordinate system is 1187×1326, x right/y down; the visible stage is 808×835 below the 65px host rail. `generate_modular_pipes.py` shares tube section/material/collar construction across four independent endpoint/tangent paths and renders its pipe layers, clamps and 12 paired gimbal frames in Blender 4.3. `assemble_modular_surfaces.sh` crops the device sheets and generated layers, and copies the unbanded core source; it checks full Blender source canvas sizes before cropping, so rerunning it on already cropped output fails visibly. `modular-pipe-bounds.tsv` records the final pipe crop origins. Render command from repository root: `blender -b -t 2 --python assets/ui/reactor/b01/generate_modular_pipes.py`, followed by `bash assets/ui/reactor/b01/assemble_modular_surfaces.sh`. Check resulting transparent bounds and Godot imports at actual 1× size before accepting changed geometry.

The lower console image carries only an architectural shell. Native `Panel`, `Label`, `HSlider` and `Button` in `reactor_scene.gd` provide full count-responsive control plates and Owner-backed interaction. The shared R3 operation styles and resource icon/number contracts are consumed by that code; this asset folder does not own common host navigation, resource identity, pricing, unlock rules or save data. Old plate files remain source/history until the archive and authoring dependencies are resolved, and must not be mistaken for the current stage texture.
