# Chrono controls

Small, original code-authored SVG vectors for the chrono art trial only.
- `particle.svg`: chunky faceted chrono-particle identity, displayed at 44–54 logical pixels in the page header and reserve card
- `slider_grabber.svg` / `slider_grabber_hover.svg`: 32 × 36 logical-pixel handle for the existing notched HSlider
- `slider_tick.svg`: 4 × 14 logical-pixel rail notch

Palette follows the current compact equipment UI: cream, navy and cyan. No generated bitmap, external source, gameplay value or shared theme dependency.
