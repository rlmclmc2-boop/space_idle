# Opening journey scenery
Original vector art generated by `tools/create_opening_art.py` with Python and Inkscape. SVG sources and PNG exports are committed. No external/image-model assets or prompt used. Consumer: existing starfield shader through `battlefield.gd`; 572×960 logical viewport, 572×3072 segment, linear filtering, 960px shared world-coordinate overlap. Three preloaded RGB textures, about 20.1 MiB RGBA-equivalent uncompressed without mipmaps. One added scenery lookup, no additional nodes or per-frame geometry. Stars, hyperspace atlas and combat layers retain their existing owners. Stage 4+ remains existing scenery pending later production.
