# AI 科技工厂首代美术

首代机械与图标由 `scripts/ai_tech_factory_art.gd` 原生 2D 绘制，无外部图片、字体或模型来源。设备统一用深蓝机座、浅灰哑光外壳、青绿能量、暖铜活动件及 3px 深色描边；同一绘制代码供大场景与选择页图标复用，避免素材风格混搭。单代四枚小型改装标记随等级逐步增加；未来十级换代通过替换绘制模型扩展。

仅绘制一个当前科技装置与一个吊臂；旋转/压合/移动等动画只在研究中且可见时更新。武器精度为瞄准台、装备强化为压合机、资源精炼为炉、碎片凝聚为带线圈的密封凝聚装置、装备精制为双臂装配台、铀提炼为离心机、联合一体化为双核心桥、AI 奇点为芯片环。碎片晶体只在凝聚装置内部出现。
