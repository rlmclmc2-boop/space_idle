# Enemy omnidirectional ports

Hand-authored 64×64 SVG emitters using the existing physical/energy palette; no image model or external asset source. `enemy_fixed_ports.gd` owns the shared ordinary-enemy mount-center geometry and face size. Logical launches and both renderers use this center directly, without an aimed barrel offset. Body entry, orientation and scale still apply; bosses and leaders retain their original design. Physical/energy styling also covers ordinary missile and continuous-beam mounts. The face keeps the previously reviewed proportions, one screen-pixel padding and four-pixel minimum radius; its size no longer represents a rotating muzzle sweep.
