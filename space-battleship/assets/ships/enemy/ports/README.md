# Enemy omnidirectional ports

Hand-authored 64×64 SVG emitters; reuse the existing physical/energy recognition palette. No image model or external asset source. `retained_enemy_contacts.gd` sizes the opaque circular face around the unchanged logical muzzle sweep, with one screen-pixel padding and a four-pixel minimum radius. These replace supported ordinary enemy turret direction only; bosses, leaders and unsupported appearances retain the original painter. Hull textures, combat sockets and hit geometry remain authoritative elsewhere.
