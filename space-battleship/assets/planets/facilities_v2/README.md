# 星球建筑第二版：Godot 接入候选

用户已要求重做旧星球建筑。本组为新建可编辑几何，不继续采用旧简化图标作为最终资产；当前是待独审/用户检查的接入候选，存在资产不等于品质验收通过。

来源为仓库自制 Blender 脚本 [build.py](../../../art_sources/planet_facilities_v2/build.py) 与同目录四个压缩 `.blend`。无外部模型、贴图或 ImageGen 图像加工。运行 `blender --background --python art_sources/planet_facilities_v2/build.py` 重建全部四套源与 GLB；此命令会覆盖本组可编辑源，手工修改后应另存并单独导出。旧资产保留作历史来源，运行时本模块改读本目录。

| 类型 | 新造型及材质 | 本轮表现归属 |
|---|---|---|
| auto_explore | 环形居住舱、指挥核、对称光伏翼及对接结构；象牙装甲、深青骨架、蓝色面板 | 空间站轨道绕行，用户已定 |
| refinery | 接地基础、工艺厅、双处理罐、铜色汇流管与控制窗 | 精炼厂贴地，用户已定 |
| equipment | 装配厅、开放工位、龙门横梁与工具滑台 | 工坊贴地，为本轮功能建议 |
| shipyard | U 形开放泊位、桥楼、服务轨及分段泊位环 | 近轨固定船坞，为本轮功能建议 |

几何使用三段软倒角与加权法线；静态结构和活动硬件分别合并，保留 `Facility` 根与 `Motion` 枢轴。四组共 19,976 个三角形、7 个网格对象，逐组见 [model-stats.json](model-stats.json)。这只是几何统计，不是渲染调用数或性能结论。

[`planet_facility_scene.gd`](../../../scripts/planet_facility_scene.gd) 在首个已领取设施实际显示时创建一个共享透明 SubViewport。球体可见表面仍来自既有解析 shader；同形深度遮罩负责建筑前后遮挡，建筑自身启用深度写入。地表位置使用当前地表相位及球面/椭球切平面，独立云相位不移动建筑；基础与光照方向固定在同一场景关系中。轨道站与船坞用各自空间位置，建筑不接收鼠标操作。暂停/离页不推进局部动画，不逐帧重载模型。

[真实 Godot 证据与边界](../../../docs/verification/planet-single-side-godot/README.md)包含领取前后、两球切换和动态帧。本轮没有启动可见网格球 B 路线或同条件基准；新共享设施 viewport 与深度遮罩的成本尚未测量，不能据软件渲染截图判断用户 GPU 性能。
