# 设施V3资产接口

可编辑来源为`art_sources/planet_facilities_v3/`；`build.py`重建四个Blend和GLB，保留`Facility`/`Motion`枢轴。`material-atlas.png`提供象牙装甲、深青结构、蓝色光伏及铜色四区基础色；几何UV映射图集区域，Godot共享外部图集并保留金属度、粗糙度与独立灯色。图集生成记录为`imagegen-material-request.json`。

现行设计与验收要求见[M7](../../../docs/game-design/art/modules/planet.md)，本任务实际选用版本见[交接导航](../../../docs/game-design/11-stage6-contract.md)。
