---
name: ctx-compress
description: Preserve the state of a long project task before context truncation, handoff, or a large topic shift; use only when continuity is at risk.
---

Keep a compact working state with: goal and done condition; authorized scope and prohibitions; decisions with reasons; changed files; verified results; open risks; exact next action. Include paths, IDs, and commands only when needed to resume. Separate confirmed facts from assumptions.

Drop repeated narrative, completed steps without lasting effect, raw logs, and details recoverable by search. Link to authoritative files instead of copying rules. A summary is a locator, not evidence: reopen the exact source or error before edits or boundary decisions. Update the state after material changes; do not create a permanent handoff document solely to compress chat.
