# 独立评测 B 评分勘误（有效版）

本页只复核此前已经完成的正常新档 GUI 试玩，不重玩、不读取其他评测者或父线程的评分。原始冻结报告仍在 [REPORT.md](REPORT.md) 与前一提交 `a6ac129372827f80eb270a2ee83bfe5db7340fdd`；连续帧与校验清单未改动。本页分数优先于原报告相应行。

## 口径改正

1. 首关教程的“槽位升级需要65铁。资源数量显示在顶部资源栏。”及“战场掉落可通过鼠标划过回收”是基础操作说明，没有指定某战该选哪件装备，**不能据此认定直接告诉战术答案**。仍保留其实际问题：教程覆盖战斗窗口下方、未暂停交战、首段停留到 3/5，观看与操作被打断。
2. 项目是自动战斗。脉冲、导弹、磁轨和光束自动射击本身不扣分；有证据的配装结果不明显、敌型重复、伤害归因弱、进度主要由数值门槛推动才扣分。首稿中单凭“自动射击”“无手动战法”所作扣分撤回。
3. 一秒一帧的**事后回看只用于复核现场印象及具体画面，不能把当时未看见的敌人/战斗补算为现场试玩**。下表 0 分为这一覆盖要求所致，不代表该战设计品质为零。原报告称“53 个战点均在连续画面中看见了敌人和战斗过程”虽描述录像内容，但误等同于本人即时观察，撤回该断言。现场确认 39/53，未现场确认 14/53。
4. 首稿将“免费+0%”“实际速度×1.000”等养成公式单独当作明显出戏文案，证据不足。它们是在数值养成页面内，属于该类型游戏正常信息。保留不同页面美术风格落差及剧情语境偏薄的轻中度问题。
