## 覆盖边界

本机为 Linux x86_64，使用 [Godot 官方 4.7.2](https://godotengine.org/article/maintenance-release-godot-4-7-2/) 标准 Linux 程序（`4.7.2.stable.official.ed1daf0bf`），Xorg dummy 1600×900、OpenGL Compatibility、Mesa llvmpipe 软件渲染；命令指定 `LIBGL_ALWAYS_SOFTWARE=1` 与 Dummy 音频。日志仅见 V-Sync 驱动不支持提示，未做声音评价，也不把此机结果当 Windows 性能复测。窗口实际内容约 1373×883，原始 PNG 是对该窗口直接截取，未经裁剪后二次修饰。实玩是普通游戏 UI 输入；Python/XTest 仅逐次发送我决定的鼠标位置与点击、抓取当前 X 窗口，不读取或写入游戏状态。第 6 关无独立结算截图、第 7 关回退无生命归零帧，相关结论只按相邻 UI 状态标明。
