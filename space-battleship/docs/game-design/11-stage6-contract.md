# 第 6 阶段收尾与持久化交接

玩法、保存结构和验收范围仍以 [唯一入口](README.md) 可达的 03、05、06、07 章为准。本页记录实现边界与当前进度，不另定玩法数值。

## 状态归属与提交边界

| 所有者 | 长期状态与职责 |
|---|---|
| 各业务模块 | 导出自己的稳定实体和进度；候选恢复时独立校验本领域 ID、数值与不变量，不将可写内部字典交给界面或 SaveFiles。 |
| `Battle`/native | 同步导出历史计数、随机状态和 ID 水位。恢复时先建立新核的完整配置，再安装长期字段，重开一个满防御战场；不跨存档保留当前弹体、敌人、受损防御或事件队列。敌方 actor ID 水位由 Campaign/Hyperspace 自己保存。 |
| `GameSession` | 在完整业务调用或固定步结束后冻结快照，校验跨模块引用与占用；加载、导入和重铸均先建候选会话，只有全部检查通过才交给主场景替换。旧会话在此之前仍可用。 |
| `SaveFiles` | 只处理不可变 JSON 快照与 A/B 文件发布，不读取游戏模块，也不替业务处理离线收入。`configHash` 随封包保存；候选会话验证它与当前配置相同。 |
| `main.gd` | 接受单次成功的会话替换并重接页面/表现，不修补候选状态、不在界面重复发奖。 |

保存 Envelope、Amount 及 int64 编码依 06 章第 5 节。重铸保留/重置矩阵依 03 章第 7 节，按该矩阵构造全新 `GameSession`；`Hyperspace.prepare_reforge` 与 `accept_reforge` 只是候选无人机及轮次局部端口，不能直接当作整局重铸。

## 2026-10-26 finalization 续接核查

`SaveFiles` 现在保留异步写入失败至下次成功提交，页面即使在后续请求排队期间也显示失败；替换候选后异步写盘失败会在成长页同时显示持久化失败，重试成功后清除。文件探针在两个排队请求均遭真实临时文件打开失败时验证上一代仍可读、dirty 保留及重试；页面探针从有效导入候选替换后注入同一真实失败，验证新会话可用、旧磁盘档可读及失败/重试提示。候选恢复增加经济登记游标与 native DropId 水位的跨域校验；会话探针加入伪造游标拒绝。离线差值抽为纯边界函数，验证设备时间回拨为零、回到原时间仍为零、超过原时间只计正差；既有实际加载/导入探针继续验证 12 小时上限和补偿后保存重载不重复发放。导入损坏 JSON 返回具名拒绝，不依赖解析器打印错误。

续补：文件发布在 flush 后核查流错误；探针以失败流注入该边界，并用延迟 writer 验证 `close(0)` 返回 `WriterBusy` 后最终成功。损坏的主指针 JSON 回退到有效备份。主页面新增可点击暂停/继续，探针核查其他暂停原因独立保留；导入配置哈希不匹配的候选在预览时拒绝，旧会话继续可用。

自动保存间隔现写入独立 `user://settings.json`，不混入玩法 Envelope；页面启动时读取、修改后原子替换设置文件，写失败保留旧控件值。页面探针使用独立临时设置路径验证启动恢复与修改持久化。

本轮复用并通过 `SAVE_FILES_PROBE_OK`、`STAGE6_SESSION_PROBE_OK`、`STAGE6_PAGE_PROBE_OK` 及主脚本 `--check-only`。页面替换时旧节点 draw 回调误用新节点的错误也已修复，并由页面探针复核无该脚本错误。完整 checkpoint 探针本轮运行过慢而主动中止，沿用上轮通过记录，不计本轮复验通过。页面探针是 Godot 控件信号及状态验收；真实鼠标点击、视觉和导出包仍未验收。
