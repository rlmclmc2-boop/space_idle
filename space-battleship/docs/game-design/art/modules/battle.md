### M1 导航、航行、战斗与资源

**目标。** 以最新用户批准稿为成品依据。敌我舰交火与环境为主体；待命、航行、战斗、撤退和再航行时背景连续。紧凑HUD显示必要盾甲余量、危险/战况及暂停/驻守状态；当前值/上限、资源明细和统计按需查看。出航、驻守和暂停可达，观看区保留交火及动态净空。

**舰体层级与空间设计准则：**

| 类别 | 准则 |
|---|---|
| 设计目标 | 巡洋舰、战列舰、重型战列舰在正常战斗视图中具有可辨的体量层级。保留已确认模型与美术，通过相对尺度和布局适配实现，不靠持续放大高档舰拉开差距。 |
| 空间约束 | 先划定我舰最大完整占用、敌方编队、交火通道、无人机及未来扩展留白，再分配舰体尺度。普通敌舰占 1 格、精英占 2×2、首领居中占 3×2；占位包含舰体、转动炮台、护盾外缘、顶部盾甲条及间距，不拉伸舰图填格。完整包络取全部合法炮台朝向的扫掠范围与舰体、护盾的并集，并单列盾甲条范围；不得挤占相邻占位、画面边界或 HUD/导航遮罩。 |
| 当前参数事实 | 尺度来源与适配边界见[舰船尺寸参考](../../reference/ship-scale.md)。参数注明其固定实现来源。尺寸适配须继续使用共享几何和真实挂点/炮口，不另设命中尺寸。 |
| 待定参数 | 最大占用宽高、净空与留白预算、五档相对尺度及具体倍率尚未定。预算确定后，用同一逻辑单位和展示比例对比五舰，重点检查后三档；候选列宽高、统一 alpha 口径的可见面积、完整包络和剩余净空，并注明与当前值的差异。批准后更新参数来源。 |
| 适配核对 | 按V1对照批准稿的舰体比例与战场构图，同时核对最大完整占用。覆盖各档我舰合法装配、敌方各阶及最密合法编队，记录最小净空及对应舰型/装配/朝向/编队；舰体、炮台、护盾和盾甲条完整可见，无相邻、敌我、顶边或 UI 重叠/裁切，交火、无人机及扩展空间保留。方案通过后按批准参数实施。 |

**输入与反馈。** 舰体生存、盾甲、目标、炮口/转向/光束、掉落身份/数量及拾取结果读取Owner事实，规则见[01](../../01-runtime.md)和[02](../../02-combat.md)。空格暂停、G驻守和点击拾取保留，输入框/弹层管理焦点；首次教学退出后可按需回看。

**完成标准 V1。** 按[13的稿件对照口径](../../13-art-interaction.md#6-制作与双审证据口径)，在真实完整战场中尽可能还原批准稿的敌我舰尺度层级、编队与交火空间、环境纵深、HUD位置、材质光照和炮火节奏。舰体及动态包络按上表保留净空；状态切换、面板收起、暂停/驻守和拾取反馈按本页输入对应实际对象。
