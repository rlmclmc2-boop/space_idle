# 固态行星：地貌就是工业底盘

[总入口](README.md) · [裸态／完整设施态概念图](images/solid-concept-a.png)

**裸态。** 蓝色海洋、浅沙海岸与低饱和绿色陆块形成可辨地貌，薄云与固定光照保留独立层。孤立星球也有清楚海岸与山脊，设施态沿用同一机位和地貌，不重新换一颗球。

**设施态与承载。** 沿海台地切出精炼厂基座，工坊落在另一片可辨陆地并露出龙门工作湾；两者通过短程地表输送与起降节点相连。空间站沿外侧轨道绕行，船坞在更外的独立服务位，和地表建筑留出轮廓空隙。图中的大型跨地貌输送和船坞尺度只是构图候选，实际 808×900 可读性待审。

**作业与动态。** 精炼厂可见入料与炉体开合，工坊可见加工臂往复；船坞吊机服务独立泊位，空间站绕行，云与地貌分速。施工前由海岸和山脊引导视线；施工后建筑沿这些地貌形成清楚的地面生产—轨道转运—外部维护链，不能显成四张贴纸。

此页只提表现与空间组织。精炼厂产出、工坊贡献、施工与开放仍以现行规则为准；图示输送路线不产生额外资源或指令。

## 分步对照

每张图左侧是同机位裸天体，右侧只显示该步及此前已建设施。下表是一条可行的领取示例，门槛并不强制玩家按此顺序领取。

| 步骤 | 图 | 新增且自带的承载 |
|---|---|---|
| 0 裸态 | [完整概念图左侧](images/solid-concept-a.png) | 自然海岸与山脊；没有预留厂台 |
| 1 空间站 | [01](stages/solid/01-station.png) | 站体自带轨道泊口；地表仍完整裸露 |
| 2 精炼厂 | [02](stages/solid/02-refinery.png) | 自带台地基座、入料口和短输送带；不借未来工坊 |
| 3 工坊 | [03](stages/solid/03-workshop.png) | 自带锚桩和龙门工作湾；仅此时才可出现两处已建地表设施间的路线 |
| 4 船坞 | [完整概念图右侧](images/solid-concept-a.png) | 独立外侧服务位，自带码头和吊机 |

该组是图像生成的静态阶段意向：同一观看机位、近似同尺度，细节地貌并非逐像素锁定。真实自转时精炼厂与工坊连同基座、短管线锁在同一地表经纬；空间站与船坞独立于地表运动。背面被遮挡时视觉上可以暂时只看到轨道设施，仍能从稳定管理入口读取已建状态。地表至轨道的连接表现宜用离散运输器或仅在交会窗口出现的短暂接驳，不画一根在整圈都绷直的固定管。两种自转取舍及待审相位见[自转分析](rotation.md)。
