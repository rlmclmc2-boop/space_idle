**当前优先审图：实体带代表稿。** [固态新图](solid-integrated-spine-concept.png)是一颗裸天体与同机位完整设施态。空间站为上左原点，金顶精炼厂接上右弧，橙色工坊与双臂船坞分别嵌入前方右／左弧；四座通过同一条象牙装甲、深青承重肋和青色通道连续连成整体，不再由虚线轨迹替代建筑带。轨道平面倾斜，远侧脊梁在天体背后被遮挡、两侧重现；近侧实体脊梁越过球前下方暗空间，和旋转地表留有间距。精炼厂与地表只用自由飞行小艇，脊梁没有焊到地面。小型姿态／场稳定节点属于各自已建弧段的结构，非额外可建建筑；这只是科幻视觉承载提案，不宣称环状刚体的真实稳定性已获物理或运行验证。

**独立建造约束。** 完整图显示四段闭合后的结构，尚未画半成品；后续分步图必须让空间站首段自带两端封帽和姿态节点，精炼厂／工坊／船坞每座自带新增弧段、封帽与局部稳定节点，不画未来段帮它承重。空间站是完整构图的视觉原点，不能据此新增玩法前置；现行独立施工／领取允许其他建成组合，若实施必须定义没有空间站却先建成别座时的自持短段。未解的主动稳定方式、段间对接及真实转动相位仍为设计验证项，不静默写成已实现规则。只在固态完整态的整体关系审过后，才把此结构扩成三类和五态。

**退回记录。** 第一版 B 的 C 形悬空托架像附着球缘，用户明确退回；第二版虽有前后轨迹，却成了四座独立飞行平台加一根虚线，也偏离“空间站原点、建筑在实体环带一体扩写”，父线程审图退回。以下旧图、旧提示词和哈希仅供追溯，不能用于证明新实体带已通过。

## 历史退回方案：独立平台与更早 C 形环带

第二版制作时，用户已退回更早的 C 形硬件；当时先经[固态完整态](orbital-plane-solid-complete.png)与[裸态→四座五态](orbital-plane-solid-stages.png)校验，再沿同一构图转出[气态](orbital-plane-gas-complete.png)与[恒星](orbital-plane-star-complete.png)及各自五态。这一版随后也被退回，以下仅为制作记录。

新结构把一条**倾斜轨道平面**作为整体秩序，而不把金属环当作承重物：轨道轨迹的远侧在球后被遮挡，左右露出，近侧从球下的暗空间越过并与地表留出间距。空间站、精炼厂、工坊、船坞各有短曲线底盘、推进器和姿态维持，分布在同一轨道平面；实心件之间留空，青色断续线仅表示轨道运动，不是承重梁、硬管或建造前置。没有精炼厂时不存在它的采集艇；没有工坊／船坞时不存在它们的底盘。每座设施可独立建成，玩家领取顺序仍按现行规则而非这五格强制。固态精炼厂与地表通过自由飞行小艇转运，不焊在自转地表。该设计更接近“同轨分布式轨道带”，不是一根环绕天体的完整实体金属环；是否保留环带外观需用户看图判断。

**返修自检。** 三类完整态均为上左圆站、上右金顶精炼、下右橙色机械工坊、下左双臂船坞，四者不同；各五态按裸→站→精炼→工坊→船坞累积，旧建筑在后续格保留。近侧虚线走天体下方暗空间，远侧在天体后中断；气态精炼厂的掠云艇到云顶，恒星精炼厂的磁采盘处于光球外，只有非接触能流进入。静图只能表达一个观看相位和设计意向，不能证明同轨运行周期、模块尺寸下可读性、真实重力轨道稳定性或自转遮挡整圈均已验证。新稿的设施仍偏细，后续需要减法。下文保留旧 B 的实际图源与提示词以追溯，不再把旧 C 形布局当推荐结构。

更早的 C 形方案曾作为供用户比较的**概念候选**，不是替代既有 A 方案的批准、游戏运行画面或新玩法规则。三类沿用同一套象牙／深青／青色能源的卡通化主体：空间站带首段短弧，精炼厂自带第二段及采集端，工坊自带第三段龙门平台，船坞自带末段泊位。五格从左到右为裸天体、仅站、站＋精炼、前三座、四座完整态；同一格内没有未建段。玩家仍可按现行独立施工与领取产生其他建成组合，图中次序只是可行示例，不是强制前置。

轨道带自身维持外部轨道姿态，不随天体表面自转。固态接点为精炼厂带来的可收回探针／自由接驳；气态接点换成精炼厂自带的云顶掠云艇，03 至 05 格持续可见；恒星接点为安全外侧的隔热磁采盘，琥珀色稀疏能流自日冕越过空隙入盘，青色回流沿短臂进入精炼厂。三类均不以永久硬管焊住旋转表面。轨道设施可随视角与自转遮挡，不保证所有建筑始终可见，也不引入拖动观察。这里的“深入采集”是视觉关系，不代表新增产出或效率。白矮星、红巨星、脉冲星采用此主体时的距离、屏蔽和避束流接点尚未出图，不能直接套用本图。

**审图边界。** [完整态对照](three-worlds-complete.png)最直接检验共用主体和三种采集端；三张五态图检验每座带来一段。完整态对照中的恒星采集端视觉上过于贴近光球，以[恒星五态修正版](star-stages.png)的外移位置和非接触能流为此轮较准的空间意向。图像编辑并未逐像素锁住天体纹理或工程件外形，不能据此认定多相位自转、实际模块比例、热防护或四设施状态组合均可运行。能流只说明视觉上的采集方向，不新增采集资源或产出规则。现有图仍偏细，在 808×900 模块尺寸需以后续资产化再做减法。
