# 恒星：热冷分层的非接触设施

[总入口](README.md) · [裸态／完整设施态概念图](images/star-concept-a.png)

**裸态。** 金色光球以暗斑和短促日冕边缘说明高温主体；光晕受控，不吞没形体。设施态保持相同光球、机位和亮度关系。

**设施态与承载。** 不在光球上铺建筑。数段留有断口的磁场采集弧悬在日冕外缘，由冷区桁架连接到屏蔽处理站；工坊和空间站在较冷轨层，船坞位于最外独立服务段。运输路线从热侧采集弧向冷侧转运，结构分层一眼可读，不以能量特效替代承重关系。

**作业与动态。** 光球自身流动、采集弧小幅调角、冷区维护臂按实际工作状态动作，运输器沿外缘绕行。裸态留足日冕呼吸空间；建成后设施用间隙框住光球，而非遮盖中心。概念图里的环弧可能过大，落到模块尺寸时需检验主体与各设施可辨。

磁场采集不代表新资源、新效果或新开放规则；若要改变精炼厂在恒星上的适用性或产出，需另行提案。
