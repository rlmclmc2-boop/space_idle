# 红巨星：远离稀薄外层的新月设施

[总入口](README.md) · [裸态／完整设施态概念图](images/red-giant-concept-a.png)

**裸态。** 锈红与珊瑚色的膨胀光球，宽松、半透明的外包层与少数突出日珥形成“体积大但边界不硬”的身份。左右同机位，设施态不把恒星换成另一个亮度模型。

**设施态与承载。** 主结构只在外包层外形成非对称远距新月，少数细探针向日珥方向接近，主体不接触等离子体。处理节点嵌在新月下缘，工坊沿冷侧维修脊线，空间站与外部船坞落在更远的反侧节点。新月内侧留大面积空隙，让危险距离成为视觉主题；也避免与普通恒星的紧环布局重合。

**作业与运输。** 物料／能量的表现从探针经新月结构向屏蔽节点移动，再沿长脊线去外部泊位。日珥流动慢于局部探针调整，站体与船坞保持各自运动／服务状态。建设前由巨大而柔软的日珥框住天体；建设后新月回应其轮廓，但不围满一圈。图中处理设备过密的风险要在模块比例下削减。

本页的探针和新月首先是视觉承载，不新增采集收益、施工规则或红巨星专属建筑；若改变现有四设施职责，须另提玩法。
