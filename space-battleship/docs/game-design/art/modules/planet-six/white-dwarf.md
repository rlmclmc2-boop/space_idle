# 白矮星：小核心与大屏蔽的尺度反差

[总入口](README.md) · [裸态／完整设施态概念图](images/white-dwarf-concept-a.png)

**裸态。** 极小、强亮的蓝白核心与紧凑光晕，周围大量深色空间就是身份的一部分。不能为填满模块而放大到普通恒星的面积。左右保持核心尺寸与光向。

**设施态与承载。** 三片错开的象牙屏蔽瓣围出可见的保护空腔，处理湾位于瓣片背光侧，工坊在冷侧维修位置。小型巡检站走外层椭圆路径，独立干船坞更远；瓣片、处理湾和泊位以清楚的桁架及遮蔽运输廊连接。主体建筑面积可以大于天体，形成与其他五类不同的观看比例。

**作业与动态。** 核心保持稳定小尺度脉动，屏蔽瓣只做有限开合或角度校准；运输器经受遮蔽的廊道出入，干船坞吊架展示独立服务。施工前是微小耀眼核心和留白；施工后由瓣片主导画面，但始终不盖住核心。缩至实际模块时应优先保住三片轮廓与核心的尺度反差，删除细碎杆件。

屏蔽不是新防御数值或新设施效果；如需专属辐射／能源玩法，属于待定提案。
