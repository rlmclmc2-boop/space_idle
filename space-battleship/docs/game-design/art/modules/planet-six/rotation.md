# 自转与完整布局的持续观看

[总入口](README.md)。本页分析静态概念图之外的运动约束，**不决定取消现有自转，也不修改运行规则**。

六套的“完整设施态”表示四座设施都已建成，不保证任意一帧都能同时看到四座。若让真实三维自转与深度遮挡生效，固态地表的精炼厂、工坊、底座和本地管线必须锁同一经纬，随球体经过正面、球缘、背面；空间站、独立船坞在各自轨道／服务位运动。云层可另速流动，但不能拖着地表设施走。恒星的表面纹理、日珥、气态云带流动只表示材质变化，不自动决定外部实体平台的轨道速度。

| 取舍 | 观看结果 | 必须解决的风险 |
|---|---|---|
| A 保留真实整圈自转和前后遮挡 | 有可信空间关系；某些相位只见部分设施 | 球缘脚点、背面隐藏、局部管线同地表变形；UI 的已建状态不依赖设施当前是否可见 |
| B 保留表面流动／自转视觉，设施整体维持较稳定的展示面 | 四设施关系可持续阅读 | 设施与地貌不再同转会显得悬浮；若选此项，须明确外部轨道承载或改写视觉解释，不能假称地表固定 |
| C 真实自转但在关键阶段减速／停驻展示 | 平时有空间真实性，停驻时能看完整构图 | 何时停驻、与游戏时间／暂停关系、恢复相位均待设计；不能偷偷强推时钟或改变业务节拍 |

目前 A 是现行表现事实，B/C 仅是讨论选项。下一轮应至少审正面、左右球缘、背面四个相位：固态确认地基与管线逐步遮挡；气态确认云带与浮台不是同一个流动层；三类恒星确认实体安全轨与表面流动分离，极轴束流不能扫过固定设施。轨道交通与地表设施之间只在可见的接驳窗口交换运输器，或由对应设施自带旋转接头；不能把固定桥线永久跨接两个不同角速度的对象。

已建而暂不可见的设施仍由稳定 UI 入口表示。若用户最终选择“整套持续可见”，需先审 B/C 的空间解释和相位图，再决定是否调整现有转动表现；这一步尚未选择。
