# 六类天体与设施一体化概念

本页是六套新概念的唯一入口，承接[M7 星球](../planet.md)。用户方向是逐类设计固态行星、气态行星、恒星、红巨星、白矮星、脉冲星，让“天体+设施的完整布局”成为星球界面的主体。每套先对照**裸天体**与**同机位、同尺度的完整设施态**，由承载、作业和运输关系决定整体构图，再讨论如何让 UI 融入。以下图是静态概念图，尚非 Godot 画面或用户批准资产。

**状态边界。** 现行[第 3 章星球规则](../../../03-progression.md#5-星球探索与建筑)仍按星球 ID、既有空间站／精炼厂／工坊／船坞、施工门槛和贡献执行；六类的资源、产出、解锁、设施适用性或新建筑功能均未批准。图里的采集环、浮台、磁场弧等首先是视觉承载方案；若将其转为新功能，必须另立玩法提案待定。当前已审的单星球地表与轨道设施、R5 造型及 R14 局部修正只供风格和问题参照，不等于这六套概念获批。

**呈现尺度。** 当前 Godot 星球模块约 808×900、客户区 1440×900，只作设计参照，非用户冻结的六类最终尺寸。概念图保留天体外的建筑、运输和运动空间；真正接入时需在目标页面检查轮廓、操作避让和阅读尺度。先看无控件整体关系，再探索把星球选择、任务和设施管理放入附近留白，不能为塞控件破坏主体。图中无烘焙文字或数值。

**视觉共同语言。** 沿用已认可的象牙装甲、深青结构、克制青色能源和少量琥珀信号。六类不共用一个设施落点模板：每类的承载介质、遮挡、运输路径与动态节奏分别定义。图像生成的原提示词、原图文件、来源参照和哈希见[生成记录](generation-prompts.md)。
