# 反应炉资产与安装契约

[M3目标与状态呈现](reactor.md) · [全局呈现](../../13-art-interaction.md)。本页维护当前分件资产的制作、导入与装配关系；现场状态只写B01 HANDOFF。 技术交付与装配按本页核对；美术完成按[13§6](../../13-art-interaction.md#6-制作与双审证据口径)及M3对照批准稿判断。

## 可替换静态资产契约

当前源为`assets/ui/reactor/b01/generate_faceted_reactor.py`。本地Blender导出可编辑的`faceted-reactor.glb`与`faceted-layout.json`；导出前逐分件应用倒角和加权法线，再按部件合并；合并顺序按稳定名称排序。GLB聚合包共享材质，内部按稳定ID独立分组，不将设备、管道、工作区和原生控件烘成不可拆的全景图。

稳定模块ID只有`weapons`、`defence`、`smelting`、`condensation`。固定背景为`bay`，核心为`core`；对应管路为`pipe_<id>`，机台为`console_1`至`console_4`。设备组含完整机体、底座、预制空心套筒以及独立工作Mesh；管组含核心出口套筒、管壳、内腔与遮挡件。工作Mesh英文语义名是生成器/呈现层之间的制作接口，不由玩家显示名或图片顺序推断。

`reactor_ports.json`是接口输入，逐设备提供核心出口、控制点、设备入口、入口轴向、口径与插入深度。先确定这些值再建模；模型、管道、光流消费同一源数据。`faceted-layout.json`交付以下真实输出：

| 字段 | 含义 |
|---|---|
| `source_size` / `content_size` | 源正交标定画布1187×1326；模块内容808×835 |
| `scale` / `offset` | 等比缩放与源原点在模块内的位置 |
| `parts` | 各稳定节点组的真实源空间可见边界，不使用旧PNG裁图框 |
| `double_left` | 武器+炼铁两路的平衡装配位移及按同源端口生成的专用管段、接收窗弧长；只变展示构图，不决定Owner开放组合 |
| `single_smelting` | 单炼铁的核心/安装座/设备位移、预生成管路输入及显式端口标记；同一源坐标变换后接合 |
| `work_paths` | 从同一构造源导出的炼铁入料起终点/炉腔照明锚点及晶体聚焦端、种子原点/GLB标记、辐照锚点和输送槽中心线、弧长/离面量；种子响应与局部光消费这些点，形成后碎晶沿同一输送路径移动，不另估屏幕坐标 |
| `work_frames` | 逐设备从制作坐标到源三维的基向量列与原点；工作Shader在顶点阶段用其逆矩阵取回安装前的热区/种子/场面坐标，先扣除少路数装配位移。不可把已转向机体的世界点直接与制作坐标常数混用 |
| `ports` | 设备及核心接口的三维位置、归一轴向、套筒口与管端、口径、实际插入长度及接收窗所在的归一弧长 |
| `console` | 1–4路状态的总控带、分配行与升级事务带内区；原生UI一次读取同一导出坐标，少路数时机台与控件一起上移 |
| `generator_sha256` / `asset_sha256` | 导出时生成器与GLB的实际哈希，用于交付绑定 |

背景几何可延伸到标定画布之外以覆盖客户区；它的真实边界不等同主体安装安全框。生成器保留实际坐标，不为把边界塞进矩形而裁断或非等比拉伸设备。

## 坐标与端接

源平面左上为(0,0)，x向右、y向下，单位为源像素；对应三维坐标为(x,-y,z)，z向观看者。正交相机位置(593.5,-663,1500)，标定高度1326。主体统一使用`s=835/1326`与`o=((808-1187s)/2,0)`，源点q在模块内容中为`o+s*q`。Scene内部内容从y65起；共享宿主的最终Canvas变换另行作用，呈现层使用其逆变换采样同一源深度。

`axis_to_device`定义屏幕轴向；三维升角与径向基底由生成器统一构造。套筒与管端使用相同中心线和截面平面，起止切线明确固定。`projected_insert_depth_px`是源平面插入量，`axial_insert_depth_source_units`是对应的三维轴向长度，二者不能混用。单炼铁使用导出的安装位移及其专用管段，机体与工作层同变换，核心出口另有与该管段轴向一致的标记；不移动原生操作台。管段不得只碰孔边、停在旁边或靠遮片假接。GLB的`<id>/power_in_<id>`与`core/power_out_<id>`保留显式接口标记，局部Z轴指向流动方向；交付元数据提供对应节点路径。

盾场压力后筒、轴承、装甲分段与前环共用投射轴；供电套筒仍使用声明的管路坐标系，两者不能误用为同一轴。凝聚顶领圈与玻璃腔共用截面；炉盆的卷边、侧壁和耐火内衬为实体，独立液面位于盆沿下方。设备壳体与工作Mesh共用同一刚性安装姿态；套筒保持声明的端口坐标系并进入壳体。姿态不能分别只作用静态外壳或工作层。当前管路为有完整侧壁/底壁的圆截面压力管，顶端能量窗凹于两侧管唇；口径以reactor_ports.json为唯一输入，改变时模型、管段和导出元数据成套重建。

实际装配必须读出：管壳进入空心套筒、连续内腔、正确近侧遮挡和端面厚度。流光沿同一几何的累计弧长UV从核心输送到设备，在真实卡箍/壳体后被遮挡；不另估一条屏幕路径。接收光面和玻璃底位于套筒的真实内嵌窗，按同一弧长位置在亮包到达时沿轴充亮、保持并回落，并联动对应设备的功能工作区短响应；不覆盖金属外壁，不在首次到达前显示接收完成。某路未开放时，设备、管路、核心出口套筒、工作层与该路原生控件成套隐藏；房间结构保持连续，不用临时多边形盖住。

## 运行分层与更新

固定机壳、房间、机台及结构阴影由同一三维源在设备范围改变时采样，颜色保留2×MSAA。材质按模型材质名区分涂层装甲、裸露合金、深色漆面、耐火内衬、玻璃及铜件，不能全部使用同一粗糙度与反射。 装甲大面使用真实浅拱折面，舱壁分叶、凹面返回和顶部凹井属于可编辑结构；不以整块平面色板承担房间进深。核心、盾场、炉池和凝聚腔使用各自真实点光源、实际机件法线和结构阴影；灯光能量按源像素单位标定，不把像素长度误当米后留下不可见的入射光。停机表面/核心入射分别缓存，已开放局部灯源的独立入射样本按实际数量紧凑打包，槽位/列数与纹理同时提交，未开放灯源不留无用图格；采样位置消费同一安装帧及少态装配变换，不另估屏幕中心。运行按实际各路有效量混合对应光照差值，核心系数随蓄能/压缩/释放变化，真零停工作光，暂停冻结、隐藏不写系数。实际有限光程的投影范围只用于略过零贡献采样，不代替BRDF/结构阴影。组合变化才重建这些缓存，普通分配不触发三维重采样。闭合结构的轮廓线由同一Mesh背面扩张生成，参与静态颜色缓存；深度采样时关闭轮廓面，避免扩大工作片元的遮挡边界。该轮廓不新建原生控件，也不在常态逐帧重渲三维场景。背景缓存是可重建的渲染结果，不能替代分件源，也不含玩家文字、按钮或数值。当前背景合成输出恒为alpha=1，使用不透明混合；正常工作效果与原生控件仍独立合成。

固定结构COLOR_0.R交付自身凹隙遮蔽；炼铁分件G记录同一制作空间受热场，仅热耐火材质读取，其他材质忽略。三层实体内衬的热色和炉腔点光在既有炼铁局部采样中捕获并复位，随实际有效量混合，不新增常态三维采样或图格。自身凹隙遮蔽，仅由同一刚性件的真实结构离线采样，不烘入未开放设备/其他数量预制件的阴影。跨分件阴影由当前组合的实际灯光缓存生成；地面与脚座共用同一坡面高度。工作Mesh保留原始顶点、法线、UV及源深度，按固定正交关系投影到Canvas，Stage另构造动态COLOR深度编码，不与固定结构的COLOR_0语义混用。 凝聚顶部聚焦头、种子凹腔、收集坡道和玻璃有真实安装/开口关系，工作孔径与晶尖保留净空；聚焦端、种子及照明位置共用生成器锚点。晶体在设备制作坐标沿生长轴改变体量，并同步变换法线/源深度；投影UV.x保留原法线Z符号以在形成中判正背面。完整/已形成前面索引均只在初始化准备，同一Drawable按状态切换，不能新增叠层或每帧重造Mesh。武器放电口为空心轴向件，放电几何位于口内及舰体通道中，释放只改真实通道内的能量包强度，不在屏幕平面拉伸光带。盾场由同一发射面坐标构造，场面与机件使用相同安装变换，实际曲面UV.x记录从发射端至外缘的建立进度；核心两极约束通道独立于机械支架。三维机壳深度以16位保存，工作片元与其比较，不能将发光绘制到前景金属上。能量表面自身边缘用连续透明度处理；不得用降低更新频率、取消效果或隐藏机器替代性能优化。改变视角、标定范围或机体时，重新生成对应几何/深度并检查同版画面。

核心等离子体序列由独立离线三维发射/吸收积分生成，配方、帧和图集哈希存于plasma-volume.json；只含能量体，不含机壳或控件。现有等离子网格以发光材质采样相邻两帧，仍受同一源深度和时钟约束；不实时作体积步进。

普通数值变化只更新对应读数、原生滑条或工作输入；工作时钟只推进工作过程，不重建节点、重读Owner或重采样静态场景。暂停冻结本地过程，隐藏停止局部循环，重开读取当前快照。静态缓存重建与工作动画分别记录计数，交付性能报告区分录制/未录制、固定渲染诊断/完整游戏及已向用户报告的上一次指标。

文字、费用、倍率与原生操作遵M3/13/14和Owner接口。 分配比例在同一滑轨右端固定读数位，滑块与填充共用缩短后的有效行程，为读数保留轨内净空；100%不改变锚点，少路数不另造排印规则。控件命中区按实际承载内面确定；所有普通值、长费用、零态/低正载、设备范围变化及正常工作动态在同一固定版本检查。格式、资产哈希、接口坐标与导入设置属于制作/交付核对，不为此新增运行时规则或全页刷新守卫。
