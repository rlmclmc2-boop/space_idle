### M7 星球探索、轨道设施与领取

**目标。** 以最新用户批准稿为成品依据。建筑与环绕结构共同整体设计，四设施嵌入同一环向建筑与承力体系，形成连续但有主次变化的剪影。主廊、功能舱和开放泊位共同决定环的体量与建筑节奏；设施身份、原接口和业务关系保留。球与环独立转，探索船另轨，保持真实球后遮挡。不同星球可共用结构并适配接点，也可按需要设计独立变体。

环带与设施节点的连接、工作口和运动部件随整体造型一并设计；各设施可辨认，独立建造段端面闭合。完整态与逐建状态均保持连续承力关系、清晰前后层次和适当球环空隙，第6类的远景身份与整体相称。

### 环向建筑的整体造型约束

| 构成 | 制作要求 |
|---|---|
| 共同曲率 | 主廊、功能舱的内外轮廓及屋面分件沿同一环向中心线展开。允许以有节奏的短分面形成弧，但主要体块本身须转弯；接口桥段承接已有体量，不能承担整段建筑的曲率表达。 |
| 体量与建筑节奏 | 先确定一组主要建筑体和次级服务段，再把四设施功能嵌入其中。廊段长短、舱体宽窄、屋顶高低与开口疏密共同形成节奏；四项业务不要求四个等大、等距的建筑块。环的承重截面应能解释功能舱如何嵌入，而非只读成一条串联线。 |
| 连续过渡 | 舱体接近主廊时，在一段可见长度内逐级收窄、降低或分叉，屋面、侧壁和承力根部一起转接。平面轮廓与截面连续变化，保留结构分缝；仅补一段接头不构成整体过渡。 |
| 制造舱端部 | 封闭制造舱的外壳沿环向展开并收束，端部用缩短的斜切面、舱门或有深度的结构解释结束。大块无功能的实心外伸端面不得成为前景第二主形；端部、侧壁与承力段共同构图。 |
| 功能与负空间 | 开放泊位以停靠负形和引导方向可辨，制造舱以封闭空间可辨，热工与指挥功能嵌在建筑体的主次变化中。星体、内环和建筑之间保留连续可读的负空间，同时让建筑体自身的弧形主轮廓成立。 |

制作先在完整页面实际主体尺寸下看单色体块与剪影，确认曲率、体量和建筑节奏，再做装甲、材质与功能光。独立建造状态各段端面闭合；完整态接合后构成共同建筑，不以独立四块各自可辨代替整体成立。整页同时放入当前舰船与操作台，判断建筑/星体/操作的主次。

### 与现有舰船统一的制作要求

保留已认可的分面装甲方向和设施功能造型，按批准稿还原设备，再与当前舰船同屏校准；现有舰船与装备操作结构保持。以下要求同时作用于设施和承力环，在实际整页尺寸判断。

| 制作面 | 明确要求 |
|---|---|
| 边缘与连接 | 主剪影用连续深蓝暗缘建立，强于装甲拼缝；开口、搭接和设备落脚用较弱的接触暗部解释深度。内部小件再降一级，避免所有面等粗描黑或仅靠亮边勾形。背侧轮廓随真实球后遮挡消失，不能穿球描边。 |
| 主次明暗 | 保持场景共同的上方偏左受光：大受光面、次级转折面、冷暗侧/内腔形成与批准稿相应的宽明暗与转折层次。主壳/功能口先于螺栓与小管可读；不以全灰均匀亮度或高频金属反光替代体积。 |
| 材质与功能色 | 象牙主装甲、深蓝承力面和低亮度机械内腔先形成层次，再补中尺度分件、宽窄受控的倒角亮面和有限反射。青色只突出能量/导引，暖橙突出热工工作口；不把整圈边框、所有接缝都点亮，也不增加写实锈蚀和密集噪声。 |
| 设施身份与信息主次 | 泊位以开放负形和停靠船、制造舱以封闭主壳和错层屋顶、精炼厂以热工炉口/出料方向、空间站以指挥核和翼形区分。缩到详情展开后的主体区仍先读出这四类主形，再读装甲分件；环为共同承托，亮度与细节不抢设施和操作读数。 |

下一固定版本先落实外轮廓、主壳/暗侧/内腔和中尺度装甲分件，再补细节。在同版总览、不同高度详情台和既有待机动态中并看当前舰船，判断造型、明暗、材质、读序是否共同成立，并按V7对照批准稿的整体还原效果。

**操作布局。** 星球选择、探索、人员和设施入口在顶部保持稳定；详情共用底部深色操作台，左侧身份、右侧事实/操作，长正文在台内滚动。主体安全区由顶部状态区实际下缘和底台实际上缘共同确定，包含设施/环及工作、抵达路径包络后整组适配；不靠挪动单一建筑避让。展开、切项和收起保持操作与主体的主次和留白，任务摘要及停止/取消仍可达。设施待领提示可发现，背侧或遮挡对象仍由稳定入口选择。

**输入与反馈。** 读取Owner的未达门槛、building、缺人暂停、ready、已领取及命令标签；显隐、施工、可领和实际收益分别映射这些状态，规则见[03§5](../../03-progression.md#5-星球探索与建筑)。设施、探索和人员展开区各展示当前对象自己的事实。探索度D、elapsed/duration、设施work/required_work分别命名；切球重绑选择、选项、人数、领取准入与指令目标，清旧短暂反馈。重铸入口连接[M10](persistence.md)。

**完成标准 V7。** 按[13的稿件对照口径](../../13-art-interaction.md#6-制作与双审证据口径)，在真实整页、相关视角与连续转动中尽可能还原批准稿的星体与建筑体量比例、主剪影、环向曲率、连续建筑节奏、负空间、前后遮挡、材质光照和局部细节；四设施功能嵌入同一整体空间。独立建造、详情开合、切球及探索/施工/领取状态保持批准构图和动态意图，控件与实际对象及结果对应。
