## 已定与待审

| 身份 | 内容 |
|---|---|
| 已定输入 | 战斗持续可见，与模块并列；唯一模块导航；无“返回战斗”页面关系；收起不暂停。奶油白/海军蓝/青色/克制琥珀的既有语言。专属场景统领界面，必要判断信息常驻，教学退出常驻。 |
| 已定输入 | 旧设备造型不自动批准；已接受舰体、背景、炮口和当前球体/地图保持。科研前置未满足项、未开放碎片凝聚隐藏。业务与共用契约归原线程。 |
| 待审 A | 宽屏左战场约1/3、右舱室约2/3；导航并入舱室顶边；全局顶栏只放钱包与系统入口。 |
| 待审 A | 窄屏上战场约30%窗口高度，下舱室独立滚动；HUD移到战场两侧，完整战场等比显示。所有文字按屏幕尺寸排，不随战斗缩小。 |
| 待审 B | 窄屏战场增至42%高度，增加战斗辨识，代价是舱室首屏更少。两稿不增加自动暂停或改变模拟；建议先审A，再按实机战斗可辨性选择。 |
| 待审 | 反应炉控制台分区、单设备输入提交形式、科研舞台及设备映射、舰装预览与槽位关系；字号/触达尺寸/断点/色值均为候选。 |
| 未完成 | 五舰/敌方完整动态包络与净空、所有模块视觉细稿、最终新资产、游戏接入与V0–V10实机验收。C1容量已由用户定为五舰1/2/3/4/5，原线程同步权威配置；前端只消费公布容量。C4仍由父线程处理。 |
