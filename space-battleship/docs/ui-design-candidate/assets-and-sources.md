## 安装尺寸、锚点和包络

反应炉直接遵守正式[M3的v1静态资产接口](../game-design/art/modules/reactor.md#v1元数据结构与稳定身份)，不另造字段/版本。资源未给出可见边界、install、power_in/out和真实路径时保持draft，不用占位SVG的画布坐标凑ready。后续清单中的资源哈希、导入模式、mipmap/过滤等也由正式接口记录。本目录只提出目标空间。

反应炉候选安装预算：宽屏单设备主体约78×90界面像素，中屏56×77，窄屏64×82；设备舱内轮廓必须等比适配，不含文字的输入/读数区另算。上述是当前HTML占位框，不是最终绘图输出分辨率；若造型无法在最小框清楚辨识，须先改空间分配再生成。核心宽屏最大约250直径，窄屏86；旧画布1364×1200/223×180不冻结本稿。动态效果要单列最大包络；生产图源像素建议至少覆盖最大显示尺寸的2倍，但须在实际窗口与导入内存预算确认后定稿。

控制台层级：后墙/外壳→核心环境和实体主管→设备/舱体→局部效果→读数/控件。管路只用同一组端口经最终变换投影，滚动改变设备与支管位置时一起更新。宽屏核心出口接到右主管，窄屏接到下方主管；本HTML只证明主干/分支关系，尚未完成核心出口的语义锚点连接，不能当“管口已接通”验收。

科研候选舞台宽屏约360高，大屏450，中屏300，窄屏245；设备占舞台宽约31–36%，底座落在平台面，探针在上侧独立包络。当前object-fit是试装，最终须用可见主体/底座元数据验证，不用透明画布中心当定位锚点。场景裁切不能移走平台承托面或使设备浮空。

所有素材分别检查资源边界、可见主体边界、布局框和点击区域。PNG透明留白不等于可点击空白，模型原点不等于视觉中心；输入框/按钮点击区由UI容器定义。舰体/炮台对齐不能借美术适配改共享碰撞。后续真实素材的可见边界、安装点、效果包络和文字安全区要在同一支持窗口中叠图测量，而非只检验节点坐标。

## 交付顺序与退出条件

1. 评审整屏A/B、八目的地导航、代表模块观看焦点和场景/终端比例。父线程确认公开端口可供消费。
2. 每模块细稿补齐常态、选择、受限/草稿、成功反馈；反应炉补核心出口/设备端口，科研完成设备映射，舰装补完整槽位/比较。
3. 填正式资产记录draft；安装框、底座/管口和安全区定量审定后，才选择必要imagegen或Blender制作。可沿用的资源原位适配。
4. 导入正式前端，仅连现有模块公开端口；实际同版本宽窄屏、暂停/离页、错误/危险预览、完整编队和发展阶段按V0及相应V项验收。

本轮结束点为可见结构候选及设计清单，未推进资产制作和游戏代码实施。
