## 定向检查

Linux Chromium与Playwright、deviceScaleFactor=1、本地HTTP及仓库字体/图片，桌面1200×900、1440×960、1920×1080。[revision03-checks.json](evidence/revision03-checks.json)记录77/77项结果与HTML/CSS/JS哈希；不是游戏测试或设计通过结论。

- 三窗口下三个代表模块的页面/正文横向边界与图片加载。
- UI-01：候选明确显示两档效果、18K/100K保留工作量、预计余时及原研究62K保留。
- UI-04：选择层与当前身份、完整工作量条、机器及探针的矩形均不相交，1200/1440/1920分别检查；选择层本身无横向溢出。实看1440和1200整屏，不将矩形检查代替视觉评审。
- UI-02：自动开关/比例草稿与当前设置有区别；应用后设置更新，但实际铁铀投入保持；岗位状态与预算刷新时机独立可见；非法比例保留草稿。最小比例与真实拒绝原因仍由原模块提供，HTML格式检查不定义规则。
- UI-05：两个独立资源应用动作。铁125样例成功后铀仍为2，铀非法草稿被拒且保留；不会假装双资源原子提交。另交铁120成功/铀失败的固定代表截图。
- UI-03：成功后当前Lv.20，旧候选选择器、报价区和提交按钮均撤回；过往费用只在“已完成回执”内。没有下一次可提交预览。
- UI-06：中性/成功/错误/等待的类别、图形和样式分别检查。等待4.7秒后成功通知已收回，已完成回执仍在且已展开状态保持；不重绘整舱干扰输入/展开。
- 继承检查：反应炉单设备错误保持；科研暂停/完成；模态焦点与关闭恢复；无JS异常。
