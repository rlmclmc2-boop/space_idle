- 四路分配、百分比、增益集中在一个完整控制区，不再每台设备附独立操作面板。
- 总能量用该区的四色总分配条表达；条内仅显示已配/总量（示例100/100），删掉独立“容量100/已分配100/剩余0”三项栏。未分配部分用条的空余段表达，不能另叠三格读数。

## 本组 B01 实机制作候选

在基线 `c0ecf9b6a0be73eb1127f1a49e1e489fd47cad6a` 之上，整模块上方换成按批准图制作的[无字双态舱室](../../../../../assets/ui/reactor/b01/README.md)：巨型蓝色核心、四种有区别的设备、四根直连实体管路，以及同一张图中的下方金属控制台。Godot `reactor_stage.gd` 的材质按已生效 Owner 负载在闲置／工作光之间切换，并随真实 `game_time` 更新工作相位；零负载用闲置层。旧四角小读面、局部滑杆、脉冲叠层和原底台平铺均从运行场景移除，没有在旧结构上加一层遮盖。静态板不含烘焙控件、文字、数值和滑杆。公共顶栏、导航与战斗仍由原宿主负责。

下方同一金属控制台的总条按 Owner 四路已接纳比例画黄／蓝／橙／紫段，原生文字只显示 `已配 / 总容量`；余量是黑色空段，不另列容量／已配／剩余三格。首次候选 `84a58f6a` 的平涂条、细槽与小圆点经整体审核未通过；本次用[可复生的材质资产](../../../../../assets/ui/reactor/b01/README.md)装成有金属内沿和玻璃盖的总仪表、四行凹入滑轨、实心金属旋钮、百分比及倍率独立读面。动态色段与四路滑动值仍由 Owner 实际比例和原生 `HSlider` 驱动，资产中无烘焙进度或数值。四行透明材质图标用 `AtlasTexture` 安放在行名左侧。右区原生均分、`×1 → ×10 → MAX` 循环、独立升级和 Owner 精准报价保持原命令；费用沿共用铀资源图标显示，不再重复本次数量或插 `·`。未改变 Owner 的分配预览／接纳、报价、购买和局部刷新订阅。

运行 shader 将核心流体运动限定在蓝色玻璃内，金属束带与前沿保持原图遮挡；四根弯管各有从核心向对应设备推进的负载门控光包。武器炮口、盾面环、炼铁炉液及紫晶折射分别有独立频率和位置的工作变化。`reactor_stage.gd` 只在可见、未暂停且 `game_time` 推进时更新相位；真实零负载不产生工作光，隐藏页停止渲染。第1／9秒抽帧的平均颜色差（RGB每通道）：核心14.58，四管路5.38／11.58／8.66／5.60，四设备3.53／3.72／9.74／11.57，静态控制台0.81；这是可见变化的局部量测，不替代整体视觉判断。
