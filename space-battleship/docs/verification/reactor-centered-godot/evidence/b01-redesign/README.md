## 制作与接入边界

四台设备分别制作完整本体、底座、工作层和预制接口，不从旧整景裁图。`reactor_ports.json` 是 Blender 设备端口、实体管壳与 Godot 放置共用的源坐标契约，固定核心出口和设备入口的中心、轴线、半径、前后深度、源原点、裁图及缩放。可见端面必须套合，管材从会合面进入设备空心套筒；不能挪管或用盖片掩缝。

核心需读出能量产生、约束和沿当前有效管路输送。四机需分别读出武器蓄能与释放、盾面建立、炼铁熔流和晶体凝聚；静态金属/玻璃与局部工作材质分层，零有效量无工作光，正载方向与强度只读已接纳 Owner 负载。未开放设备、管路和控制行整套隐藏，暂停冻结，隐藏停局部刷新，重开读当前快照。文字及交互仍由 Godot 原生控件绘制。公共壳、装备、`main`、Owner 规则、支付、分配和升级逻辑均不由本组改动。

下部控制区的均分按钮应完整落在金色凹槽内；名称、滑条、百分比和增益组成同一路读控组，四路状态为完整行。整页原尺寸 1/2/3/4 路零载与正载、正常 1× 连续动态共同判断核心主次、信息读序、字形净空、真实端接、材质差异及各机工作因果。坐标正确、控件存在或动画在跑都不足以证明品质。

## 当前固定资产与观察

`a0ccc0de` 保留分体设备、共用端口、实体双层管路和玻璃核心。四机在同一舱室冷暖补光下受光，墙梁托座和落地脚座承担可见载荷；炉口已有独立金属料嘴、内凹承接槽、抬高耐火岸、带暗壳热缝与浅弧起伏的熔池及右侧排液口，槽内有受限于液面贴图的移动热斑。盾镜的格栅降亮，机体外的展开场壳现在由弯曲半透明曲面和外弧共同构成，零载隐藏；真实投射鞋和轴承前遮并在正载受入射冷光。七根晶柱的全体切面都进入受控工作层，生长前沿达到顶端后保持凝聚、切面反射继续运动。当前舱室、核心玻璃、静态夹具和控制台仍由运行引用，在替代闭包完成前不能删除。四机源码及基图/工作图都在 `assets/ui/reactor/b01/`。

本版已完成本地 Blender 4.3.2 炉、晶体与盾设备分层重渲、Godot 4.7.2 导入、入口解析及四路正载原尺寸 1× 约十秒作者预览。作者目视确认原橙色弯管已经改成料嘴落入熔池、右侧出液的空间关系，晶体由第 2 秒下部微光增长到第 5 秒中段、第 9 秒接近顶端，未再于第 5 秒归暗；盾外场有可见弧面而非孤立线条，零载不出场，但整页主次、场体体量及原尺寸偏小的炉口仍待判断。这些作者预览不代替本版八态整屏、正常 1× 完整动态固定证据或独立视觉判断。既有受控 1/2/3/4 可用模块只说明隔离显隐，不等于自然解锁。
