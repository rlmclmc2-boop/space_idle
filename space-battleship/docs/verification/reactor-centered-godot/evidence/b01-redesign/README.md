## 当前运行边界

批准 B01 构图保留中央核心、四身份设备和短实体接续，已改为[独立部件与生成源](../../../../../assets/ui/reactor/b01/README.md)：背景、核心球、三维机械约束转子/钳臂、四机体、四条有前后遮挡的管壳及各自弧长内腔；真实已接纳负载驱动核心离散事件、管内向设备输送及设备专属局部工作。撤掉像按钮的中央圆 lens 样片，不回整张前景贴图+通用水波。原生 `Panel/HSlider/Button/Label` 不烘焙在美术图；少态左承托板全高，启用行按数量居中，无未开放空槽；升级按钮扩宽为 89px 以保 glyph 净空。动态仍需原视觉审核按整页/全片判断物理体量、主次、接口和跨页材料，局部修正不等于验收。

## 性能：上次已报 → 本次

上次实际向用户报告的**旧 packed 架构**在公共 `051cbd0d` + B01 `6d0ee146`、Godot4.7.2/Xorg/Mesa llvmpipe/OpenGL3/1440×900、正常1×、四路25%、不录屏的同实例6秒正序为 `31.29→32.33` 与 `31.61→32.23 fps`。本次分件源和控制材料已变，不能跨版本相减。本版 `3b2c31e2` 同实例6秒缓存开关对照条件相同（战场自主推进，不是完全同战斗帧）：

| 对照 | 原静态分件重绘 fps / mean / p50 / p95 ms | 同视口静态缓存 fps / mean / p50 / p95 ms |
|---|---|---|
| A1→B1 | 34.04 / 29.38 / 28.341 / 34.372 | 33.98 / 29.43 / 28.415 / 34.585 |
| A2→B2 | 32.33 / 30.93 / 29.758 / 35.878 | 34.00 / 29.41 / 28.394 / 34.535 |

产品缓存只在可用集合变化时于运行时一次合成背景/启用管壳/控制台，再放回原舞台视口第一层；核心、管流、设备动画、Owner/原生 UI 与每帧相位均保留。同相位全屏 RGB 零差；1路/4路舞台开关也零差。第二稳态短窗 Canvas draw calls `27→22`；首冷窗和 FPS 收益波动，不能声称持续增益或已消除用户约10fps损失。此前外层双视口原型虽然约+3fps，但有126620像素边缘差，已淘汰。未取得用户目标机器、renderer/分辨率及同场 profile；**目标硬件性能验收未成立**。新稿不可援引旧 packed 的收益当本版指标，细节与原始日志均在上述归档包。
