## 制作与接入边界

四台设备分别制作完整本体、底座、工作层和预制接口，不从旧整景裁图。`reactor_ports.json` 是 Blender 设备端口、实体管壳与 Godot 放置共用的源坐标契约，固定核心出口和设备入口的中心、轴线、半径、前后深度、源原点、裁图及缩放。可见端面必须套合，管材从会合面进入设备空心套筒；不能挪管或用盖片掩缝。

核心需读出能量产生、约束和沿当前有效管路输送。四机需分别读出武器蓄能与释放、盾面建立、炼铁熔流和晶体凝聚；静态金属/玻璃与局部工作材质分层，零有效量无工作光，正载方向与强度只读已接纳 Owner 负载。未开放设备、管路和控制行整套隐藏，暂停冻结，隐藏停局部刷新，重开读当前快照。文字及交互仍由 Godot 原生控件绘制。公共壳、装备、`main`、Owner 规则、支付、分配和升级逻辑均不由本组改动。

下部控制区的均分按钮应完整落在金色凹槽内；名称、滑条、百分比和增益组成同一路读控组，四路状态为完整行。整页原尺寸 1/2/3/4 路零载与正载、正常 1× 连续动态共同判断核心主次、信息读序、字形净空、真实端接、材质差异及各机工作因果。坐标正确、控件存在或动画在跑都不足以证明品质。

## 当前固定资产与观察

`edf1b016` 保留分体设备、共用端口、实体双层管路和玻璃核心。四机钢、银、铜大面有冷暖反射，铸铁承重面保持暗部，墙梁托座和落地脚座承担可见载荷；炉口有独立金属料嘴、加宽内凹承接槽、抬高耐火岸、带暗壳热缝与浅弧起伏的加深椭圆熔池及短右侧排液口，料嘴与熔池之间有实体落流。炉液工作层的热锋从左向右移动，热度随相位改变。盾镜的格栅降亮，机体外的展开场壳由加宽的弯曲半透明曲面和外弧共同构成，零载隐藏；真实投射鞋和轴承前遮并在正载受入射冷光。七根晶柱的全体切面都进入受控工作层，生长前沿达到顶端后保持凝聚、切面反射继续运动。当前舱室、核心玻璃、静态夹具和控制台仍由运行引用，在替代闭包完成前不能删除。四机源码及基图/工作图都在 `assets/ui/reactor/b01/`。

现行 `edf1b016` 同版作者证据含受控 1/2/3/4 路零载与正载整屏、四路正载正常 1× 250 帧录屏、第 2/3/4/5/9 秒整屏及混合零载、盾 1% 低正载与隐藏重开整屏。作者逐张原尺寸查看八态与边界图，并看完视频的十张顺序接触表和炉体相位局部：落流与横向明暗变化可见，但原尺寸整页仍偏向常亮橙色熔体，料嘴到池再出液的连续方向不够清楚。盾外场正载展开、归零收起；晶体从下部微光增长到接近顶端。盾场体量及四机与舱室同质程度尚待独立判断。受控 1/2/3/4 可用模块只说明隔离显隐，不等于自然解锁。

## 尚未完成

当前明确的制作缺口是炉内热流在原尺寸尚未清楚读出料嘴到承接床再出液的方向；需从实体造型、熔池亮暗分区和工作层一起改善。仍需独立核定外伸盾壳是否真正读成受约束的空间场、四设备大面冷暖反射是否与核心/舱室相称；不能以光纹存在或控制参数正确替代整页品质。同版归档八态、录屏、混合零/正、极低正载与隐藏重开均为 `edf1b016` 的作者证据，不记录独立通过。自然解锁、最终公共组合和目标硬件性能亦未在本版验收。

制作仅用本地 Blender 4.3.2、Godot 4.7.2、Python/ImageMagick；不使用付费账户、云积分或试用次数。历史工具比较和退役资产证据保留在 Git archive，当前制作不从它们恢复方向。
