## 制作与接入边界

四台设备分别制作完整本体、底座、工作层和预制接口，不从旧整景裁图。`reactor_ports.json` 是 Blender 设备端口、实体管壳与 Godot 放置共用的源坐标契约，固定核心出口和设备入口的中心、轴线、半径、前后深度、源原点、裁图及缩放。可见端面必须套合，管材从会合面进入设备空心套筒；不能挪管或用盖片掩缝。

核心需读出能量产生、约束和沿当前有效管路输送。四机需分别读出武器蓄能与释放、盾面建立、炼铁熔流和晶体凝聚；静态金属/玻璃与局部工作材质分层，零有效量无工作光，正载方向与强度只读已接纳 Owner 负载。未开放设备、管路和控制行整套隐藏，暂停冻结，隐藏停局部刷新，重开读当前快照。文字及交互仍由 Godot 原生控件绘制。公共壳、装备、`main`、Owner 规则、支付、分配和升级逻辑均不由本组改动。

下部控制区的均分按钮应完整落在金色凹槽内；名称、滑条、百分比和增益组成同一路读控组，四路状态为完整行。整页原尺寸 1/2/3/4 路零载与正载、正常 1× 连续动态共同判断核心主次、信息读序、字形净空、真实端接、材质差异及各机工作因果。坐标正确、控件存在或动画在跑都不足以证明品质。
