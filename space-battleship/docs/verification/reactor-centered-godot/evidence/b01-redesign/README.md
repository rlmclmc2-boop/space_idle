## 制作与接入边界

四台设备分别制作完整本体、底座、工作层和预制接口，不从旧整景裁图。`reactor_ports.json` 是 Blender 设备端口、实体管壳与 Godot 放置共用的源坐标契约，固定核心出口和设备入口的中心、轴线、半径、前后深度、源原点、裁图及缩放。可见端面必须套合，管材从会合面进入设备空心套筒；不能挪管或用盖片掩缝。

核心需读出能量产生、约束和沿当前有效管路输送。四机需分别读出武器蓄能与释放、盾面建立、炼铁熔流和晶体凝聚；静态金属/玻璃与局部工作材质分层，零有效量无工作光，正载方向与强度只读已接纳 Owner 负载。未开放设备、管路和控制行整套隐藏，暂停冻结，隐藏停局部刷新，重开读当前快照。文字及交互仍由 Godot 原生控件绘制。公共壳、装备、`main`、Owner 规则、支付、分配和升级逻辑均不由本组改动。

下部控制区的均分按钮应完整落在金色凹槽内；名称、滑条、百分比和增益组成同一路读控组，四路状态为完整行。整页原尺寸 1/2/3/4 路零载与正载、正常 1× 连续动态共同判断核心主次、信息读序、字形净空、真实端接、材质差异及各机工作因果。坐标正确、控件存在或动画在跑都不足以证明品质。

## 当前固定资产与观察

`f7d3d055` 保留分体设备、共用端口、实体双层管路和玻璃核心。四机钢、银、铜大面有冷暖反射，铸铁承重面保持暗部，墙梁托座和落地脚座承担可见载荷；炉口有独立金属料嘴、加宽内凹承接槽、抬高耐火岸、带暗壳热缝与浅弧起伏的加深椭圆熔池及短右侧排液口，料嘴与熔池之间有实体落流。炉液工作层的热锋从左向右移动，热度随相位改变。盾镜的格栅降亮，机体外的展开场壳由加宽的弯曲半透明曲面和外弧共同构成，零载隐藏；真实投射鞋和轴承前遮并在正载受入射冷光。七根晶柱的全体切面都进入受控工作层，生长前沿达到顶端后保持凝聚、切面反射继续运动。当前舱室、核心玻璃、静态夹具和控制台仍由运行引用，在替代闭包完成前不能删除。四机源码及基图/工作图都在 `assets/ui/reactor/b01/`。 本次用同一路径顶点生成槽底、侧壁与液面，从池右岸经真实侧墙缺口下降接入下方排液管；移除原先不相连的短溢流和封闭喉管。液面工作光按下降路径推进，并由渲染液面alpha限制。

本次同版证据仅覆盖四路均分25%的工作与真零整屏、2/3/4/5/9秒原尺寸图和10秒连续视频，受控状态只用于表现检查。驱动逐帧清理既有引导避免遮挡；没有通关或解锁业务验证。作者看过全部250帧炉区与整页时间样本：热区沿池面进入下降槽，再到排液端，实体侧壁始终包覆液面。未改其他设备、端口与布局；本包不扩大为全部少路数、交互或整页品质通过。
