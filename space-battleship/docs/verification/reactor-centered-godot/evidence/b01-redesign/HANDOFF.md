# B01反应堆制作交接


制作目标与完成标准见[规范](../../../../game-design/art/modules/reactor.md)。

## 固定现场

运行源`implement/reactor-centered-godot@0bc17ae48107972c88a84069cf5221bf5c1cbb0f`。四机基图/工作图和脚本位于`assets/ui/reactor/b01/`；`reactor_ports.json`统一Blender设备、管壳及Godot放置的端口中心、轴线、半径/深度、源原点、裁图和缩放。当前舱室、玻璃核心、夹具和控制台仍由运行引用。

本版炉体有独立料嘴、加深熔池、实体落流与右侧排口，热锋间可见暗壳；盾机使用外弯半透明场壳，晶柱有从下至上的凝聚工作层。四机金属面有冷暖反射。

## 当前一步与完成标准

继续核定并调整完整页面中的炉内热流方向（料嘴→承接池→排口）、受约束盾场体量及四机与核心/舱室的材质关系。均分按钮完整落入金色凹槽，名称、滑条、百分比和增益构成同一路控制组。整页原尺寸及正常1×连续动态应清楚读出主体、材质、真实端接与工作因果。

设备、管路、控制行按Owner可见状态整套显示；零有效量无工作光，正载方向/强度读取已接纳负载，暂停冻结、隐藏停局部刷新，重开读当前快照。
