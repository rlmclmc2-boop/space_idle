# 反应堆模块安装现状（供共享宿主 H2 协调）

本页回应`design/shared-host-shell@cfaa9635`的[模块安装交接](https://github.com/rlmclmc2-boop/space_idle/blob/cfaa9635/space-battleship/docs/ui-redesign-plan/shared-host-shell/module-installation.md)，只记录当前反应堆所有者的安装事实，不批准65px共享带或新的最小尺寸。代码与整屏证据随本分支本次固定提交，入口见[验证记录](README.md)。

| 项目 | 当前事实与边界 |
|---|---|
| 内容根与坐标 | `src/ui/reactor_scene.gd`是左侧原点(0,0)的`Control`，固定`size/custom_minimum_size=808×900`且`clip_contents=true`；内部`SubViewport`也是808×900。`src/ui/reactor_stage.gd`对1024×1536源板等比0.6、原点(96.8,20)，机器与工作效果沿同一投影；外围纹理由Stage单独绘制。宿主`src/main.gd`将Control加在左模块CanvasLayer，通过`feature:reactor`开放并控制显隐。当前右侧战场由宿主负责。 |
| 顶部当前占用 | Stage在本地`y=0..65`画象牙标题带；局部模块名`(26,18,170,28)`和等级`(612,23,170,28)`在带内。等级是反应堆局部读数，不能被全局资源或导航覆盖。非模态状态文字位于`(278,91,252,68)`。当前宿主导航按钮`y=52..82`（本分支现有位置410/498/586，80×30）压到本地标题带下沿及上方机器空间；导航属于宿主，不应在M3内部复制。上方设备图从标题带附近起，不能直接裁掉`y=65`以下或整体下移而不复核四机器/下沿。 |
| 全局与局部 | 品牌、钱包/资源栏、模块导航可由共享宿主提供；反应堆需要保留局部等级、四设备效果/供能短读数、四直接滑杆、容量/已配/剩余、购级/均分/确认/还原和局部结果提示。当前短读数18px与16px，滑杆132×18；底部主控面`y=809..886`，最右按钮`x=702..755`，与主控面右缘`x=768`留13px。具体金额和状态仍读已接入的所有者出口。 |
| 可读尺寸与缺证 | 当前只有808×900内容根、1440×900整屏的真实Godot截图与局部操作证据；这些图可供当前尺寸审看，尚无更窄/更矮安装的最小字号、点击净空或无裁切验收。不能把`custom_minimum_size`或视觉近似当成最小可读尺寸通过；机器、短读数、滑杆和主控须一并检查，不得缩放/裁切机器补宿主空隙。 |
| 弹层、焦点、显隐 | 本Control没有自有模态弹层；局部提示是鼠标忽略的非模态Label，主界面的引导弹层由宿主管理。滑杆获得焦点时选择对应设备，按钮有焦点样式；页面隐藏后场景停止`_process`及SubViewport刷新，显示时失效重读当前快照并重置视觉时钟。宿主负责模块切换、引导弹层输入与遮挡顺序。目前只有`visibility_changed`驱动本地恢复，没有已确认的共享宿主最小呈现/焦点交还通知；这仍是协调缺口。 |

H2原约束为“保留808×900、仅替换重复顶部”，并不等于接受65px统一顶带。反应堆当前`0..65`含局部等级，且导航按钮延伸至`y82`；简单替换整条65px会丢失等级或覆盖上方设备，整体下移会挤压`y809..886`主控。宿主需明确等级安置、导航与机器顶端的净空、显隐/焦点回交通知，再与本模块共同验收整屏。本组不改`main.gd`，当前说明不推断其他尺寸可装入。
