# 反应堆模块安装现状（供共享宿主 H2 协调）

本页回应`design/shared-host-shell@cfaa9635`的[模块安装交接](https://github.com/rlmclmc2-boop/space_idle/blob/cfaa9635/space-battleship/docs/ui-redesign-plan/shared-host-shell/module-installation.md)，记录当前反应堆所有者的安装事实及可调整边界，不批准65px共享带或新的最小尺寸。代码与整屏证据随本分支固定提交，入口见[验证记录](README.md)。用户已否决在左右原黑带换上没有信息要素的铁框架；当前两侧程序结构带不能作为解决方案或视觉通过依据。

| 项目 | 当前事实与边界 |
|---|---|
| 内容根与坐标 | `src/ui/reactor_scene.gd`是左侧原点(0,0)的`Control`，固定`size/custom_minimum_size=808×900`且`clip_contents=true`；内部`SubViewport`也是808×900。`src/ui/reactor_stage.gd`对1024×1536源板等比0.6、原点(96.8,20)，机器与工作效果沿同一投影；源板横向占`x=96.8..711.2`，两侧各约97px目前只由Stage画无操作信息的结构纹理。宿主`src/main.gd`将Control加在左模块CanvasLayer，通过`feature:reactor`开放并控制显隐。当前右侧战场由宿主负责。 |
| 顶部当前占用 | Stage在本地`y=0..65`画象牙标题带；局部模块名`(26,18,170,28)`和等级`(612,23,170,28)`在带内。等级是反应堆局部读数，不能被全局资源或导航覆盖。非模态状态文字位于`(278,91,252,68)`。当前宿主导航按钮`y=52..82`（本分支现有位置410/498/586，80×30）压到本地标题带下沿及上方机器空间；导航属于宿主，不应在M3内部复制。上方设备图从标题带附近起，不能直接裁掉`y=65`以下或整体下移而不复核四机器/下沿。 |
| 全局与局部 | 品牌、钱包/资源栏、模块导航可由共享宿主提供；反应堆需要保留局部等级、四设备效果/供能短读数、四直接滑杆、容量/已配/剩余、购级/均分/确认/还原和局部结果提示。当前短读数18px与16px，滑杆132×18；底部主控面`y=809..886`，最右按钮`x=702..755`，与主控面右缘`x=768`留13px。具体金额和状态仍读已接入的所有者出口。 |

H2原约束为“保留808×900、仅替换重复顶部”，并不等于接受65px统一顶带。反应堆当前`0..65`含局部等级，且导航按钮延伸至`y82`；简单替换整条65px会丢失等级或覆盖上方设备，整体下移会挤压`y809..886`主控。宿主需明确等级安置、导航与机器顶端的净空、显隐/焦点回交通知，再与本模块共同验收整屏。本组不改`main.gd`，当前说明不推断其他尺寸可装入。

## 侧边无效区域与内部重排边界

现有`x=0..96.8`与`711.2..808`不能靠补纹理、纯装饰边框或拉伸1024×1536源图来消化。模块所有者可在整体界面给定的真实可见内容框内重新设计三/四设备两张同源安装图，并同步调整Stage的五个机器锚点、四条短接、各自滤光/工作层、读数托架和滑杆；核心与设备比例、机壳外缘、设备间距、四路读数位置以及下沿主控分区都可为有效信息和操作净空重新排布。需让机械体积、供能路径或直接可用控件实际占据新增空间，不能把空边改名为框架。当前`scale=0.6`、`origin=(96.8,20)`只是本版图与层的共同投影参数，不是已批准的最终宽度或不可改的绝对坐标。

重排仍须保持`59dd464d`已定的中央核心、武器左上/防御右上/炼铁左下/凝聚右下、四路短接各自直接接入共同装配体；三设备版须闭合右下支路并隐藏整套凝聚机器/读数。每版底图、四路接头、玻璃球/设备工作层、局部滤光、文字和滑杆必须使用同一套校准后的锚点，避免再次出现底壳与前景错位。四路直接滑杆、实际有效供能和必要效果、核心等级及容量/已配/剩余与整组操作不能为了铺满边缘而裁掉或缩成难读符号。已接入的Reactor/Economy展示与提交边界继续保留。

请整体界面组先确定反应堆实际获得的**可见且可交互内容矩形**：左/右/上/下坐标、全局导航及资源栏的覆盖范围、左模块与右战场的分界和边距、局部等级与状态提示的安置、底部操作是否有共享占位。若仍以808×900为外框，也须明确其中可由机器和控件使用的横向宽度，不能把两侧约97px认作预留装饰带；若外框或顶部占用改变，本模块据此成套改图和锚点后再做真实Godot整屏及鼠标净空复核。当前证据仅覆盖既有1440×900/808×900，尚未实测任何新矩形或最小尺寸。共享宿主的`main.gd`修改及最终模块边界由整体界面组负责。
