# 按决策分区的装备工作台提案（未实施）

用户新增判断是“少内容占大量空间，完整信息又拥挤”。前一份236/258/266px分析只说明旧分节结构的小改上限，**不再作为推荐终点**。本提案重组现有信息与承载方式，属于评估授权；真实运行源码仍d034de07，当前实图仍266/288px，没有制作下述166/188px版本。

## 推荐组织：常用区常驻，一个展开区按需打开

底部仍只有一件工作台壳。常用区承载当前稳定槽位的对象/等级、部件图、当前→购级后主值、当前模式完整费用、可购数/失败原因和数量→唯一购买键。右半区域用于费用和购买，不再常年为四个候选和比较保留空地。

对象条保留现装名称/等级；右侧两个明确入口“更换”“详情”。点更换打开同一工作台内的选择区，点详情打开详情区；二者占同一可伸展位置、最多一个打开，不再叠第二弹窗。既有舰体、武器和侧槽索引仍是识别与选择主体，工作台不接管舰船尺寸或布局。展开区位于常用内容上方、使原壳向上增高，常用属性/报价/两键靠底锚布局，打开选择时购买组不会被推离原位置。

- **常用：**默认不展开；现装升级需要的主值/费用/当前数量/可购或失败状态始终在同一视野。没有右半空白候选工位。
- **更换：**左侧一次展示已有目录选项（武器4项，68px点击宽、8px列距，共296px）；右侧只在异物时展示现装/所选主值与周期/类型和独立安装键。同物没有重复比较/安装占位。候选数量少时保留真实空位规则，不添加假装备或教学来填空。
- **详情：**同一展开区显示现装、购级后及所选候选的已有完整比较字段；详情内容超高只滚动该详情区。常用费用和两键不进入滚动，也不靠tooltip才能知道是否付得起。
- **返回：**展开区有可达的“收起”按钮，点击原入口也收起；收起后焦点回到发起入口。选择未安装时不提交、不假冒现装，现装标题保持，入口明确标“更换 · 候选名称（未安装）”，保留当前候选供再次打开。详情与选择之间切换保留同一槽/候选/数量和各自滚动位置；切槽仍按现有select_slot把候选重置为该槽现装，不跨槽带入旧候选。

常用对象保持“现装升级”，选择区保持“候选换装”，安装不插入数量/购买两键之间。更换展开不改变购买报价对象；当前Owner的upgrade本来就针对现装，不能让候选图像暗示购买会给候选升级。

## 具体尺寸预算（逻辑像素，待实施验证）

按当前808×900模块、776px工作台宽度、底锚896估算。左右常用内容分别沿用现有400px属性跨度与308px费用跨度，中间28px；主数值继续27px、费用金额17px、标签12/13px、操作16px，数量键96px，购买键200px，两键间12px。308px费用宽与当前报价相同，不为放入右侧而缩金额宽。

对象条40px，至主体8px；属性保留现有80px高度（包括长值上下两行和部件图）。购买组为“当前模式/可购数20px → 每资源22px完整费用 → 8px → 36px两键”；底部保留32px壳面。常态高度公式为 `40+8+max(80,20+22×费用行数+8+36)+32`，而不是给所有状态统一锁死一个矮窗。

| 状态 | 预算高 | 顶部（底锚896） | 当前同类高 | 原则 |
|---|---:|---:|---:|---|
| 常用、单费 | 166 | 730 | 266 | 只现装事实和当前购买，不为未打开候选留空 |
| 常用、双费 | 188 | 708 | 288 | 两费用逐行完整显示，不折成一句 |
| 常用、三费 | 210 | 686 | 无本轮真实生产例 | 仅高度公式，不造第三费用或图 |
| 更换展开、单费 | 270 | 626 | 同物266/异物288 | 在需要选择时加104px，主动换装期间允许使用更多空间 |
| 更换展开、双费 | 292 | 604 | 288 | 内容多就增高，保留独立安装/购买，不强塞回166px |
| 详情展开、单/双费 | 326/348 | 570/548 | 当前没有完整字段详情位 | 增加160px详情位；内容更多滚动详情，不滚费用/执行 |

104px选择预算由现有88px候选和两侧8px留白组成；右侧比较43px+间隔8px+36px安装=87px，能与88px候选并列。选择区可用宽736px：候选296px、间隔24px、比较/安装416px。不能把更换入口误当安装；首次点击只展开，不写Owner。选择与详情互斥展开，所以不是270+160同时堆高。

**动态增高例外是方案的一部分：**长金额若原字级无法在308px行内完整显示，该资源行改为名称/金额上下两行44px，每处额外22px；失败原因保留实际文字，按22/44px必要行增高；MAX可购数用Owner quote.count放在20px模式/可购行，执行键可只写“购买”，数量不挤在200px执行键内。对象名、长等级、冷却和入口装不下时对象条增加一行22px，不能省略现装/候选身份或隐藏冷却。因而166/188是普通状态预算，并非对极端文本的已验证固定上限。

主读数仍用已有80px长值路径；费用不因打开详情而消失。第三费用、新资源资产或未知第五候选没有真实制作/运行证据。本轮没有新三费fixture、全舰组合或长金额测试。

## 完整详情用什么数据，不能承诺什么

已只读核对本分支现有src/systems/equipment.gd的slot_facts、_comparison_value、slot_comparison和Session.equipment_comparison，不向Owner索取新字段：

| 展示 | 已有来源 | 可执行呈现 |
|---|---|---|
| 槽/现装/购买等级/有效等级/休眠/换装冷却 | slot_facts和comparison | 常用对象与必要限制；详情列出已有有效等级 |
| 当前、购级后、所选主值 | current/upgrade/candidate.primary | Owner给出的同口径文本三列对照；未知/空槽有对应状态，不补0 |
| 周期、导弹齐射数、长激光充能 | properties.interval_seconds/salvo_count/charge_seconds | 只出现实际存在字段；常用主值不被这些次级项撑开 |
| 护盾恢复率/恢复延迟、类型 | properties.recovery_rate/recovery_delay_seconds/damage_type | 详情逐项；类型名称依据02-combat既有0中性/1能量/2物理规则，不造新抗性或战斗值 |
| 当前模式、可购数、逐资源费用与不足原因 | quote.count/costs、affordable/payment_reason | 常用区始终可见，不藏到详情 |
| 候选准入/冷却/类别拒绝 | switch_admission、slot cooldown | 选择区安装状态及常用更换入口必要提示，沿Owner原因 |

“完整”仅指现有比较口已经发布的这些字段。primary当前是格式化字符串，不能从中反推原始精确值、所有派生公式、DPS或战场最终伤害；没有端口就不写进详情承诺。无新业务字段、无UI重算成长/价格/MAX/原生数值，也不恢复记录/最近结果/历史回执列表。

## 状态、返回与精准刷新

未来实现只需展示层的展开枚举（常用/更换/详情）、两个展开位置和入口焦点引用；沿用_selected/_candidate/_quantity/_maximum。它们是本地视图状态，不能成为Owner字段或通用新路由。

打开/收起纯展示区不发购买/支付/native通知；候选变化仍走现有comparison_dirty，数量变化仍只重读同槽报价，槽等级只刷新相关ID及当前比较，refit/availability仍必要结构失效。详情打开时复用该次已取的comparison，不能每帧重查全部装备。余额变了，即使详情在滚动，常用费用和执行状态也更新；详情滚动位置和候选不因此丢失。

成功安装后沿既有loadout/refit更新现装与候选显示，不额外制造回执系统；打开的选择区保持可辨当前状态，用户可主动收起。模块隐藏/宿主切换需撤走展开区焦点，保留必要本地选择；现有独占Batch仍由prepare_host_hide/has_exclusive_ui处理，普通内联展开不冒充全局独占。仅详情/选择自己的滚动区接滚轮，不截右战场或G/Space；不新增全局快捷键。
