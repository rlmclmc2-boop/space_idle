# R20 四设施材质协调图证

源码为 `feat/planet-single-side-ui@be19dfa6`。Godot 4.7.2 OpenGL/llvmpipe 在 2048×768 SubViewport 取原图。六类变体是脚本配置四设施 built 的默认模拟姿态；`side25-1` 是站单建 25°，`side25-4`／`side70-4` 是完整态 25°／70°。角度及 built 状态均由脚本设置，不代表自然施工、整圈或自然转动。

四设施的主承力甲色统一压低明度，炉、工坊、船坞的赭色结构面降低饱和度，使新增炉拱、开口和环的甲板材质更接近。已看默认与两个侧角原图；变化有限，整体主剪影和概念材质协调仍未通过。`SHA256SUMS` 记录所有原图、取图脚本、导入及取图日志的字节摘要。
