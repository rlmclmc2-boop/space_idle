源码为 `feat/planet-single-side-ui@6823e761`。Godot 4.7.2 OpenGL/llvmpipe 以 2048×768 SubViewport 取六类完整态默认模拟姿态、站单建 25° 和完整态 25°／70° 原图。设施根部在既有 owned 环截面中下沉 0.08／0.09 个模型单位；站低位通道、工坊工作口、炉双料斗及船坞开口仍在侧角可见。此图只作当前形体候选，不代表自然施工、自然转动或整圈。

原图显示根部悬置感减轻，但设施依然偏独立块体，整体与 8136 概念不通过。`SHA256SUMS` 包含原图、脚本和取图日志的字节摘要。
