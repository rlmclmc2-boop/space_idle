# R3 球面经度亮线：shader 修复候选，待根审

根审在旧 `4368ca57` 的短片约10秒、完整采样第165帧，指出星面约 `x414` 有从上到下断续的黄亮线。固定 [旧原始帧](before-4368-frame-0165.jpg) 的球面相位为 `0.535568`；该列处投影经度约为 `uv.x + phase.x ≈ 1.0`，与水平纹理重复边界吻合。旧 `scripts/rotating_planet.gdshader::map_sample` 并非直接读取贴图边缘，而是把末端压到 `u=0.96` 并在接缝前后混合；原图的 `u≈0.96` 恰有多枚高亮岛屿，遂在经度缝上形成竖排亮点。只读像素核对原始 `1774×887` 地表图：左右最外列的 RGB 平均绝对差约 `(2.4,2.5,2.3)`，左列与 96% 列约 `(52.0,40.4,16.9)`。云图与当前其余球面图的最外列也接近连续。这里仅分析原字节，没有加工或改写 imagegen 原图。

修订只在 shader 的 `map_sample` 去掉 `0.96` 重映射/混合，让已声明 `repeat_enable` 的采样器直接跨原始贴图左右边缘插值。没有修改纹理、地图、球体时间、业务/UI、main 或共享宿主。shader 为共用球面代码；当前只对第一星球旧接缝做了真实运行回归，其余星体未作画面复验。

使用同一官方 Godot `4.7.2.stable.official.ed1daf0bf`、项目 native/config、原星球夹具与正常 Session 推进重新运行；没有引擎帧帽或强推时钟。[修后驱动](after-driver.gd.txt)、[运行日志](after-runtime.txt)、[入口脚本检查](after-main-check.txt)均归档，脚本检查和运行退出0。整段定向运行200个样本、107.488秒墙钟、实际累计球面 `0.581304` 圈，捕帧累计14.660秒；这不是新完整周期。逐样本相位/时钟见 [原始轨迹](after-motion-poses.jsonl)和[摘要](after-motion-summary.json)。

[修后第165帧原始JPEG](after-frame-0165.jpg) 的球面相位 `0.535063`，与旧帧仅差 `0.000505` 圈；周围未加工的 [第162帧PNG](after-key-0162.png)（相位 `0.526607`）、[第171帧PNG](after-key-0171.png)（相位约 `0.552`）供看接缝转入转出。[连续20秒视频](after-seam-crossing-150-189.mp4)直接用该运行第150–189张原始JPEG按2fps编码，覆盖实际相位 `0.491047–0.603992` 圈、墙钟 `82.15–102.45` 秒；播放器20秒不等于引擎时间。修后关键位置不再有旧帧的竖向黄亮断线，但画面判断仍交根审。所有归档字节见 [SHA256](sha256.json)。

旧 `4368ca57` 的1.05圈视频仍是历史运动证据，不能证明新 shader 的完整圈或其它星体；原视觉限定结论因新发现的接缝需按本候选重新审。未测高帧性能、用户GPU或整M7。
