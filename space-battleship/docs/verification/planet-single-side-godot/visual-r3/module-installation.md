## 当前尺寸与尚缺的最小尺寸证据

当前真实运行证据仅确认 `1440×900` 客户区、左侧 `808×900`：R3 4.7.2 原图和完整相位周期见 [视觉记录](README.md)，征服详情的同版原图见上。`custom_minimum_size=760×740` 是源码声明，**不是经实屏确认的可读最小尺寸**。本模块 Theme 默认字号17、品牌24、菜单17；当前控制按钮高44/42、宿主导航高30。没有单独测量更小安装尺寸、必要最小字号或最小点击框，也没有证明将 808×900 缩放/裁切仍可读。当前不应裁去首两行操作、局部抽屉、`y820..890` 命令反馈或球面观看区来声称安装完成；尤其抽屉高度随设施/征服/人员内容变化，不能用默认态一张图代替展开态边界。

## 弹层、焦点与显隐责任

设施/探索/人员入口由星球 Control 切换一个非模态左侧抽屉；开合不暂停 Session，也不改变星球相位。星球、设施、成员和派遣选择使用本模块 `OptionButton` 的 `PopupMenu`。现有 4.7.2 OS 鼠标记录给出当次弹层矩形：星球 `(494,156,176×70)`、设施 `(36,419,248×128)`、成员 `(36,308,319×592)`、派遣 `(36,505,319×70)`；这些只是该夹具选项数及当前尺寸的实际记录，不是各状态统一包络，见 [操作记录](evidence/preview-operations.json)。弹层行选择、局部抽屉关闭和当前星球绑定归本模块；重铸按钮只发当前星球 ID，实际页面跳转、重铸预览及其焦点归宿主。

宿主以 `scene.visible` 控制模块显隐，星球面板隐藏时停止自身可见帧更新，重现后按脏标记刷新；真实 Session 替换由宿主释放旧页面并新建页面，旧 Planet 征服通知已在退出树时断开。本模块目前**没有**在宿主隐藏前统一关闭已打开的 `PopupMenu`、转移键盘焦点或向共享顶层报告弹层占用的专用呈现通知；这几项在 H2 的焦点/覆盖方案中须由整体组与模块约定并取证，不能从已有 OS 点击成功推出已实现。宿主自己的引导框与保存/重铸弹层及其焦点不属于星球抽屉。

## 对 H2 的明确冲突

H2 提出保留 `808×900` 内容根、仅替换重复顶部；当前星球顶部是 `90px`，共享导航也在 `y52..82`，模块身份的绘制基线 `y74` 落在拟议 `65px` 带下方。直接覆盖或裁到 `y65` 会遮掉当前标题，且未说明钱包、导航与首行操作之间的分界。若宿主接管全局品牌/钱包/导航，仍需给“星球探索”身份及 `y112..264` 当前星球操作保留可见和可点击空间，并处理局部菜单/抽屉与宿主层级。当前不能以 H2 排版图推断这处冲突已消除，也不把本组的 `760×740` 声明当作宿主新安装尺寸批准。
