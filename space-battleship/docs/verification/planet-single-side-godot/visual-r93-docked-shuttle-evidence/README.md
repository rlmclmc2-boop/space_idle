# R93 船坞停靠艇主轮廓图证

源码及模型为 `feat/planet-single-side-ui@88de9c5f`。Blender 重建船坞 `.blend` 与运行 `.glb`；Godot 4.7.2 OpenGL/llvmpipe、2048×768 六类默认完整态、默认相位四段累积、25° 与 70° 站单建及完整态。脚本设置 owned 建造阶段和角度，图证不代表自然建造、自然转动、整圈或整体通过。

停靠艇沿原泊位发射轨前移0.29、抬高0.09，默认/25°/70°船首和蓝色座舱都越过泊位前缘，艇尾仍在双门架内。四设施共同主剪影、材质协调及六类整体仍未通过。`SHA256SUMS` 覆盖14张原图、4份脚本、6份构建／导入／取图日志。
