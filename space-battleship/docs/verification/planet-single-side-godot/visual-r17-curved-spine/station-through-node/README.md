# 站体贯通节点局部候选

`auto_explore.glb` 由 `art_sources/planet_facilities_v5/build_station_node.py` 独立生成。模型沿环道切线开两端通道；左右压力墙包住本设施的真实环段，上层指挥舱由门架承载，旋转观测环和两片短翼仍使用原有运动端口。运行时不再使用相机朝向的站体插画。环段的 built 归属、球后遮挡和独立公转未改。

同版 Godot 4.7.2、2048×768 原尺寸取图：`full-phase-0.png`、`full-phase-70.png` 是四设施完整态两角；`station-only-phase-0.png` 是只有站体建造时的自由端。取图仅覆盖当前站体、环端可见形体；没有自然施工、整圈或整体视觉通过结论。整体仍需炉体同等级完整资产、四节点材质和密度统一、环下暗层及自由端进一步封装。
