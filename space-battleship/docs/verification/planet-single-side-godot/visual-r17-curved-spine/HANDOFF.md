Godot 4.7.2 同源真实整页、四阶段、90帧/6秒正常速度视频及等球径对照图见 `archive/planet-resume-20261101@cdf3260cfa2fc3eeb9b2aa245681de1d048da70c:v49-shadow-light-aa8ab67e/`。有无阴影对照确认碎颗粒来自船翼浅层壳体自阴影，现只关闭这几片的投影，其他建筑真实阴影保留；制造工位、船坞入口与琥珀信号灯的暖光增强，现有竖向装甲下缘形成更深暗部。开放布局、四设施体量、细环与电车保持。四段独立归属、球体与细环分别转动保留。逐建与全建状态使用内存视觉夹具，不代表自然解锁；日志无脚本或 Shader 解析错误，仅环境无声卡的 ALSA 报错。原业务和 UI 接口保留。

本组已在原宿主完成阴影颗粒诊断与修复、暖灯、四阶段和正常速度动态核对。当前实机仍少于绘画稿的设施雕刻密度、暖灯氛围与颗粒星云；下一步以最新同源整页在公共宿主评估这些可见差距，继续按 M7 还原。此为作者候选，尚无用户验收或 main 合入授权。
