# 站体承力墙装甲：局部制作候选

接续 `889120d` 四节点候选和[同版 0–12 秒证据](../natural-motion-889120d/README.md)。在站体 Blender 源模型的实际压力墙外侧加入分段维修装甲、下部受力肋和贯通口两端的装甲面及检修槽；环道中央通道仍开放。这是几何与材质一起做的站体局部修改，未触及其他设施归属或运动。

Godot 4.7.2、2048×768 受影响对照：[单建站体相位 0](planet-station-armor-1.png)、[完整态相位 0](planet-station-armor-4.png)。取图脚本和输出见 [capture.gd](capture.gd)、[capture.log](capture.log)，校验见 [SHA256SUMS](SHA256SUMS)。已逐张原尺寸复看：贯通口未堵塞，双承力墙更可辨，前端暗面有暖色结构层次；下腹的深灰体量仍明显，整体四节点材质与细节密度仍需继续协调。两图仅是此次受影响视角，不能替代其他角度、自然建设态或连续相位验收。
