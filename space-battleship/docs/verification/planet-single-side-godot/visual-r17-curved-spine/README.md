# R17 星球整体结构：当前制作入口

本页只维护当前状态；交接发本页路径与当前具体动作。制作不因文档整理中断。

## 批准基准与完成判据

按用户已认可的[实体环带完整态 `8136cef8`](../../../game-design/art/modules/planet-six/scheme-b/solid-integrated-spine-clearance.png)制作“装甲承力脊与四设施共同形体”；[闭环分步 `1eda07fd`](../../../game-design/art/modules/planet-six/scheme-b/solid-integrated-spine-stages-closed.png)约束独立建造累积。环须贯入设施承力节点，不是宽托盘上摆建筑。球与环独转、探索船另轨、真实球后遮挡和前弧暗缝继续保留。

原尺寸完整态和受影响侧向角下，站／炉环通道应从低位承力口连续进入和离开，四节点材质、体量、细节密度应共同成形；炉双料斗、接收口、工作端口和站顶运动部件仍可读。不得出现飞碟、暗盘、浅方壳、外挂三件或假垫层。各设施保持独立建造归属。**整体尚未获得用户或独立审核者通过，当前继续制作。**

## 当前具体动作

继续解决默认角度站体单建的深色开口，并协调站、炉、工坊、船坞整体材质、剪影和细节密度。当前 `b5a4e127` 让四个 owned 环段原有的甲板接缝包到真实压力侧墙，截断同一截面的嵌入灯带；这增强了环脊承力节奏，但整体尚未通过。前一 `05cba6f5` 将站体通道内承力颊加厚、下斜撑接入压力脚、上承力横梁收住上方暗影，默认角度仍保留较低通道缝。更早 `bcf4fb7c` 收低工坊上承力轨与车架；`8d283fe2` 抬升站下侧墙并收束内颊。继续实际调整四节点总体剪影、材质和细节密度，不以仅调色或局部图结束。

环下承力截面见[环下压力箱](lower-pressure-box/README.md)，未连接端见[自由端局部候选](tapered-free-end/README.md)；站／炉实体各见[站体](station-through-node/README.md)与[炉体](refinery-through-node/README.md)。这些都是局部候选，不能替代整体审。
