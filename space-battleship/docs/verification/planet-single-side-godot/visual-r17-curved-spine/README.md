## 批准依据与完成判据

按用户已认可的[实体环带完整态 8136cef8](../../../game-design/art/modules/planet-six/scheme-b/solid-integrated-spine-clearance.png)制作装甲承力脊与四设施共同形体；[闭环分步 1eda07fd](../../../game-design/art/modules/planet-six/scheme-b/solid-integrated-spine-stages-closed.png)约束独立建造累积。环须贯入各设施承力节点；球与环独转、探索船另轨、真实球后遮挡、前弧暗缝和四段独立 owned 归属保持。原尺寸完整态及受影响侧角应读出站／炉低位连续通道、炉双料斗和接收口、工坊工作口、船坞停靠艇及站顶运动件。不得出现飞碟、暗盘、浅方壳、外挂三件、假垫层或仅改色／环宽替代资产制作。**整体尚未通过，继续制作。**

## 当前具体动作

当前源码 `7e9506c4` 在四段 owned 承力截面基础上，让炉原压力舱一体拱起、冠部高于双料斗内缘、同网格切热井；两只原料斗侧墙外张、蓝色下壳和浅色料块分层，接收口保留，炉节点中心已移入本段承力弧。R48 将两只料斗内各三块方料改为两块不规则矿石；原尺寸默认／25°仅局部可辨，70°受口沿遮挡，不能把矿石当成整体形体改进。船坞原停靠艇沿发射轨前移微抬，船首露出泊位端；工坊侧窗后的遮挡内墙收成上下承力边，侧角可读内部工具行程。站指挥冠承力盘和运动环扩大，原下承力颊渐缩并压入 owned 环截面；站下缘重复箱体改成连续装甲侧壳，节点中心落在本段甲板中部，低位通道保持。共同环平面上移后，站＋炉阶段上承力弧跨球顶可见；R62 将站／炉 owned 端面同时移到 `1.39π`，站单建也拥有朝炉延伸的上承力弧。R70 将站段下承力壁连续到短压力端面，端面改成浅色承压面；第5／6类紧凑恒星的环与设施随球体比例收拢。R74 将炉、工坊、船坞 owned 节点承力肩按实际脚距扩宽，第6类可读下限收至0.42。R76 将站段下缘从站脚向独立端面渐收，默认与25°暗色悬垂缩短。R80 将炉原连续下承力颊作为暖色可见侧壳，移除重复小盒和细悬垂支架。R81 移除工坊两条原承力顶梁上的六块重复顶砖，开放工作口保留。R82 用一条连续承力梁替换船坞泊位顶边重复小件，开放泊位及停靠艇保留。完整态前弧与球下缘相交，真实球后遮挡保持。站单建下缘深色体量仍可见，四设施与环的共同主剪影、材质协调仍不足，整体未通过。
