## 当前具体动作

当前源码 a7ed241c 保留炉体下凹热井、船坞压力龙骨和环段接缝；船坞停靠艇沿发射方向前移 0.27 且在坞内上抬 0.05，站体原有内侧承力网格拓宽低位通道并使入口外扩；炉体两料斗底板与矿块降入已有围壁，形成可见内腔；工坊移动滑座分为同一枢轴上的两条承力轨，露出工作口；四段 owned 环甲板共用的中心槽在原有截面中加深；站顶承力盘收窄且分面，装甲接缝与状态灯随实体收回。默认、25° 与 70° 原尺寸图已复看，仍需继续四节点共同体量、材质与剪影协调，优先在设施同网格与已有 owned 承力截面中修形；任何候选先看原尺寸再决定保留。
