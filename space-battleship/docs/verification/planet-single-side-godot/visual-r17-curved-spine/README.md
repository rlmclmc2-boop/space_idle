## 当前依据与下一步

当前源码 `e29fc33b`：四段 owned 承力截面与独立端面构成闭环，站／炉在 `1.39π` 对接，站单建拥有朝炉延伸的上承力弧。共同环半径4.35，甲板、侧壁、青色服务线贯穿四设施节点；工坊／船坞交接处的前弧承力肩与冠部属于两段建成后出现的环体网格。炉双料斗、热井和接收口，工坊开放工作口及移动工具，船坞轨内停靠艇，站冠运动环均在真实设施模型中。第6类光束恒星以0.40的共同环尺度下限及0.88可见包络拟合保持球环和光束可读，四设施模型按紧凑环尺度补偿至0.50基准以增强远景身份。R114在四段 owned 环体及已建接合处增加连续实体侧肩和下承力折面，青色服务线仍处于暗槽；工坊开放门架的移动工具抬高0.25，保持在真实工作口内；R122又将两条原有头梁和其白色装甲边改成浅拱形分段承力梁，工作口仍开敞。R123将第6类紧凑恒星的环体渲染高度基准从0.235提高到0.285，四设施随真实环体一同放大，球体与光束拟合不变。R124把站冠顶盘、外压缝、八个服务口与转动观察环一起收窄，使其在前弧视角更贴合下方承力墙。R125将双料斗整体横向收至0.88、竖向收至0.95，使炉冠在默认与侧角中成为更清晰的炼炉主剪影，同时保留两只开放料斗。R127在原船坞真实开放泊位内放大停靠艇并略向内移，机首和座舱在默认与侧角中更清楚，仍由两道泊位框夹持。R129使共同环的横向承力暗缝从甲板延续穿过实体侧肩，独立端面与青色服务线保持。

下一步仍须推进**站环共同主轮廓和四设施共同剪影／材质**，尤其第6类紧凑恒星的球环空隙和设施远景可读性；不能以局部改色或小件替代整体制作。
