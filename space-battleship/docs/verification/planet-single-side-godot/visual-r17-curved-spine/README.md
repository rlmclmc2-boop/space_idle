## 批准基准与完成判据

按用户已认可的[实体环带完整态 `8136cef8`](../../../game-design/art/modules/planet-six/scheme-b/solid-integrated-spine-clearance.png)制作“装甲承力脊与四设施共同形体”；[闭环分步 `1eda07fd`](../../../game-design/art/modules/planet-six/scheme-b/solid-integrated-spine-stages-closed.png)约束独立建造累积。环须贯入设施承力节点，不是宽托盘上摆建筑。球与环独转、探索船另轨、真实球后遮挡和前弧暗缝继续保留。

原尺寸完整态和受影响侧向角下，站／炉环通道应从低位承力口连续进入和离开，四节点材质、体量、细节密度应共同成形；炉双料斗、接收口、工作端口和站顶运动部件仍可读。不得出现飞碟、暗盘、浅方壳、外挂三件或假垫层。各设施保持独立建造归属。**整体尚未获得用户或独立审核者通过，当前继续制作。**
