代表机位的三座工作设施取消通用黑圆座：旧插画底脚的 3D 根点降至本段曲面鞍座，精炼厂两条短入料槽、工坊开放工作湾两侧导轨、船坞泊位双轨分别属于本座已建环段，不依赖其他未建段；空间站保留自身圆形轨道接口。这是本次接口与深度关系的视觉候选，仍待独立审图，不代表原插画已经转换为完整 3D 建模。

## 精炼厂固定槽口投影校正候选

原审退回上一节：024 嘴下仍有细黑竖刺，stage4/051 是短黑垫块。量取代码端点后发现，024 带端到环中心槽口在画面上仅约 9 像素，而试验桥宽约 28 像素；其逐帧寻找屏幕最近环角还让尾端滑动。曾试固定外侧槽的 3D 细桥、同风格独立袖管和外移建筑，原尺寸都读成环外伸出的细杆或枪管，**未进入本版**。这些失败试验不作为通过证据。
