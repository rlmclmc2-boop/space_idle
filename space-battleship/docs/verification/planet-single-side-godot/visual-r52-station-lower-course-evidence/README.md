# R52 站连续下侧承力壳受影响图证

源码为 `feat/planet-single-side-ui@350f3d51`。Blender 4.3.2 重建站 `.blend`／`.glb`；Godot 4.7.2 OpenGL/llvmpipe 2048×768 脚本模拟完整态默认、单建25°及完整态25°。built 状态和角度由脚本模拟，不能代表自然施工、自然转动、整圈或整体通过。

站原两侧压力墙端部渐缩，原下缘重复料仓状甲片与四组外侧箱体退出，连续下侧装甲从压力墙接到两端承力足，通道保留。原尺寸默认和25°可见下侧更连续，但站暗色下缘与四设施共同主剪影仍不足，整体未通过。`SHA256SUMS` 覆盖原图、脚本、构建／导入／取图日志。
