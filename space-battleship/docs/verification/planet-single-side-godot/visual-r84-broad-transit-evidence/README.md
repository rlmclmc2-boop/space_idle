# R84 共同承力环甲板截面图证

源码为 `feat/planet-single-side-ui@0850021a`。Godot 4.7.2 OpenGL/llvmpipe、2048×768 六类默认完整态、默认相位四段累积、25° 与 70° 站单建及完整态。脚本设置 owned 建造阶段和角度，图证不代表自然建造、自然转动、整圈或整体通过。

共用前后承力甲板过渡段的实际截面加宽，默认与70°浅色甲板承接四设施更明显，紧凑恒星的四设施保持可辨；站单建端面及独立归属保持。第6类球仍显著小于环；四设施共同主剪影、材质协调及六类整体仍未通过。`SHA256SUMS` 覆盖14张原图、4份脚本、4份取图日志。
