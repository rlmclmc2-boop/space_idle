## 当前构图与穿插

当前 `1440×900` 画面左侧星球模块宽约 `808px`，右侧战斗约 `536px`，两者之间还有间隔；球体中心约屏幕 `(461, 495)`、半径约 `230px`。`planet_visual.gd::_scene_center()` 在模块内取 `0.57×宽、0.5×高`，因此球体在**模块内部**稍偏右，但对**整屏**仍明显偏左。用户所说“没有占据视觉中心”与实图一致。整屏结构由共享宿主负责；不能仅把局部 `0.57` 改成另一个值来声称解决整屏构图。

左侧背景当前是深蓝径向渐变和固定随机稀疏星点，缺乏足以建立远中近层次的星云、尘带或其他空间参照；静帧左下大片区域尤为空。六颗星球共用这套背景，因此第五、六颗的小半径更显空旷。太空背景、球体与右战斗区的整屏关系都需下一阶段另出构图候选；本轮没有改共享宿主或背景。

现有空间站在 `orbital_facilities.gd` 中有绕行速度，船坞路径速度为零，`planet_facility_scene.gd::update_pose` 又将船坞角度固定为 `0.65`。只读解析此前始源星 [R3 完整运动轨迹](../visual-r3/evidence/final-motion-poses.jsonl) 的两个模型屏幕 AABB：361 个样本中 37 个样本相交，首次集中在帧 74–82（地表累计约 `0.218–0.242` 圈），之后还有帧 177 起及约帧 293 附近。帧 183 的 AABB 交叠面积约 `4842px²`。这证实画面有显著的**投影穿插风险**，不能据此单独断言三维实体碰撞。旧 [R3 视频](../visual-r3/evidence/final-full-surface-orbit.mp4)可直接复核；它没有覆盖六星球或新设计稿。后续建模前应确定船坞安装/锚点以及空间站轨道包络，确保实际三维净空与屏幕前后关系都清楚，再用连续帧复核。

## 四张独立设施设计提案

四图均为本轮 imagegen **原始 PNG**，各自包含三分之四主视和辅助轮廓视。材质统一采用深青承重结构、暖象牙色局部装甲、石墨暗面、铜色机械关节与少量青/琥珀工作灯；视觉主次以大体积和功能动作建立，而非增加碎小零件。图像是造型方向，辅助视图未保证工程正交精度；落地时须按游戏画面实际约 80–110px 可见尺寸简化和校验。

| 设施 | 独立图稿 | 功能与可动部件 | 附着关系与待确认点 |
|---|---|---|---|
| 空间站 | [station.png](designs/station.png) | 有压居住环、独立主脊、可见泊口与太阳能翼；环体转动、翼板调整。 | **已定在轨道**。请确认居住环主形及泊口方向；轨道不能穿过船坞工作包络。 |
