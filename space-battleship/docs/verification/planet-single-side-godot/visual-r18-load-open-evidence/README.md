# R18 承力槽与设施开口独立图证

源码为 `feat/planet-single-side-ui@a43d7b81`。Godot 4.7.2 OpenGL/llvmpipe 在 2048×768 SubViewport 取图；六类变体均为脚本配置的四设施 built、固定姿态。`side25-1` 是站单建模拟 25°，`side25-4` 与 `side70-4` 是四设施模拟 25°／70°。这些角度不表示自然转动、施工历程或整圈验证。

本轮加深环自身截面的中心槽，并把同一截面分为暖甲板与深色凹槽；扩大站低位通道、工坊侧工作口及船坞的径向／环向实穿口。曾试更宽更高的节点渐变，但 25° 图呈现浅色三角垫形，已撤回。现图确认三个开口与四段环可渲出；整体剪影、炉顶体量和材质仍未达到 8136 概念，不作通过结论。

`planet-r18-*.gd` 是取图脚本，图片为 Godot 原始输出。`SHA256SUMS` 记录这些文件和取图日志的字节摘要。
