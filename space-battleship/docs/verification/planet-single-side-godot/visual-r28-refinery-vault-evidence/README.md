# R28 炉同体拱壳受影响图证

源码为 `feat/planet-single-side-ui@096cb3af` 加 `build_refinery_node.py` 本轮改动。以 Blender 4.3.2 重建炉 `.blend`／`.glb`，Godot 4.7.2 OpenGL/llvmpipe 取得 2048×768 完整态默认、25°、70° 原图。图中 owned 和角度由脚本配置；只证明这些模拟姿态的外观，不证明自然施工、自然转动、整圈、六类或整体通过。

原压力舱改成一件从两侧承力墙拱起的闭合网格，热井在同一网格上切出。三帧中拱面、双料斗与中间接收通道可见；前端蓝色压力口仍留暗面。四设施与环的共同主剪影仍未达到批准概念。`SHA256SUMS` 覆盖原图、脚本、构建／导入／取图日志。
