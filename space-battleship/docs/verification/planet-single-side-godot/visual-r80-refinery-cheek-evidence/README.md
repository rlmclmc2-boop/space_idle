# R80 炉下承力颊一体轮廓图证

源码及模型为 `feat/planet-single-side-ui@ede4744a`。Blender 重建原始炉 `.blend` 与运行 `.glb`；Godot 4.7.2 OpenGL/llvmpipe、2048×768 六类默认完整态、默认相位四段累积、25° 与 70° 站单建及完整态。脚本设置 owned 建造阶段和角度，图证不代表自然建造、自然转动、整圈或整体通过。

炉下承力颊由原有连续网格承担可见暖色侧壳，原重复小盒与露出的细支架移除；双料斗、接收口、热井和低位通道保留。站下缘仍有暗色体量，四设施共同主剪影及六类整体仍未通过。`SHA256SUMS` 覆盖14张原图、4份脚本、6份构建／导入／取图日志。
