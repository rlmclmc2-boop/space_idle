# R48 炉料斗矿石受影响图证

源码为 `feat/planet-single-side-ui@2ea70ccd`。Blender 4.3.2 重建炉 `.blend`／`.glb`；Godot 4.7.2 OpenGL/llvmpipe 2048×768 原图为脚本模拟完整态默认、25°、70°，不代表自然施工、自然转动、整圈、六类或整体通过。

两只原料斗各以两块不规则矿石替换细小方块。默认和25°角能辨料斗与矿石；70°时炉节点接近侧视，矿石被料斗口沿遮挡，不能用此图宣称三角度均可辨矿石。四设施与环的共同主剪影仍未通过。`SHA256SUMS` 覆盖原图、脚本、构建／导入／取图日志。
