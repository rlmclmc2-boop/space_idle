# R53 站节点居中于 owned 环段图证

源码为 `feat/planet-single-side-ui@0d5af135`。Godot 4.7.2 OpenGL/llvmpipe 2048×768 脚本模拟完整态默认、单建25°及完整态25°。built 状态和角度由脚本模拟，不能代表自然施工、自然转动、整圈或整体通过。

原站中心角靠近 own 段起点，模型一侧超出承力弧；本轮将中心角置于该段中部，使两端压力墙都落在本段真实甲板上。默认图站与环对位改善；单建25°被球体遮挡，不能以图证明完整开口。站下暗色块与四设施共同主剪影仍未通过。`SHA256SUMS` 覆盖原图、脚本、导入／取图日志。
