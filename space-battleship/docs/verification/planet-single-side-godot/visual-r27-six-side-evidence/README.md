# R27 六类与侧角原尺寸图证

源码为 `feat/planet-single-side-ui@a2c49979`。Godot 4.7.2 OpenGL/llvmpipe 2048×768 原图为脚本配置的六类完整态默认角、地球类站单建与完整态 25°／70°；角度和 owned 状态均为模拟，不代表自然施工、自然转动、整圈或整体通过。

逐张检查：六类共享同一设施与环构图，热球和小球类设施仍可见；默认及 25° 站低位通道、炉拱顶、工坊工作口和船坞艇可辨。70° 站被球大幅遮挡。四设施主剪影仍像各自置于环上，承力脊和共同材质尚未达到批准概念。`SHA256SUMS` 记录原图、脚本和日志字节摘要。
