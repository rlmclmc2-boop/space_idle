# R19 炉压力舱拱顶图证

源码为 `feat/planet-single-side-ui@64a26f57`。Godot 4.7.2 OpenGL/llvmpipe 以 2048×768 SubViewport 取原图：`planet-r19-variant-1.png` 为脚本配置四设施 built 的默认模拟姿态；`side25-4`、`side70-4` 分别为四设施模拟 25°、70°。图证只覆盖炉顶改动所影响的完整态视角，不代表自然转动、自然施工或整圈验证。

炉原压力舱同一网格沿入料方向拱起，并在网格内布尔切出热井；两个开顶料斗、矿块与接收口保留。球冠试样在 70° 图形成独立圆盘，已完整撤回。当前拱顶在默认及侧角仍与炉身相接，热井可见；整体剪影与材质协调继续未通过。

`SHA256SUMS` 记录三张原图、取图脚本及实际取图／导入日志的字节摘要。
