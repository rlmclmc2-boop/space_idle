# P4 信息收纳：两侧余量与按需抽屉

[唯一入口](../../game-design/README.md) → [M7](../../game-design/art/modules/planet.md)。用户否定P3下方控制区占比，并明确优先利用圆形星球两侧余量，不够再用抽屉；本轮不先切走下方整片空间。保留建筑纯观看、操作独立、空间站绕转及资源工厂贴地。工坊地表、船坞近轨仍是建议，共用13不改，正式UI仍待确认。

## 生成前的比例与净空判断（本轮建议，未冻结）

P3下方常驻设施表占约三成高度，四设施细项及右侧空区长期挤占观看。本轮先删除常驻表格、收起低频管理，再利用圆形主体两侧的真实余量；不靠继续放大球图补偿，也不默认划出一条完整底栏。

工作条件仍为待确认的1440×900整窗、808×900模块，不是main尺寸或最终布局。以下是构图预算，不是已实现/已通过的像素规范：

| 区域/状态 | 本轮建议 | 取舍 |
|---|---|---|
| 全局信息/导航 | 顶部约100–110px | 沿既有整窗关系，不增加标题栏层级 |
| 默认观看空间 | 连续场景延伸到模块底部；除全局信息外不再切出横向控制带 | 星球、地表设施、轨道与探索机仍是观看主体，下部留给轨道/飞行 |
| 左侧探索仪表组 | 暂约150–160px宽、150–180px高，落在左上圆外余量 | 本次进度/人数、自动状态、人员及停止/取消；小按钮和文字直接承托，不做大白卡 |
| 右上设施入口 | 暂约160–180px宽、44–56px高，带“1待领取” | 默认只占一个入口，不摆全设施表、禁用重铸块或空面板 |
| 管理展开态 | 右侧窄抽屉暂约210–230px宽、240–280px高 | 只显示当前设施，尽量放右上圆外余量；不横切整片下缘，不为关闭状态预留空位 |

默认局部控件合计约占模块面积4–6%，而不是拿走约三成高度；展开抽屉自身约7–9%面积。这只是目标预算，不能与工具生成后的实际面积混称。按钮/中文不靠压小来塞入空间，净空不足先收纳内容和减少重复读数。

球体暂约380–400px直径、中心约(375,440)，两侧有可用余量。左组初拟在x24–175/y200–360，右入口x610–790/y170–230；先画出站体/探索机轨道及抵达路径的完整运动包络，控制区退让，不因建筑不点击就允许它们穿过按钮。轨道可采用下偏斜的观看关系，让左上/右上形成净空；这只是前端构图提案，不变玩法或承诺已实现路径。

抽屉初拟落在右侧上半区，避免覆盖球体和主要交通带；如果实际图像余量不够，应缩减详情/分层，不重新腾出一大片常驻底部面板。打开不自动改相机、缩放、暂停或业务状态；关闭归还完整余量。

## 常驻与按需

| 默认观看态保留 | 管理抽屉内收纳 |
|---|---|
| 当前探索中/暂停及必要原因、本次68%、人员入口和人数、自动开启事实 | 设施选择、完整门槛/施工次数/额外人员、当前效果/领域原因 |
| 本次完成后停止、立即取消，物理上分开 | 精炼厂领取、船坞人员入口，随选中设施出现 |
| 右上稳定“设施管理”入口＋琥珀“1待领取” | 累计加成、重铸预览和条件不足原因 |
| 当前任务缺人/失败不可隐藏 | 不常驻四行全设施表、不保留无内容的大块右栏 |

默认态不直接摆每个设施的领取/人员行；代价是管理/领取需先打开一次。待领提示始终可发现，打开可定位本星球待领设施，但仍由用户点击原领取动作，不擅自自动领取。船坞38/180及额外人员1/1在选中船坞时查看，必要受限原因留在对应管理上下文。

稳定设施入口不跟随建筑，建筑处于背侧/被遮挡也不改变操作可达。所有控制仍按原稳定星球/设施ID及公开事实消费，不增加待办账本、位置业务字段或建筑点击。

## 两张同状态图

1. **默认观看态：** 场景铺至下缘，左上圆外余量为窄探索仪表组；右上只有设施管理及1待领取提示。无底部整条控制台、常驻设施大表、重铸占位。建筑纯观看，地表/轨道分工保持。
2. **抽屉展开态：** 同一世界/任务/摄像机状态，右上入口就地展开为窄抽屉，左侧探索仪表组不动。标题/收起、单个设施选择器，示例选中精炼厂，待领/施工5/5次与领取按钮；累计加成、重铸预览是紧凑按需入口。不是再列四行全设施，也不在右侧摆大空区。

同一排版样例为D68、探索者1人、自动开启、本次68%；空间站/工坊built，精炼厂ready，船坞38/180且额外人员1/1。两张图只比较前端开合，不发生推进/领取，不冒称真实操作证据。P3三时刻图只作运动关系过程参照，其大控制区布局已被用户否定，不再继承。

本轮按此独立取舍生成两态image，交原独审与用户确认；无HTML/SVG、实现、基准或main合并。精确分区/字距与运动净空要按生成原图如实复核，图稿不自动通过V0/V7。
