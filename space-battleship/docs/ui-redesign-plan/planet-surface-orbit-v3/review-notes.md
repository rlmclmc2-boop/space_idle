## 图像自查与原独审重点

- 画面内无建筑按钮、悬浮详情或点击标记；控制区固定显示探索、自动、人员、领取及设施状态，建筑在球缘/背侧不决定操作可达。连续浅暖操作台使用四行，而不是四张建筑卡片；与整片深青观看空间的主次仍由独审判断。
- 精炼厂在下方同一大陆上，保留双横罐与接触阴影；分镜随该地貌向球缘移动。工坊按本轮建议贴地，随左侧大陆移动并压缩。空间站与地表不同步，船坞按本轮建议保持近轨固定。
- 分镜相位是生成近似：建筑的局部切面姿态、基座接触、地貌追踪、尺寸缩短、云差速与遮挡边界没有数值/像素保证。当前附图工坊到t8仍部分可见，未伪称其已经完整转到背侧；精炼厂没有被改成漂浮轨道物。
- 主图与附图存在尺度/局部位置及细节漂移，附图省略上方全局导航，只集中表现观看区与操作台；不能当原主图逐像素同机位裁图。亮缘强度、设施在球面的体积/比例、观察台占比、字体/个别笔画均待独审。
- 主图分区偏宽约102目标像素，未达808目标。新稿没有因此冻结目标尺寸或主张布局通过；manifest记录实际尺寸。
- ready工厂只给待领状态/琥珀点，操作在控制台，未显示已生效倍率或生产流；施工38/180不是秒，未提前到built。工坊/船坞的建议在客户区外说明，不烘焙为产品内设计文案。
- 星体贴附路线仍未选：A需同相位锚点/切面姿态及部分遮挡处理；B共享深度可简化这些空间关系，但成本未测。用户已撤销建筑点击需求，两者都不需要新增建筑射线/碰撞拾取。详见direction-and-routes，不报性能胜者。

本轮无UI、业务、配置、模型或共用风格改动，无HTML/SVG样稿、B实现、基准、独立复测或main合并。文档链接、JSON、原图尺寸及SHA-256已核对；文档/图像自查不构成V0/V7实机验收。完成后由原独审复核图像，再交用户确认。
