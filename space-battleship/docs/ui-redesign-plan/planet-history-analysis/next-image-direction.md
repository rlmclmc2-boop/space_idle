## 观看主题：从轨道中观察一颗持续变化的星球

下一版的主体是星体转动、探索机飞行与设施前后经过所形成的空间。连续场景铺满模块可用区；星球、轨道和设施的关系先成立，控制台依附场景边缘，所选对象的读数与操作通过邻近锚点关联。球体完整保留，降低上一稿的画面占比，为经过球缘与背侧的运动留空间。

拟沿用待用户确认的1440×900整窗、左808×900模块、右侧战场比例作图稿工作画布；它不是main尺寸或最终布局决定。以下位置/尺寸只用于原独审判断，不写进共用规范。

## 一张整窗主图的具体构图

- **连续空间。** 浅暖灰/象牙色用于全局信息与场景边缘操作结构；轨道空间从低饱和青灰过渡至承托球体的深青蓝，直接延伸至模块左右边缘。无球体内框、无圆角舞台盒、无设施卡片底板。不延续上一稿遍布小行星的暖色桌面感。星点少而轻，观看内容由天体与任务提供。浅暖与深青的面积关系作为本次模块构图提案待审，不擅改共享风格。
- **星体位置。** 球心暂约(370,450)，直径约360–390；标题和导航在顶部边缘，底部留操作净空。星体可见直径以最后整窗观感确定，不为“整区场景”继续扩大球图。球面沿旧实机的简洁海洋/大陆轮廓、柔和卡通明暗带和克制边缘大气，云层保持独立稀疏带状；不重画成噪声细节丰富、满圈强发光的球体。
- **轨道。** 使用少量前后弧与不同倾角建立深度。背侧轨道更弱，经过球体投影的背侧段确实被遮住；前弧跨过球缘后连续进入前景。弧线可以延伸到模块边缘，但不画成围住球体的装饰框。球体左右留出设施绕入/绕出的空间。
- **探索机。** 在前侧轨道的右下段出现，船首沿实际切线，尾迹短，尺寸服从设施与星体主次；附近只放“探索中”、探索者人数及本次进度。不是横向摆在球旁的舰船图标。
- **设施。** 空间站、精炼厂、工坊与船坞保留现有双翼、双横罐、压床和U形轮廓。位置从各自轨道/固定停靠关系产生，不按四角平均摆放；主图至少有一个**已领取**设施处于球缘的部分遮挡阶段，另一个在清楚的前景，体现属于同一空间。船坞保留固定停靠位置，不为展示动态擅加公转。
- **状态。** 延续同一排版样例：D68，空间站/工坊built，精炼厂ready未领，船坞building 38/180、额外人员1/1，探索者1人、本次进度68%、自动开启。building以未完工轮廓/工程定位区别于已领取设施；ready有待领取文字与琥珀标记，不能用运转的完整设施冒充已拥有。样例不是实机状态，也不推定建筑分段外形的新玩法。
- **操作。** 默认只展开一个选中设施的必要详情。文本和点击目标位于稳定的邻近净空，细引线端点跟随对象，不要求玩家追着移动按钮点击。对象进入背侧也不漂出一个“完整设施”盖在球面前；所选身份/详情仍清楚，具体背侧锚点方案留实现前核对。停止/立即取消在场景底缘分开，累计加成和重铸预览按需进入，不堆常驻解释。
- **战场。** 沿已展示的固定右侧参照，仅保证整窗主次；不另设计舰船、护盾或战斗逻辑边界。无P3/评审/示例标记和上下矛盾的航程状态。正式UI面不出现本提案的分层、时刻、方向箭头或教程文字。

## 主图之外，用同一场景三个时刻表达动态

拟交付“整窗主图＋同一模块空间三时刻附图”。附图都是同一808×900场景/同一机位，不新增窗口规格；不把三个缩小整窗塞进产品界面。若原独审认为三帧不足表达，可先调整分镜时间，不能靠主图中的箭头或大段解释冒充动态。

三个时刻取同一已进入稳定探索的t=0/4/8游戏秒，前提为未暂停、探索及额外施工人员持续在岗；1×时等同经过0/4/8墙钟秒。主图取t=0。构图、球心、直径、光源、设施身份及未完成/未领取状态保持一致；按[03 §5](../../game-design/03-progression.md#5-星球探索与建筑)第一星球本次60秒的规则样例，本次进度依次68%、约75%、约81%，这8秒内不触发完成，故D68及船坞38/180不变。这些是图稿样例，不证明真实时钟或UI已接入：

| 层/关系 | 三时刻应能核对的变化 |
|---|---|
| 背景、相机、结构与光源 | 不移动；亮面/暗面主方向固定。不是连光斑和阴影一起旋转整张PNG |
| 地表 | 同一个大陆轮廓沿球面连续移位，靠近边缘时收窄；地表标志不能每帧换成另一套大陆 |
| 独立云层 | 同一条云带相对大陆产生小幅差速；沿现有运动关系表达，不为看得清而随意夸大速度 |
| 大气/轮廓 | 稳定承托球形及明暗，不能随地表纹理摆动；强度克制，不用亮环替代体积 |
| 探索机、前后弧 | 随同一轨道沿切线移动；分镜相位选择覆盖前景、过球缘及背侧遮挡，不能在背侧仍画成前景贴纸 |
| 已领取设施 | 位移、朝向与部件表现保持身份连续；至少一个可核对前后关系。网格或图集均可，图稿不承诺实现路线 |
| 施工/待领设施与读数 | 不用“运转动效”暗示已领取；探索本次进度随样例时刻变化，未完成前不提前累计施工。这是视觉分镜，不冒称8秒任务推进/结算实测 |

分层是呈现职责：背景／背侧轨道与设施／球面及独立云／固定光照大气／前景对象／交互文字。它不规定必须有多少节点、纹理pass、网格或viewport。图像生成会输出合成图，但交付说明须明确可动层及相互关系；整张生成图不能直接当运行场景底图。

## 原独审需要先核对的四项

1. 整片轨道空间、收小星体与前后经过关系，能否纠正上一稿“放大球图＋四周摆模型”的方向。
2. 浅暖控制结构与连续深青轨道空间的比例，是否延续共享视觉语言；无内框时仍能读清文字。
3. 一张整窗加同机位三时刻附图，是否足以审地表/云/光照/遮挡；这不是图稿已验证动画。
4. 当前业务样例与一个选中设施的密度是否合适，是否还需先调整观看焦点再生成。

方向核对后已进入image出图，图像结果须另交原独审。若工具原图尺寸或分界有偏差，按实际记录，不能声称精确布局通过，也不为此无休止重画。正式UI、B实现、性能基准及main合并都不在本轮动作内。
