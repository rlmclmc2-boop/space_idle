探索摘要、人员、设施/待领入口与停止/取消收在左上同一操作簇；右侧原设施入口移除，归还观看。常用控制重新分行，星球名称/探索度移至球体上方余量。左侧抽屉在操作簇下方展开，摘要与停止/取消不被盖住，保留精炼厂作用、领取及低权重更多入口；不恢复大表或底栏。

沿用同一D68、本次68%、探索者1人及自动开启样例，未推进或领取。空间站轨道、精炼厂贴地、建筑仅观看/操作独立的已定分工保持；工坊贴地、船坞近轨仍是建议。P4观看资产/构图为参照，不宣称生成图逐像素保持原世界。

本轮三次image_gen：默认、展开、一次集中校正展开图的站体位置/抽屉宽度。原始PNG未经额外压缩、缩放、裁切或拼接。两张候选均1586×992，分区仍映射约910而非808；控制簇和抽屉也宽于最初预算，808下需保留字号重排，不能整体缩图。

**净空待审：** 默认站体未压在常用按钮上，但取消按钮靠近轨道上沿；完整运动/抵达包络未验证。展开抽屉允许临时遮部分站体/左球缘，常用控制保持可达。一次修正后站体相对默认图仍有向右生成漂移，不能据此证明原站体的真实遮挡或精确同状态复现。详见自查，不宣称V0/V7通过。
