# P5 左侧集中：两态构图与净空策略

[唯一入口](../../game-design/README.md) → [M7](../../game-design/art/modules/planet.md)。用户确认“按集中重新设计”：探索、人员、设施入口集中左侧，详情同侧抽屉，展开后任务摘要及停止/取消可达，右侧留给观看。以dbd70b29的观看场景为参照，不移动/重做星体、地表设施和右战场来掩盖控件问题；本轮只出两态image及模块规范，不实施。

## 不把右入口直接塞到旧长列末尾

P4左列已靠近轨道弧，将设施按钮继续堆在取消按钮下，会向交通带延伸。本轮把常用信息和入口重新分成两行短操作簇，位置抬到轨道上沿之前；不缩小整体文字，也不恢复大底栏/全高侧栏。

工作条件仍为待确认的1440×900整窗、808×900模块，不能把P4映射约910px的原图整体压缩充当808适配。字号/按钮留用可读层级，按内容换行和重排；尺寸仅是图稿目标，工具偏差单列。

初拟操作簇位于模块左上、全局导航之下，约x20–350/y120–205。第一行是两行以内任务摘要（探索中/本次68%、自动开启）、人员1和设施/待领入口；第二行独立摆本次完成后停止与立即取消。所有常用操作在一个视觉/鼠标区域，人员与设施入口不用跨球寻找。星球名称/探索度可移到球体上方余量，属于信息布局，不改观看主体。

## 默认观看态

- 保留P4星球、地表精炼厂/工坊、轨道空间站、近轨施工船坞、探索机与固定光向；不为控制图稿另选2D或3D。
- 左上只有一个短操作簇，设施入口保留“1待领取”提示；右上原孤立管理按钮移除，右侧和下方连续留给观看。
- 无常驻设施表、空管理占位、建筑点击圈或追踪标签。工坊地表及船坞近轨仍为建议，不当用户已选位置。

## 同侧抽屉展开态

- 同一世界/任务瞬间，仅在操作簇下方左边缘展开紧凑抽屉；上方摘要/人员/停止/取消保持原位并可达，抽屉不覆盖它们。
- 复用dbd70b29精简内容：精炼厂·待领取选择行、“领取后：铁、铀原生掉落加成”、领取按钮、低权重“更多·加成与重铸”。不再铺四设施大表或禁用重铸块。
- 抽屉约210–230px宽、240–280px高，按内容重排、保留字级；不扩成大左栏。打开时允许适度临时遮盖局部站体/轨道，收起归还，不宣称所有时刻无遮挡。
- 开合只改变前端本地状态，不自动暂停、推进、领取、重新居中或缩放场景。

## 净空复核口径

默认控制簇首先退到轨道上方，避开P4旧取消按钮靠近的轨道弧；不把控件向左侧空间站的当前模型包围范围继续堆高/堆宽。应按实际生成图检查文字/按钮轮廓与站体、轨道弧、进入通道的最近位置，不能仅检查控件矩形中心。

两态同时看：默认态尽量不压站体/主轨道；抽屉态的适度临时遮盖与常用控制不可达是不同问题，摘要及停止/取消始终在抽屉之外。空间站/探索机可以经过背侧，建筑纯观看不成为操作依赖。

P4静帧及旧轨道源码可以定位风险，但P5生成图不是运行坐标或相位求值结果；本轮没有真实全轨道/抵达过程，不能将静帧评审当完整动态包络通过。若生成图仍有贴近/覆盖，明确交独审，不通过移动星球/缩字或伪造测量消除问题。

两图继续同一构造样例：D68、本次68%、探索者1人、自动开启；空间站/工坊built，精炼厂ready，船坞38/180、额外施工人员1/1。图像不是实机操作或推进证据。用户确认的是左侧集中方向，新图品质/比例/净空仍待原独审及用户确认。
