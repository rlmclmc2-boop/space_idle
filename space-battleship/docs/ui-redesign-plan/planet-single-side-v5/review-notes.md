## 可见控制关系

- 默认图内探索摘要、人员1、设施/1待领在左上同组，停止/取消在其下；原右侧设施入口消失。星球名称/探索度只作球体上方身份信息，不是第二个操作区。
- 两态任务及停止/取消保持同一上方位置，展开抽屉顶部与这排按钮底部有约18原生像素间隔，未盖住按钮/任务。人员和设施入口仍可见；无需关闭管理才能停止/取消。
- 抽屉只选择精炼厂，合并待领态，显示领取后作用、领取及更多；没有再铺四设施表/禁用大块，也不要求点击场景建筑。开合不表示暂停、时间推进或领取。
- 右侧及下缘保持连续观看空间，无额外操作框或常驻预留。图像的文字/图标可能有生成细节错误，普通控件的真实焦点、命中与返回仍未实现。

1. 默认静帧中常用按钮排底约y253，当前站体轮廓顶部约y270，能看到间隔；但取消按钮右端靠近轨道弧上沿。控件簇实际宽于初拟框，不能套用提案中的“上方净空”直接宣布安全。

3. 站体在展开图仍相对默认图向右偏移数十原生像素，尝试一次校正未完全恢复。因此该图不能证明按P4原站位的遮挡比例，也不能称世界坐标/姿态完全未变。其他局部细节亦可能漂移；不据生成图改动实际轨道来消除风险。
