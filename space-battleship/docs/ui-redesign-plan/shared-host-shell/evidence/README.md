## 32px / 33px实际排布结论

Chromium版本见JSON；CSS像素与导出物理像素1:1，DPR=1，缩放100%。使用仓库字体SHA256 `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`，450字重，正文16px，字体实际加载已核。浏览器Canvas实测样本文字墨迹高16px（上14、下2），资源行line-height24、导航line-height22；不是把文本节点高32误当字形可见。

资源行预算经过实验调整为96 / 160 / 160 / 208 / 32 / 88，五个8px间隔、两侧各12px，总808；分别为品牌、铁、铀、时空微粒、全部资源明细、保存状态。移除顶梁资源装饰图标以保留中文/数量级与读数宽度，导航图标保留原资产18px。该预算仍是H2提案，不改变模块内容尺寸。

| 样例 | 文本实际宽 / 可用宽 | 结果及限度 |
|---|---|---|
| 普通铁/铀/时空微粒 | 50.03/152、72.64/152、120.64/200px | 完整显示，无截断。 |
| `铁：1.235×10^123` / `铀：9.999×10^999` | 各142.70/152px | 资源名与数量级完整保留。 |
| `时空微粒：1.235×10^123` | 190.70/200px | 完整显示；实际Godot字体仍需核。 |
| 无界长指数 | 三格均超出固定预算 | 不截尾吞掉指数，不自行重算金额；改为具名“完整值”入口，并在完整详情中逐字保留原公开文本、允许换行。极值呈现策略仍待审，不声称顶栏完整容纳任意金额。 |
| 保存已完成/待写入/失败/有改动 | 16px文字，独立88px状态位 | 故障短状态连完整说明，待写入不冒充已完成。真实状态仍需现有SaveFiles提供。 |
| 九个导航项 | 按80/96px原预算，图标18px、字16px、按钮高30px | 五组样例中0项水平溢出；选中、焦点、悬停各有非颜色单一线索。 |

所有金额/状态都是**设计字符串**，形态来自现有PlayerText格式，不是实际Amount、钱包或保存事实。该证据支持宿主梁的尺寸可行性，不证明眼动舒适度、各模块最小安装或Godot运行通过。

## 复现范围

在项目根`space-battleship`用只读本地HTTP服务打开设计文件，例如`python -m http.server 8765 --bind 127.0.0.1`；再运行`python docs/ui-redesign-plan/shared-host-shell/render-design.py`（需已有Playwright及Chromium）。脚本只导出上述静态HTML，不是游戏runner/独立复测入口，不安装依赖、不读取个人数据。未重建Godot环境或运行游戏。
