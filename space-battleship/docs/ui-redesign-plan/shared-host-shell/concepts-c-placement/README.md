## 当前 1440×900 几何硬约束

当前运行组合中，模块区 `x=0..808`，战场容器 `x=808..1440`。572×960 战斗投影按 0.9375 缩放后，实际画面 `x=855.875..1392.125`，左/右未绘制空带各 **47.875px**。如果不压缩模块、也不拉伸/平移战斗，居中控制轴只能位于 `x=808..855.875`，最大宽 47.875px；其余材质与光轨应是实际环境绘制，不可用不相连的底板遮缝。右侧 `x=1392.125..1440` 可放辅助结构，却不宜把主要模块入口隔到战场另一端。左置若占固定 90px，在当前 1440 宽度下与 808px 模块根冲突；两张美术图都**不证明**现行尺寸可直接安装。

下一步在用户选定位置/连接原则后，先做真实 1440×900 尺寸的可读性和安装稿，再由模块/战斗所有者核净空、HUD、投影和输入焦点。当前公共布局未实装；反应堆 R1 是单独的既有宿主接入，不能把本页视觉视作其整屏证据。不做额外实机测试，不合 main。
