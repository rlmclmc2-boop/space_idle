# C 风格公共层：与导航位置无关的状态规格草案

此页承接用户要求打磨战场区和模块区**之外**的全部公共界面。它把 [R3 三模块概念](README.md)中的公共信息/控件语言延伸到必要状态，但不选定 R3、中置导航或区域连接原则，也不批准实装。适用于任何最终导航落点；模块内选择、费用、草稿、结果和战斗 HUD 仍由各自所有者负责。

依据为 [全局规范 13 §2.0、2.2–2.4](../../../../game-design/13-art-interaction.md)、[共享交接 14 §6.1](../../../../game-design/14-ui-contracts.md)与[现有运行候选 H1](../../runtime-h1/README.md)。以下只定义**呈现规则**；实际数值、开放、保存与输入事实沿已接入公开端口，不在概念层模拟为已完成业务。R3 整屏中的示意余额不是自然游戏状态证据。

## 公共层级和材料

| 层级 | 常驻内容和视觉处理 | 不得越界 |
|---|---|---|
| 当前入口与资源 | 当前工作区名称、已接入资源的短金额和资源详情入口。深色哑光面承托浅色高对比数字，数值较标签醒目；边框只提示槽位，不画连续金属纹样。 | 不重复模块局部等级/费用，不重算 Amount，不在图上烘焙金额。 |
| 会话状态 | 保存/故障的具名短状态；有故障时以文字和形状持久区分，完整说明从同一入口打开。 | 排队不能显示成“已保存”；失败不能靠瞬时亮光结束。 |
| 导航与辅助 | 每个入口有稳定中文全名、当前态和可识别图形；未选位置前只约定控件语义，不约定横向/竖向数量、图标轴宽度或坐标。 | 不新增第二套舰桥导航；不把收起当离开战斗或暂停。 |
| 临时公共浮层 | 资源详情、更多菜单、保存故障详情、恢复提示等从其触发件生长，暗底实字、清楚的关闭/返回路径。 | 模块的价格/比较/确认弹层仍归模块；公共浮层不覆盖战斗拾取后再把点击透传。 |

R3 的浅象牙用于已选、高强度焦点等少数状态；普通控件保持深青底和低强度青色边。琥珀只提示需注意的状态，不作为普遍装饰。文字与图形共同表达状态，不能只凭亮度或颜色辨认。公共浮层的材质与顶梁同源，但不把机库、反应堆或行星的场景纹理做成通用底。

## 可复用控件状态

| 状态 | 玩家应看到的公共层变化 | 对应输入语义 |
|---|---|---|
| 普通 / 悬停 | 普通中文名或可查全名；悬停加短边缘提示，不让光晕占据相邻模块或战斗有效投影。 | 悬停不触发模块切换或业务动作。 |
| 键盘焦点 / 按下 | 焦点用连续可见轮廓与底色，不依赖鼠标悬停；按下用短促内凹/压入反馈。 | 焦点留在可见公共入口；Space/G 服从现有 UI 占用门控。 |
| 当前已选 | 浅象牙或等强对比的持续面、中文全名/可查名与图形同时对应当前模块。 | 普通切换保留所属模块的选择、草稿、滚动与视角，不新建 Session。 |
| 未开放 / 暂不可切 | 保留有效的公开开放判断；已展示但暂不可用时给出具体原因或可查说明，不只变灰。 | 模态、文件选择器等独占时暂阻切换/收起；先完成或取消，不暗中提交。未开放入口的隐藏/展示遵守原模块规则。 |
| 收起 / 恢复 | 明确写“收起工作区”与“恢复当前模块”，同时保留当前工作区身份和可返回入口。 | 仅显隐内容；战斗持续可见，未自动暂停、清草稿或切 Session。 |

## 公共信息的长值和故障

- 资源短值必须消费现有格式化结果并保留单位/数量级。显示空间不足时优先省略次要标签或使用受控截断；完整原文及全部已接入资源仍可从资源详情读取。示意稿不得用固定 `10万` 验证极长金额或未登记币种。
- 保存状态区分排队、写入中、真实完成、失败与恢复暂停。失败保持可达的文字提示和详情入口；临时成功提示可收回。状态以现有保存事实为准，不从按钮按下时间推断。
- 更多菜单、资源详情及普通临时浮层由创建者关闭。点外侧的首击只关闭并消费；关闭后焦点回到可见触发件。危险确认或原生文件选择器仍在场时，宿主入口暂不可切，必要原因保持可读。
- 公共控件覆盖只占自己的交互区域。弹层或独占状态应同时阻断鼠标穿透与 Space/G；不能用全屏高层底板盖住所属模块的独占操作。战斗投影、舰船/HUD、拾取映射与伤害回执归属维持原样。

## 后续选型需要的实物判断

本页不声称上述状态已经在 R3 图或 Godot 中呈现。用户仍需决定导航落点及连接原则，并选择公共壳候选；R3 边缘取样尤其反应堆下半吊臂有重复折返，不能作最终环境素材。获选后须在真实 1440×900 及已定桌面范围内给出当前态、长金额、资源详情、保存故障、更多/收起、焦点/模态的同版整屏和输入层级；最终环境应由共享宿主绘制与战场联动，不能固定镜像一张截图。该阶段的实施和实机验收另行授权。
