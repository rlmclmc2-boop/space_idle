## 只需的前端协作端口（候选，未实现）

这是直接视图协作，不是新DTO、总线、后端门面或公共业务命令。原组实现各自适配，整体线程唯一维护宿主调用。

```gdscript
# 原模块视图提供；签名随本方案一起审核，当前代码不具备这些新增端口。
func set_shared_host(enabled: bool, context_slot: Control, backdrop: Texture2D = null) -> void
func has_exclusive_ui() -> bool
signal exclusive_ui_changed
func prepare_host_hide(force: bool = false) -> bool
```

- `set_shared_host`只分离已确认的全局chrome，并将模块创建/更新的上下文Control装入宿主96px槽。反应炉用现有展示模型更新等级，星球用原静态模块身份；不得因此新增后端查询或宿主计算。背板只消费声明的纯环境区；无此需求可忽略。模块保留上下文内容/绑定所有权，宿主保留其专属子槽/层级所有权。装备可不创建额外上下文，由宿主默认品牌承托；反应炉/星球各只写自己的槽，切换时整槽显隐。禁用/卸载时先解除并释放模块创建的槽内Control，再释放槽；不让旧视图继续写新模块上下文。
- `has_exclusive_ui`只报告自有模态、批量遮挡、PopupMenu或Window是否占用交互。反应炉当前无自有模态，可返回false；所属普通抽屉打开不等于全局模态。`exclusive_ui_changed`仅使宿主刷新可用入口与输入遮挡，不承接领域接纳。
- `prepare_host_hide(false)`在独占UI未关闭时返回false，阻止普通切换；否则关闭自有临时Popup/tooltip、撤离焦点并允许隐藏。非模态抽屉/选择/草稿/回执保留本地状态，随根隐藏，不清零。
- `force=true`只用于会话替换/实际释放：阻断旧输入、关闭自有窗口与弹出控件、撤离焦点，清理旧显示引用；不隐式提交/取消业务命令，不另改暂停状态。宿主先将旧视图标为卸载中，再解绑上下文/通知、释放页面，防止旧回调恢复新会话输入。
- 宿主注册继续保留id/中文名/内容根，增加已有公开开放查询的只读callable。科研/船员/星球/星系/超空间逐项沿14§6.1原判定，不退化成统一Campaign.available。普通模块动作仍由模块/原注入callable直调。

## 输入与层级落点

1. 宿主自有更多/钱包详情：遮挡层在本宿主弹层之下，先关闭并消费外点；底层不可穿透。该遮挡不能直接复用于更低CanvasLayer的模块自有批量。
2. 模块独占UI开启：顶部入口阻断；在战场x808..1440覆盖只接输入的透明层；左模块内由原组本层遮挡保护自身弹层。避免高层全屏覆盖挡死模块操作。
3. Space/G：根main与CampaignView两个未处理入口均读同一宿主前端条件（活动模块独占UI、原生Popup/Window、当前UI键盘焦点），不向Session保存UI状态。只抑制UI占用期间的全局动作，功能快捷键仍保留，不自动暂停。
4. 普通切换：先询问占用/prepare_hide，允许后隐藏旧模块及其上下文，显示目标模块/上下文；焦点到可见入口。背景业务时间及既有视图显隐规则不变。

真实安装事实、重复chrome归属、局部必留空间和输入缺口已收齐；本候选已给出明确处理及四个最小视图端口，不再以“缺所有者说明”为停点。Godot图只是宿主设计呈现，模块仍占位。安装职责/四端口不重开；下一门槛是原审收尾的简洁对象＋等级文字和纯环境连续性，之后交用户整体确认。未经确认不修改模块视图或main，不宣称65px/最小可读安装/巨缝品质已获批准，不合main。
