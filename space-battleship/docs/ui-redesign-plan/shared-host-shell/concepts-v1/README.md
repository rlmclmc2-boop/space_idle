## 当前问题的来源与设计边界

`src/main.gd::_show_session` 将逻辑战斗视口 572×960 放进 632×900 右侧区域，按高度缩到 0.9375 后，画面实际约 536.25px 宽，右区左右各约 47.88px 不属于视口。这是可见黑边的几何来源。概念图的侧翼是有意设计的环境延展；实施时须在视口外**实际绘制**，而不是用不接环境的底板遮住裂缝。战斗投影、拾取、舰船和 HUD 的内部契约不由公共界面改写。

当前 `src/ui/shared_host.gd` 的资源与导航是独立深色矩形和普通描边控件，`src/ui/bridge_theme.gd` 是通用扁平皮肤；模块区与战场各自起笔，缺少统一的结构衔接。三案都以象牙/暖灰装甲、深蓝绿结构、少量青色和琥珀色强调为共同词汇，但信息层级和布局不同。模块/战斗内部仍由原负责人控制。状态、金额、入口语义与焦点/收起契约应保持；图上数字只是示例。

**选择门槛：** 用户先选方向或指出组合修改。此时不启动运行实现或新的实机验收；若选 B/C，先协商原组尺寸/HUD 约束。源图由本目录 `generate.py` 生成，PNG 是对应 SVG 的等尺寸导出，可供逐图审阅；概念稿不代替固定版本真实整屏。
