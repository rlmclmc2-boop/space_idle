基线为已接纳装备的 `main@e3b38d7b6d8256f6031e1b086c7db7812b6a441f`，本候选在 `design/clear-zone-host`。前期分区稿保存在独立概念分支 `design/shared-host-shell@fa28589b`，本分支不继承该分支的运行树。遵从用户后续要求：操作区和战斗区完整收边、字体和公共控件一致，分隔克制；去掉“战斗视窗”字样。右侧预留空间不加入环境或特效，后续由战场组处理。`51cc7c99` 的输入净空曾获限定通过，但用户随后退回整体公共 UI 质感、图标、空隙与贴边问题；该旧结论不覆盖本轮修订。当前 `c77afe04` 两模块组合已因用户反馈退回，待原组内部修订后重新整屏审核；未获准合入 main。

## 用户退回后的两模块统一交接

用户看 `c77afe04` 后认可质感提升，但指出装备与反应炉仍不统一、反应炉有文字超框且新控件受旧效果遮挡；**该组合已退回，以上历史“候选／局部通过”不能作为当前整体验收**。共享标准只在[13第 2.3 节](../../../game-design/13-art-interaction.md#23-所有模块共享的状态与反馈)和[14第 1 节](../../../game-design/14-ui-contracts.md#1-版本与使用边界)维护，本页记录当前源码差异与接力范围，不另立一套标准。

| 交接面 | 当前 `c77afe04` 的实际差异／风险 | 后续归属 |
