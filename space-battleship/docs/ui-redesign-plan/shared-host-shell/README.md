## 视觉与切换规则

全局只保留一层结构框。梁/接缝使用同一象牙色 `#ecebdc`、结构蓝 `#243d50`、青色 `#83cfcb`；深色阅读面维持对比。沿用仓库NotoSansSC发布字体；提案导航16px、主体文本16–18px、重要读数20–22px，模块已有较小的精确附值留给所属组评估。正常/禁用、焦点、选中不能只用亮度区别；选中用内凹底座、青色边和中文名共同表达。费用、失败和草稿靠近实际动作；全局保存失败单独持续可达，临时成功提示不占整个工作舱。

顶部导航每次只切换一个活动模块；同一模块不重复构建。切换和收起不提交、不清草稿、不暂停业务，不创建新Session。隐藏视图停无用动画/绘制，重新显示由其所有者处理待失效快照。选择/滚动/视角/焦点仍由模块保存；对象失效、开放集合变化和危险事务按原模块契约使旧预览失效。宿主不代替模块确认或撤销。

“收起工作区”通过模块入口梁末端的“更多→收起工作区”进入，仅隐藏操作内容，保留顶部入口、最后选中入口及完整模块背景的静态环境；不缩放/移动战场，不自动暂停。收起时停该模块工作动画，避免把静态底图误称设备仍在推进。恢复返回原上下文。更多菜单局限在模块侧，不覆盖战场；点击菜单外的首击只关闭菜单并消费，不穿透拾取。危险确认/系统文件选择器未完成时暂阻切换/收起；不以隐藏替代取消。危险确认维持既有语义，不添加自动暂停。活动UI占用时main的Space和逻辑战场CampaignView的G都必须门控，不能只挡鼠标或只挡root。

全局钱包只显示已接入资源，长金额采用所属公开格式化结果及单位，悬停给完整文本；资源行的独立“⋯”打开Economy.balance_rows全部现有资源及完整金额的只读明细，不与模块“更多”混用；不经float重建Amount。矿产不足仍在费用旁解释。保存“已保存”必须来自现行持久完成状态，排队不能冒充完成。设计示意数值仅沿用来源截图，不承诺自然游戏状态。
