# 反应炉核心主角构图 R2（待用户审整体空间）

用户认可 R1 的设备、控制台与舱室一体化语言，要求解除四角等权布局：核心成为主角，四台较小模块作为不同深度的辅助供能设备。本稿沿用浅暖装甲、深青舱壁、青/琥珀工作体及四种机器身份，改为巨大中央核心、后方左右壁架和前方左右地座。四条短接分别连到核心，承架、遮挡、地面和光照共用同一透视。前沿仅设一处主控台；各设备底座保留直接读控的视觉位置。**本轮只请审构图、空间主次及三/四设备状态，尚非可运行 UI 或 Godot 验收图。**

固定范围来自 [`4f4d63d5` 反应炉作图 V1](https://github.com/rlmclmc2-boop/space_idle/blob/4f4d63d57ddc215453993cce739eaa3eecfc4198/space-battleship/docs/ui-redesign-plan/shared-host-shell/reactor-drawing-v1/README.md)：内容 808×835，宿主偏移 (0,65)，安全内区 (16,16,776,803)，公共顶部 65、右战场 632 保持不变。该范围并未要求四机等大或严格四角陈列。
