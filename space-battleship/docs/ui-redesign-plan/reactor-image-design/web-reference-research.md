**推荐的适配判断（先交叉审，暂不生成）：** 现有核心和四小模组保留；把下一稿的主角定为紧贴核心外缘的**共同分配总成**，而不是房间外壳或横跨全屏的供能脊。分配总成有清楚的收能接口、四个输出接合位及适度纵深，四模组安装端与其短接口座插接。能源经过总成内部，必要窗口/接合处显示去向，不需要粗管串联；短读数和直接滑杆属于接口座或模组的操纵结构。核心主控继续位于同一总成近侧/下侧，预算与整组确认只保留一套。
