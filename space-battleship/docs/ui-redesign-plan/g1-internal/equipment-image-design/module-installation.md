## 可以分离与必须保留的内容

品牌、顶部钱包、“战力维护 / 装配”可在未来宿主接入时由宿主统一承载，避免重复；这是装备组对归属的确认，**当前尚未拆除或加开关**。钱包仍由Economy预算驱动，迁移时由对应所有者提供真实钱包，不把经济位置通知变成装备全量MAX重读。现有“舰桥面板”按钮在main的CanvasLayer 10、position(678,48)，属于宿主全局导航而非装备根内容；其矩形未由装备代码固定，不在本说明猜测最终宽高。

局部必须保留：当前舰名、独立全部装备升级、武器/防御槽选择与真实启用/空槽/休眠状态、当前装备和付费等级、当前/升级/候选比较、费用与不足原因、冷却、+1/+10/MAX/购买、候选浏览与安装、实际回执及批量明细。费用/比较不能随顶部钱包一起移走或用全局钱包替代；槽位开放与候选装备解锁分开。局部读数并非只存在顶部：现装标题(42,610,330,29)、等级(383,615,70,22)、底部反馈(25,875,757,24)均要保留空间。

## 当前可读尺寸与缺证

本组仅确认已有证据下**1440×900逻辑窗口、装备808×900、1:1原像素**的安装事实和可读呈现，不宣称这是经测得的最小可读尺寸，也不等于当前整体视觉通过。根minimum声明808×900不是缩小实验。未测试更小安装、65px重排、DPI/系统缩放或新宿主映射；本次不新增测试。

现有实现取样：主值27px；标题18px；常规按钮16px；槽名15px/槽元信息12px；比较及资源说明12–13px；候选状态与冷却最小11px。现有数量键59×37、购买218×40、安装244×36、候选65×89、槽终端220×82；批量按钮最小270×44。这些是源码值及既有实图的取样，**不是已批准的通用最小字号/命中标准**，不得据此继续整体缩小。长值保留业务格式/tooltip，不通过统一缩字号让位；长金额多资源先前证据见[工作台交接](../../../verification/equipment-hangar-godot/workbench-pass/README.md)，该页固定旧提交，不能升级为本次新宿主验收。

不得把底部y875..899反馈裁掉、裁去费用/安装/候选、压缩批量面板或缩放正式船/炮资源来强行接入。右战场保留现有同轴等比投影/拾取坐标；装备组不改其几何。未来宿主若映射坐标须明确绘制、输入和弹层的同一变换；当前没有该新映射的实测证据。

## 自有弹层、焦点与显隐责任

普通槽位、候选、购级均为根内非模态Control；图标/Label设MOUSE_FILTER_IGNORE，根MOUSE_FILTER_PASS，按钮接pressed。长值等tooltip为现有Control原生提示，不是新的跨模块抽屉。批量面板是根内PanelContainer，**不是Window/PopupPanel的全局模态**：遮挡ColorRect(0,0,808,900) z19，外框/内容(90,180,628,590) z20/21；内边距30；OptionButton有原生下拉PopupMenu；明细位于ScrollContainer。打开时将遮挡/外框/内容移到根子节点最后，显示并读批量现状；关闭按钮仅隐藏这三者，不提交、不清掉已存的最近批量回执。历史[批量部分结果图](../../../verification/equipment-hangar-godot/workbench-pass/candidate/12-batch-partial-result.png)本次实际查看，仅佐证旧版808×900内弹层呈现；其来源提交在工作台README，非本次新取证。

代码未显式设置焦点抓取/限制循环/关闭后焦点恢复，也没有Esc关闭或向宿主发布“模态开启/输入占用”通知。遮挡没有显式设置mouse_filter，不能仅凭z_index推断跨CanvasLayer键鼠封锁；当前main的全局导航在layer10，高于装备layer9，**根内z19..21不能遮挡更高CanvasLayer**。main还持有未处理空格暂停；批量开启时该键、OptionButton弹出时以及切模块的焦点行为缺新宿主证据，不能声称全局暂停被批量模式截获。未来宿主需决定导航可否切换、焦点与全局快捷键优先级，并与模块补最小呈现通知；本次不新增接口或默认以弹层暂停游戏。

当前装备始终挂载，main切growth页只显隐growth面板，没有显隐equipment_scene。装备 `_process` 在不可见时直接返回；已有所属模块信号仍累积dirty/comparison_dirty，恢复可见后按待刷新处理。未实现模块呈现激活/失活通知、切离时关闭批量/下拉菜单及焦点恢复约定；不能宣称已有“切页自动收拢全部弹层”。未来宿主负责模块根挂载/显隐及全局输入统筹，装备负责自身选择/回执/报价/冷却和局部弹层内容；跨层遮挡与恢复策略需双方接入时明确，不能用隐藏视图修改业务暂停或安装状态。

## H2约束与当前方向状态

H2保留808×900可以作为当前尺寸讨论前提；“仅替换重复顶部”须显式分离上述全局元素，同时确认y65..80副标题及y85起场景与y96批量入口的边界。不能先把原画布裁成808×835、把全根下移65px或全根压缩后称等价；也不能保留原全局副标题再叠一条新导航。65px仅为宿主待决方案，装备组本说明没有同意该高度能解决所有冲突。局部标题、批量入口、根内弹层与更高层导航冲突由宿主整体方案解决，不要求本组先重排。

图稿状态与代码严格分开：用户最新反馈“新的装备可以，不过防御怎么展示再想想，武器认为没问题”，据此固定U1武器展示方向（轻量侧索引+单选实际部件关联），不重做武器/整体布局；防御展示仍待推敲及原审/用户确认，侧边保留槽选择，不能编造武器物理挂点。U2厚轨/穿线仍WIP，不并列成熟。图稿下方不算完成稿；下方保留原结构，仅字体层级/图标视觉中心/对齐内边距/按钮规格/资源区疏密待打磨。没有恢复B/C整页方向，也没有授权把生成图的导航/右HUD或下方重画接入。本文仅记录接入现状，不生成新图，不恢复代码；防御后续图稿另按原模块任务推进，武器认可不等于代码实施授权。
