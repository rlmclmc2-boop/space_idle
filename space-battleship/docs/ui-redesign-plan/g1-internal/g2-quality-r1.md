## 可迁移规则与Godot还原

1. 每一级导航只承担一次定位：A仍按模块，B仍按工作组/关联对象；同组摘要不再另占一排大卡。目标对象标题与即时状态同行，详细事实属于场景旁操作台。
2. 场景是可工作的空间。背景、设备、探针、读数台、预算台分层；实际动作紧邻所属对象，候选、已接纳、费用、错误保持明确区别。装饰不能截获点击。帮助按需展开，危险后果和失败恢复常驻。
3. 材质统一靠层次和结构：深蓝承重边、象牙白面板、青色运行指示、琥珀候选/警告。控件与场景共同使用这些材质；不靠给每个容器套框获得层级。
4. Godot用持续存在的战场根和独立模块Control。模块舱宽808，不因切换/收起改变战场R/T；不对DPI和引擎比例重复变换。导航、场景与操作台使用独立布局/卷动职责。
5. 工厂分背景TextureRect、设备与探针TextureRect、实际读数Control和前景预算Control。当前浏览器装配参考：场景宽约744，背景保持源宽高比、宽140%、left−38%；设备300×300、left27.5%、top95；探针75×70、left24%、top44；读数台left18、top392、宽48%−34；预算从48%横向锚点起。按图像透明边界校准安装盘，不把300px容器当设备有效像素。临时动画只作用视觉子节点，输入仍在稳定Control。
6. 星球/星系继续消费原表面、云层、设施与GLB导出图；世界坐标、地图平移缩放、身份选择不随容器重排重算。右侧详情允许自身卷动，未知信息保持隐藏。

源资产沿用S6/S9/S10及 `assets/ai_tech_factory/README.md` 的既有背景、八设备、探针；本批未生成或替换资产。还原应引用原资产，不能以证据整屏贴图替代场景。
