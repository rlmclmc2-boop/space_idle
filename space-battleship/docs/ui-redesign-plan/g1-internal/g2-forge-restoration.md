## 预览、回执和继续操作

- 预览不改实体、随机、钱包。对象/操作/目标/保底/源revision/主动收藏变化使旧预览失效；确认使用同一意图，材料不足保持当前并解释。
- UI预览包含本地operation_id；真实命令仍调用Session.forge，原Session负责相同ID相同内容返回原结果、不同内容拒绝，不新建通用日志。
- 拒绝和“已付费但未升阶”分开。每次结果显示实际支付、余额和实体前后，不把随机未提升说成未扣款；最近回执标清操作，不冒充下一报价。
- 同一对象可继续：保底→现代化→付费未提升→再提升1阶→加词缀→定向替换→锁定→重抽未锁/参数→预兆开关→究极/还原→定向传说/参数重抽；所有原保护与挂设继续保留。
- 同一回调复现返回同一最近记录且不再扣费；冲突签名明确OperationIdConflict。此处仅镜像原生幂等语义，未接真实文件或RNG。

## 传说图鉴

十二效果以各自中文名称、已见/未见和主动收藏区分。未见不可主动收藏；已见可收藏/取消。图鉴主动收藏只决定定向升传说，与单机主动收藏、预设/装备/封存拆解保护独立。定向选择只列当前武器相容/通用且已主动收藏项。已获得传说显示随机参数当前原值、可重抽区间与按需参数含义；无随机参数的固定机制明确区分。不同武器源/同效果唯一来源评分仍由native/所属模块输出，不在此按DPS改规则。

## Godot还原与接口边界

层级：ForgePage → 当前对象选择条 + DroneSourceRig（TextureRect/形态/普通与额外词缀/锁定/传说参数）+ OperationConsole（具名操作/目标参数/Quote/保护范围/确认/回执）；LegendCollectionPage → 十二效果已见/主动状态与操作。纹理沿四家族原图可见框及前批8px安全边界装入；新背景/边框/读数都是Controls/纯呈现，不向后端传像素。

已核对可复用：Session.preview_hyperspace_forge(id,operation,args)只读返回候选/costs/draws；Session.forge(id,operation,args,operation_id)负责付款、最终配装合法性、发布及幂等。Hyperspace.warehouse提供实体、legend_collection/set_legend_collected提供图鉴，player_catalog提供选项ID。`target_affix/target_effect/guaranteed/target_level`沿原参数名；不是旧reroll/refine别名。预览中即便提供方返回了随机候选，也只展示范围/费用/保护；正式结果后才显示实际新参数。

仍需原线程核对/最小输出：

1. 本机affix_limit、允许/保留hanging_limit、现有形态/究极额外词缀与操作拒绝原因。不能假定候选forge_display_limits已在main；前端不读私有配置表。
2. 所选词缀及传说参数的原值/格式化值、min/max、锁定与可改范围。catalog只给ID，不等同完整范围/当前值。
3. costs的canonical Amount文本与显示文本、可支付/具体不足、精确draws；沿原Amount/付款查询，不能把已格式化中文价串反解为数值。保底/定向/现代化必须复用原报价，不前端算公式。
4. source drone稳定ID+现有forge_revision用于局部预览失效；确认仍按原命令重验，实际发布结果优先于旧预览。不要求新全局revision系统。
5. 完成后的当前实体/余额/图鉴/派生武器贡献只消费所属提供方响应；选中实体消失清旧详情。真实Higgs/传说/究极上限等最终配装检查不移到UI。

相关界限澄清：原prepare_hangings/preview_forge仅拒绝封存/不存在，未禁止溢出区改装；本批移除前批演示擅加的“仅主仓可改装挂设”，仍保持**仅主仓未封存可装备**。溢出整理后可装备，改装按公开准入。未改实际玩法。
