## 两方向的工作结构

| | A · 机舱现场 | B · 作业编排 |
|---|---|---|
| 首要组织 | 从模块直接进入当前专属场景，围绕设备、槽位、人物或设施工作。 | 从战力、殖民、超空间收获、航行维护进入关联对象；同一行显示当前状态，下面只展开当前工作点。 |
| 连续使用 | 各模块保存对象、草稿、子路由与滚动，返回继续。 | 每个作业保存最后路由；关联摘要读取同一演示对象，购级/派遣/科研应用后更新，返回不再强制第一步。 |
| 共用部分 | 同一稳定战场、基础动作、对象/比较/费用固定操作区；不强造操作差异。 | 同左。去掉重复路径导航，关联摘要承担跨系统记忆；仍须以实际路径证明不是A加一排卡片。 |
| 当前主要挑战 | 专属场景的真实资产、完整运行状态与观看品质尚待深化。 | 关联层收益与高度代价继续待审；摘要只有对当前作业有价值时才出现。 |

主设计客户区1440×900；1280×800/1600×900仅暴露边界，不同步精修。战场外框固定约465×750，投影宿主约431×662、s≈0.690；模块切换/开合默认不改变投影。工作区约923×750：导航56，固定动作区100，余下显示主体/详情，B仅额外占一行关联对象。固定动作同时携带具体对象、本次比较/取舍与费用，不以按钮固定代替决策信息可见。

572×960是逻辑投影参照，不自动成为最终裁切框；视觉安全区须另计炮台、盾、双条/文字、五无人机与效果。预览“装配边界”为候选留白示意，未定完整包络；不得据此外框锁定贴边遮罩/导航位置。统一缩放不消除逻辑相对重叠，不扩拾取或移动真实炮口。

## 全系统的实际安排

| 系统 | A的当前工作点 | B的关联及当前路径 |
|---|---|---|
| 战场/航程/资源/属性 | 稳定战场、UI HUD，按需明细。 | 共用战场；摘要不复制全局余额，属性可从配装工作点展开。 |
| 舰体/装备 | 舰预览、前置比较/费用、完整3武器2防御槽与固定购级/换装。 | 战力作业的配装对象，摘要携带实际槽位/等级/候选；可到供能/科研后回原槽位。 |
| 反应炉 | 核心—主管—设备分支，实际/草稿效果与具体调配任务。 | 战力作业保持装备/科研摘要；任务把熔炼15单位转给武器、防御35保持。 |
| 科研 | 当前设备/研究、保留工作量、投入草稿/当前值、应用与选择。 | 当前研究与生效投入进入摘要；切模块不丢未提交草稿。首批已补双资源投入与自动预算/岗位续研分离；全部状态与真实接入仍待G2。 |
| 强化 | 顺位、分支、购级工作点已安排，详情可达。 | 战力作业可从全系统索引进入并保存路由；完整顺位/分支操作仍待G2。 |
| 船员 | 真实演示成员/当前占用、派遣草稿、确认/释放与目标返回。 | 殖民/超空间作业共享同一成员事实，切换任务后摘要与目标人数更新。 |
| 星球 | 球体/轨道设施、施工/缺人/ready/已领；人员、自动/取消与重铸入口。 | 殖民作业保留人员/星系对象；人员调整后返回设施与当前状态。 |
| 星系 | 地图节点与施工/升级/完成，所选节点详情，无领取动作。 | 殖民作业保留星球/人员对象；调整人员返回原节点。真实GLB、相机操作仍待G2。 |
| M9路线/回执/仓库 | 具名子路由、路线对象、启动/停止/回执→领取→仓库。 | 超空间作业的任务对象；返回恢复所选路线/仓库/无人机。 |
| M9无人机编队/详情 | 从仓库选择对象进入独立无人机编队，展示母舰容量、当前/候选、装卸清单再确认。 | “编队”明确进入hyperspace/formation，绝不进入普通舰体装备；摘要显示当前无人机与候选。 |
| M9改造/过滤/材料/挂设/保护 | 各有可追踪子路由；改造预览/取消/结果，规则应用/导入审阅/导出，兑换，挂设/保护/封存对象详情。 | 选择/草稿跨子路由保留，back返回来处；完整条件、随机/保护约束和全部业务仍待G2。 |
| 保存/设置/危险事务 | 保存状态页；重铸/导入/新游戏各自来源→持续预览→确认/取消/失效→结果。 | 航行维护保留上次事务子页；来源变化关闭旧确认，取消不改当前航程。 |
| 档案/通知/教程 | 信息分类及详情入口，教学检查说明移内部层。 | 航行维护对象，已见/已读及完整教程仍待G2。 |

## 关键路径与状态

- **换装/购级**：先看当前与候选/购级后属性、具体费用，再购级。MAX先切到该模式并显示本次4级/总费；不能在看不到报价时直接执行。固定区和首屏比较引用同一对象/报价；冷却与不足保留原选择。
- **B关联**：武器槽选中/购级→反应炉草稿→科研修改并应用→切到殖民→返回战力，恢复最后科研子页及关联对象；科研草稿不因仅切换覆盖。成员派遣→目标场景→返回同一成员。作业摘要随实际演示状态刷新，不写死原配装、人员或研究。
- **反应炉**：查看“熔炼15→武器、防御保持”的方案，武器增益×1.28→×1.40、熔炼×1.18→×1.05、防御×1.21保持，本次费用0；核心/主管各支路及设备读数对应当前实际与草稿。按既有单设备命令先应用熔炼、再提交武器；每步更新实际，未应用意图可还原，已成功部分不伪回滚。上述为固定演示快照，非真实求值；未知组合不假造效果，缺效果预览时不能确认应用。
- **M9**：路线→回执→仓库选d2→无人机详情/编队→装卸预览→确认；仓库单选→改造→预览→换对象旧预览失效→重新预览/取消/实际结果。过滤导入先审阅，非法文本保留原规则；返回仓库仍保留所选对象。
- **危险事务**：从设置或星球进入具体事务，修改来源使旧预览失效；确认仅绑定本次来源/保留对象，取消不执行，完成后确认关闭并保留结果。当前仅演示路由/事务UI，不做真实保存、重铸或会话替换。
