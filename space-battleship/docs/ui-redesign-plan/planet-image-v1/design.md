范围仅星球 M7/V7；整体视觉沿[13共享规范 bf359c0d](https://github.com/rlmclmc2-boop/space_idle/blob/bf359c0d9073e064f71028958a21a649b3951875/space-battleship/docs/game-design/13-art-interaction.md)。规则仍以[03 §5](../../game-design/03-progression.md#5-星球探索与建筑)为准；不以本页新建规则。

场景焦点是正在探索的星球及轨道发展。球体与独立云层继续使用现有着色器/配置身份；图中的生成画面只表达构图，不作为重画资产或替换模型的许可。设施继续映射实际 `(planet_id,id)`，空间站双翼、双横罐精炼厂、压床工坊、U形船坞沿现有模型识别。图稿中的高光、云层细节、字号和控件尺寸均待审，不冻结为产品参数。

## 图中状态

这是构造的排版样例，无对应运行会话或存档。始源星探索度68；探索者1人，本次进度68%；自动探索开启。空间站与工坊已领取；精炼厂 ready 未领取；船坞 building，38/180次，额外施工人员1/1。第一星球船坞D30开放，跨门槛那次不施工，D68对应38次；工坊D50开放，累计10次后可在D60领取，故D68已领取可成立。精炼厂故意保留ready，不显示其生效倍率。所有资源、战场关卡、舰船和生命盾值沿风格参照作为构图背景，不证明同一真实配置/进度组合。

探索度是累计次数，故已移除首稿错误的探索度百分比条。68%的条仅指当前一次探索。施工38/180是探索完成计数，不是秒数。重铸预览因船坞未领取而禁用，不能在本状态发起首次征服。

## 对象与操作

| 场景对象 | 当前常驻 | 按需操作及关联 |
|---|---|---|
| 星球及标题 | 名称、探索度、紧凑切球 | 只在可用星球间选择；切球清掉旧对象详情/短反馈 |
| 探索机及航迹 | 是否推进、探索人数、本次进度 | 人员入口只定位到该星球的船员派遣；不新建自由加减人数命令 |
| 空间站、工坊 | 物体及已领取状态 | 选择对象展开当地详情；工坊倍率仅使用已接纳的source_factor |
| 精炼厂 | ready、待领取、领取按钮 | 原claim_build；成功后才切built并读真实贡献，失败留在该设施旁 |
| 船坞 | building、施工计数、额外人数 | 选择锚定详情含D30门槛、施工需求及人员入口；禁用领取 |
| 场景边缘控制台 | 当前自动设置 | 本次完成后停止调用关闭自动；立即取消独立进入现有协调命令 |
| 累计加成／重铸预览 | 紧凑按需入口 | 加成读已领取/征服事实；重铸打开既有预览—确认流程，显示损失/保留/收益，不直接执行 |

## 后续状态，尚无图像或运行证据

| 真实状态 | 应有表现 |
|---|---|
| 未达设施门槛 | 仅实际适用设施可查门槛；不可展示成已拥有的活跃轨道设施 |
| building且缺人 | 同一设施读数保留已积累次数，显示具体缺人原因；不播放施工推进 |
| 无探索者／未运行 | 航迹为静态定位；设施暂停原因与探索状态关联，不伪造倒计时 |
| ready | 琥珀标记+待领取文字；未领取不显示已生效收益 |
| built | 领取成功后更新该对象，已接纳贡献可查；不保留领取按钮 |
| 关闭自动且本次进行中 | 设置显示关闭，本次仍推进；与立即取消清本次进度区分 |
| 全局暂停 | 状态静态可读，探索/施工不假推进；仍可选择、查看与取得合法UI反馈 |
