# 文档整理交接

目标：现行规范与各组入口各守自身职责；有效制作要求表达为目标、接口和完成标准。依据为用户本轮清除非必要防御性提示词、规划职责收敛及各线程交接整理要求。

工作源：`docs/design-entry-cleanup-20261031`；各组源由[11](../game-design/11-stage6-contract.md)定位。文档差异独立于游戏运行代码。

当前一步：完成纯文档发布与原组安全消费核对，记录实际HEAD及消费范围。制作中WIP由各原执行者/新接替者保留，按文档差异接入。

完成标准：现行规范只有一处正文、文件与锚点闭合、改前原文已独立保全并回读，主线和各组实际消费状态清楚；未决问题有双方来源。当前规则问题见[问题页](../game-design/review/conflicts.md)。

恢复：从本分支固定Git版本接续；构建/运行说明见[foundation](../../foundation/README.md)，审核与日常清理方法见[07](../game-design/07-verification.md#5-实施顺序)。
