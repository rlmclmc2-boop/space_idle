# 独立评测 A：正常新档 1–7 关

**冻结基准**：`7350199bca810209f505561ddb7a5be1a7059bdd`（`main`）。**结果**：第 7 关 9/9 通关，左侧“异空间”入口开放并可进入“异空间探索”页；没有挑战异空间第 1 层。截图见 [证据目录](evidence/20261017-independent-a/)。本报告在未查看其他评测或实现结论的情况下冻结。

## 方法与边界

- Godot 4.6.3 Linux，Xorg dummy 1600×900，Mesa llvmpipe；实际游戏窗口 1373×883。指定 Windows Godot 4.7.2 环境未提供，音频设备初始化失败并回退 dummy，**音效不评分**。隔离的空白 XDG 用户目录启动正式 `main.tscn`，通过实际 UI 鼠标点击与输入做选择；进程在查看截图期间暂停，未注入存档、关卡、资源或游戏内部状态，也未使用模拟器决定路线。进度在游戏“手动保存”按钮保存到隔离用户目录；存档不入 Git。
- 自动战斗默认推进，驻守关闭，普通速度。截图是离散取样，未录全程视频，未测每点精确耗时；下表的“缺口”表示只能从下一点的 UI 进度确认经过，**不对该点画面、数值与体验打分**。第 7 关结束后为验证保存入口，自动倒计时曾进入第 8 关 0 点；第 8 关不在本轮评测内。
- 所有投入均来自普通战斗掉落。起始 0 铁、0 铀。第 1 关末首次花 65 铁升复合装甲；第 2 关换追踪导弹、反应炉初始 100 能源“均分”后分别获得约 +17% 武器、+16% 防御和铁掉落；第 3 关换偏转护盾、磁轨火炮，反应炉花 10 铀升 2 级并“均分”。第 4–7 关继续用掉落购买装备和反应炉等级；第 5 关起铁增长很快。第 7 关末为打“异空间门卫”，光束槽升到 Lv.16、护盾槽升到 Lv.19；通关时约 7.6K 铁、187 铀、0 强化碎片。装备是一个武器槽、一个防御槽，免费换装时等级保留。
