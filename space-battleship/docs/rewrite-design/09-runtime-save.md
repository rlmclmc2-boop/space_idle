# 09 大数、时间、保存和生命周期

## N01 数值分类与共同算法

统一BigNumber为非负有效尾数+十进制指数（零独立规范值）的有限精度类型；native实现，GDScript通过同一API使用，不写第二个float公式再溢出回退。尾数采用binary64精度，指数使用明确有界整数；可表示范围超限明确报错，不能声称数学无穷精确。负差值用于报表另有符号，不允许负余额。具体数值范围D05批准后固定在formatVersion，不能因某后端不支持而静默降精度。

API：parse_decimal/string、normalize、compare、add/subtract_checked、multiply/divide、pow/log10、floor/ceil/round(step)、min/max、ratio_clamped、format、serialize。小量低于相对精度时统一舍弃，不设补偿余额、整数精确账本、残差追踪。ceil/round在可表示精度下定义，费用/显示/支付共用结果。概率与短时长等有界float仍用显式范围检查，复杂增长链不得先转换float。

| 类型 | 建议范围与序列化 | 不可混淆 |
|---|---|---|
| 余额/伤害/HP/保护/债务/经验/研究工作/成长倍率 | BigNumber；序列化规范尾数字符串+指数字符串 | JSON数字不得截成2^53边界 |
| 购买级、全局历史、degree、挂载级 | 按玩法可增长范围D05；无界则BigNumber整数语义，有界则整数+明确上限 | 不自动把所有循环次数定义无限 |
| 槽位、类型、节点数、每批数量、派生深度、预设索引 | 有界整数 | 大余额不许可创建无限弹体 |
| actor/run/command身份、RNG状态 | 无符号整数/字符串稳定编码 | 身份不是经济大数，不取近似 |
| 真实时间戳、短计时、几何、UI比例 | 单调时钟/有限double/Vector；显示比例夹0..1 | 不用墙钟直接驱动战斗 |

## TM01 时钟与完整推进

一个Session入口`advance(realDelta,focus,pause)`：检查合法delta与无重入→处理真实时间保存期限→若暂停则不推进游戏/不耗加速→后台强制默认倍率→按当前粒子余额分割可加速真实时段与默认时段→生成游戏时间→固定步推进。加速只在这里乘一次，粒子成本按真实秒扣；资金不足后余下真实时间按默认倍率，不能丢掉或双计。

小于1/60的剩余游戏时间由Session唯一持有；为支持同一帧余额耗尽，最多需要有序的时间段/单个待处理步，不能每域再有一套支付预算。接受粒子消费与时间段登记同步完成，帧预算不足保留剩余，恢复只处理未完成步。不开启任意半步可回滚框架：数据/能力在推进前校验，完整步内部无UI重入；意外内部故障停止并禁存半成品，报告恢复上一有效存档，不能重放已发生伤害或继续接收新时间。

共享域顺序保留建议：手动异空间计时→生产游戏钟→后台异空间→武器临时计时→星球→银河→船员→顶部资源→科研→普通掉落到期→自动投入刷新→战斗阶段；到期战斗事件内部按04。若改顺序会影响同刻消费/收益，必须显式审阅，不能“模块化”时随意按字母排序。

实时自动保存/提示采用单调时间；在线统计另用真实时刻；离线差值只用持久UTC时间且向下取整/非负夹界。离线粒子=floor(min(max(floor(now−savedAt),0),offlineMax×3600)×particlesPerSecond)，再限制到floor(capacity−balance)，capacity=offlineMax×3600×rate；不发部分粒子，每次启动都显示实际获得含0。离线不补科研、探索、生产、战斗。时钟倒退获得0；本地时钟异常如何额外提示不改变收益公式。

## SV01 新存档结构

`SaveDocument{formatVersion,configId,savedAt,settings,progression,economy,equipment,enhancement,reactor,research,crew,hyperspace,planets,galaxy,random}`。每节由域明确导出/校验；不序列化整对象，不依赖属性反射扫出所有变量。formatVersion是新格式，与旧v4/v7等无自动兼容承诺。

保存字段逐类见03，额外明确：装备换装冷却保存为剩余游戏秒或与productionTime配套截止时刻，二者择一且不会离线消耗；科研/星球/银河/后台工作保留已实际发生的工作；教程earned/seen/read分别保存；BigNumber与RNG稳定字符串。普通战斗HP/敌人/CD/弹体/临时buff/债务不存，普通读档从保存旅程位置新建合法战场；不能保存半个native状态又接旧GDS场景。

手动异空间started的读档语义受D01/D02限制，须选中断取消或重新开始；completed_pending冻结奖励和结算身份必须保存，恢复不能重抽/双领。若以后确认收费，只记录实际付费与一次性处理结果，不再保存暂停主线战场。

## SV02 写入、读取、导入导出与失败

仅定时/手动进度保存；默认1正整数分钟，可编辑，真实单调时间不受暂停/倍速/前后台影响。迟到只保存一次，下次从现在算；改间隔只重置期限不写盘；手动保存不改变自动期限。业务、启动、退出、升级、拾取、切页、重启不暗存。UI显示“未保存进度可能丢失”和最后成功时间。

`save()`在完整逻辑步边界取域组合→校验→临时文件写/flush→读回校验→保留上一有效备份→替换正式文件。失败保留旧文件/内存业务结果，成功时间不前移，下一期限或手动重试；不用后台保存候选队列。文件失败不能造成双重收入或回滚购买。

`load/import`先解析和全量校验临时数据：版本、ID引用、余额、容量、任务与船员占用、分支合法性、run结算状态、RNG、蓝图。不得按缺字段补入历史默认玩法。准备好新Session后一次替换，失败旧会话继续/启动显示明确错误。正常load可读取已验证备份；导入文件损坏不能自动覆盖本地进度。用户显式确认导入后才替换当前进度/文件，导入前可留备份；导出仅导出有效快照，不改变自动保存期限或假装已写主存档。

删除存档是游戏内显式操作：仅目标进度槽，不删配置、素材、QA/音乐偏好；取消不动文件。旧格式不支持时解释并允许用户另存备份/新开，不擅自删除用户文件。要求“不保证连续性”不是授权启动自动删盘。

## LC01 会话替换矩阵

| 操作 | 保留 | 清理/重建 | UI和失败 |
|---|---|---|---|
| 普通死亡 | 永久域、余额、历史、建设科研 | 战斗按退却/复活规则，非立即清所有掉落 | 死亡模式选择有效，禁止半场换内核 |
| 换装/升级 | 已出生攻击、合法历史、债务 | 仅受影响新属性与容量 | 保留滚动/选中，失败无变更 |
| 进/出异空间 | 永久域和已结业务 | 原战场清空，返回D01 | 不恢复隐藏战场快照 |
| 读档/导入/重开 | 来自选定保存事实和独立设置 | 全部旧native/表现引用失效，新会话代号 | 完成后才显示ready，失败不混入新域 |
| 重铸 | 08矩阵 | 本轮成长和战斗；全部旧报价失效 | 预览明确，不隐式写盘 |
| 配置导入 | 新包仅成为下一次显式会话配置 | 重启时重算派生值/检查引用 | 导入成功≠当前游戏已切配置 |

平台层只提供文件/时钟/进程接口。无需ProgressRuntime、ProductLifecycle、CommitEffects、StepProgress各自另包一层所有命令；上表由少数具体函数完成，保留文件安全替换和完整会话安装这两个真实边界。
