# 父协调者约束恢复

本文件仅由父协调者维护，供父在任务分配、验收和上下文恢复时读取。独立线程不读取、不维护整份文件；父仅下发当前任务必需的最小约束。后续双方明确确认的长期规划由父更新到原条目，撤销或被替代的约束及时移除，不累积历史版本；最新用户指令优先。技术规则与操作入口见 [WORKFLOW](WORKFLOW.md)。

1. **授权与任务边界。** 新任务、新线程、独立复测及并发扩展均须用户明确授权；只使用指定环境并履行指定角色，不擅用用户电脑。实现交付不等于持续试玩完成；按约定范围和终点停止，不自行补任务。区分环境故障、必要依赖、可避免空闲和已完成范围；运行标记不证明工作或恢复。角色与互评范围按用户明确分工，不自行扩大或排除；表现专职仅实现、不测试、不参与评分；依赖等待只阻塞依赖它的工作。

2. **Git 与发布。** Git 是交接和恢复的主要依据。只上传任务代码、必要测试资产和明确获准的数据；凭据不得入库；玩家存档、缓存、原图、聊天及详细报告未经明确许可不得上传。阶段成果保存到工作分支并回读远端提交与树；候选不等于 main，正式合入须父验收并回读远端。保留无关改动，不扩大特例许可。

3. **独立判断与验收。** 每位参与者独立分析，交付先给接受或拒绝结论、至多三项关键风险、证据范围与建议；父指令与证据冲突时应明确反对，不能转交判断责任。保留玩家分歧，父记录采纳、延后或拒绝的理由、负责人及修改后的观察结果。复查旧低分项与复发，每项保留负责人、下一步及验收证据；实现完成不关闭体验问题。既定四方互评：发现20／修正25／对照25／实玩20／协作10，各方取另外三方评分的最低值；未齐或过期须如实说明。系统价值与协作评分分开，分数、旧评分和提交数量均不替代新验收证据。

4. **性能与画质。** 优先真实整帧耗时、尾部卡顿、明确余量与动态画质。父主动跨语言、引擎与技术领域查阅网络一手资料、源码和成熟案例选择方向，核对版本和适用边界；外部案例不能替代项目实测。结构改动前测主要成本及可得收益，无收益则撤回；反复微基准不算突破。比较须同环境、同负载、干净隔离并重复测量，注明自然试玩或 QA、固定吞吐或 1×、软件或 GPU 渲染及未覆盖范围。保留状态、随机序列、战斗顺序与画质；不能靠明显降画质宣称优化，诊断性关闭效果仅提供边界。

5. **玩家体验与节奏。** 从普通玩家可见信息判断，不依赖作者知识；主界面简洁，次要细节深入查看。持续试玩记录系统动机、投入、操作、卡点与负反馈，不把可运行当体验通过。先审逐波战斗、等待和重打，再审投入前后推进及解锁前压力、解锁后释放，最后看总时长；同时检查敌方耐久与玩家生存压力。累计失败数既不是验收指标也不是停止门槛，不能以少失败为优化目标。QA 遇损坏、非有限数据或非法状态须中止；长期无前沿推进时结合收入、正常购买、生存、击杀、敌方剩余耐久和最远波次发诊断警告，不自动停止积累或削弱敌人。

6. **试玩轮次与接续。** 新一轮普通新档须先有充分、连贯的改进并通过针对性快速 QA，再按明确授权以新线程、正常资源新档开展；小改动复用最小相关检查，无未闭合风险不重复宽测。区分正常资源 1×、加速和定点夹具，记录版本、初态、修改与证据限度；不把混版本或断线墙钟算连续节奏。获准的三方试玩由两位主动策略玩家和独立低干预父样本组成，彼此不预知策略，旧轮意见与进度留给父比较，不灌入新玩家上下文；1–20 轮到达 20 后保存并结束，不在边界继续 farm。持续保存版本、输入、进度和恢复检查点；断线约五分钟后实际重连原环境，常规断线不逐次通知用户，成功工作区操作才证明恢复。长上下文替换须获用户许可，最小交接保留证据与未闭合项，不复制整段历史。

7. **玩家数字与说明。** 百分比显示整数；未缩写的普通小数仅允许 .5；资源显示整数。39.1K 等缩写可保留必要精度；显示规则不擅改内部数量、计费或扣款。文字说明必须与实际机制一致，具体契约见 [UI_TEXT](UI_TEXT.md)。

8. **维护与汇报。** 每三小时内部整理，按用户约定时间汇报；完成授权工作即停止，不制造忙碌。问题、缺失证据和未验证范围须直说。约束改变时更新原条目并删除过期规则，不堆叠历史结论、临时进度或聊天；每个事实只保留一个权威来源。正式交接须核对当前私有台账，检查通过只证明完整性，不证明结论真实。
