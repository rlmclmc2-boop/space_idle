# 熟练与暴击强化

- Proficiency10B compounds per full same-primary-target game-time interval, independently per weapon; extra/secondary/chain targets do not reset the primary lock. Critical20B stacks are capped and refresh as one timed group; Critical30B keeps its guaranteed event separate from the underlying chance that retains critical damage. Branch transient timers/targets are bounded by active modules and cleared by the existing full-health reset; dead/removed enemy source histories are pruned.
- Only eligible critical effects apply enhance_config base probability and effective-level critical damage; equipment-authored critical probability remains independent. Enemy stats remain table-authored. Proficiency/adaptation retain the authored log-counter growth and rounding rule. Automatic crew enhancement buys one affordable shared level per existing configured assignment cycle; direct drops, reactor condensation, galaxy/crew fragment modifiers and the existing furnace remain currency producers. Spending never enters production income.
