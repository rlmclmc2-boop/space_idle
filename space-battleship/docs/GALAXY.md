# Galaxy

Authority: `config_excel/galaxy.xlsx`, `galaxy_build.xlsx`, `galaxy_config.xlsx`; GLB pipeline: [assets](../assets/galaxy/v3/README.md). Unlock requires cleared level 60 **and** six conquered planets, using the existing unlock system.

- `locked → available → exploring → developing → complete`. Exploring advances `explore_work` by `(base + crew × per_crew) × online dt`. Compact cells follow that progress through an indexed connected frontier; they do not determine duration or building capacity.
- Seeded macro slots unlock by progress. G1 defaults to 30 functional slots surrounding a separate core. Slot count is independent of map dimensions. Each normal bag contains each configured normal type once; every `special_cycle` rounds gives a special attempt. An attempt without an unlocked empty slot is consumed, not queued.
- New construction uses the Galaxy's `construction_time`. At exploration completion, active buildings can upgrade even before the last slots are built. A shared work rate is divided among up to `concurrent_upgrade_count` targets; each level cost is a direct table value. Completion requires all configured functional slots built, construction finished and all levels maxed. Initial work/rate values are hand-editable starting values, with no 24h/36h guarantee or calibration test.
- `GalaxyEffectAggregator` owns effect projection. Construction contributes zero; upgrades retain the current-level effect until completion. Galaxy multipliers multiply, automatic resource ratios add. Existing valid-income sampling excludes automated outputs, preventing recursion.
- Only online time advances logic. Hidden pages batch at `hidden_tick`; no wall-clock timestamp, catch-up or offline integration. The entire 3D viewport, shader clock, traffic, pulses, construction and activity stop while hidden or paused. Visual RNG/routes never affect saved logic.
- Galaxy save version 2 stores work, compact explored cells, layout seed, building states/work, shuffle bag and logic RNG. Layout regenerates from seed. Legacy grid saves infer work from explored fraction and migrate the first configured number of known occupied buildings in slot order, dropping obsolete core cells and excess grid slots. Missing Galaxy data initializes normally. Runtime visual state is never saved.

The initial 3D pass supplies a core, colony_ring Lv1–5, a shuttle and five distinct base blockouts. Other families reuse their base GLB across levels until a later art pass; gameplay levels remain independent. Old PNGs are historical assets and are not loaded by Galaxy.
