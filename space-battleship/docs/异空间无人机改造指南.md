# 异空间无人机改造指南

先选无人机，再到“改造”选择操作。先点“预览报价”，确认消耗和结果提示后，再点执行。报价本身不扣材料；切换无人机、操作或完成其他改造后，要重新预览。所有金额以当前报价为准。

一、先分清三个概念
品质决定基础能力与词条／挂设容量；T阶表示词条档次，T1最高、T5最低；无人机等级影响参与等级放大的词条。升级等级不会自动升T阶，传说和究极也不是T阶。蓝色来源传说仍保留蓝色武器模块加成。

二、添加与替换词条
“添加词条”增加一条随机词条，不能超过当前品质上限。“替换未锁词条”随机选一个未锁词条，重新生成类型、T阶和数值。想保留的词条应先锁定，但锁定对象本身也是随机的。
选择指定词条时，报价会计算连续替换直到首次出现该类型的总消耗；可能改到多个未锁词条，不代表指定某个位置，也不保证T阶或最大值。报价太贵可以放弃，不必执行。

三、随机锁定
从全部未锁词条中等概率选择一个并永久锁定。已有锁定不再参与抽取，未来预兆不会帮你定向锁定。锁定数量越多，后续锁定费用越高。当前没有解锁词条的操作；不要把差词条全锁住。

四、升阶一阶
随机选择一个未锁词条，按阶级权重判定成功。成功只升一阶，并在新阶范围内重新随机数值；失败仍消耗本次费用，词条保持原样。T1不能再升。未来预兆不改变升阶目标。T3是成长配装参考，不是系统上限。

五、重随机数值
保留词条类型与T阶，重新随机所有未锁词条的数值；传说效果的随机参数也会参与。锁定词条不变。“保底最大值”会把本次涉及的数值取到各自范围上限，费用可能非常高；先看报价，不要将它理解为免费补满或只洗一条。

六、未来预兆
开启后，仅替换词条时优先替换未锁词条中的最低阶：先T5，再T4，以此类推；同阶随机。它不提高新词条抽取概率，不保证升阶，也不影响锁定和升阶的选取。关闭后恢复普通随机替换。

七、挂设槽与挂设
添加挂设槽不能突破当前容量。挂设需要先解锁，再在无人机详情里配置；同一种挂设不能在同一架重复安装。低品质转为传说会保留已有挂设槽和已安装挂设，因此若需要经济型传说，应先考虑挂设，再传说化。究极状态不能更换挂设。

八、传说化
获得一个传说效果，保留全部现有词条、锁定、已有挂设槽及已安装挂设。保底指定效果必须先发现并加入收藏，且符合武器限制。首次见到的效果不等于已加入收藏。当前不支持再次传说化来重抽效果。当前传说同时最多装备2架；究极独立最多1架。同时具备传说和究极的无人机，会同时占用两种名额。

九、现代化
只提升无人机等级，不改变已有词条类型、T阶或原始随机值。目标取该武器对应异空间路线当前可用的最高已通记录，并受本轮主线最大关卡限制；不是自动跟随主线。
例如主线已通60、开放61，但对应路线最高只通55，则现代化到55。重铸前的历史记录可保留，重铸后要重新推进到相应主线关卡才可使用。没有更高可用记录时不能现代化。
费用由目标等级、基础系数、现有词条阶级和传说倍率计算；基础系数包含1。高阶词条会提高费用。先看预览中的前后等级、属性和材料消耗。

十、究极化与还原
究极是独立状态，可以与传说同时存在。究极化使武器模块等级+5，并增加额外词条，但此后不能直接进行普通改造或更换挂设。想继续现代化，要先还原究极，再现代化，最后按需要重新究极化；每步分别报价和付款。
还原不会重新抽掉原来的究极额外词条：它暂时失效，再次究极化时恢复原词条。等级提升后，参与等级放大的效果随新等级计算。

十一、拆解与保护
拆解会永久移除该无人机，获得对应路线材料；挂设奖励按当前规则结算。已装备、已收藏或被预设引用的无人机会受到保护，需要先解除相应保护才能拆解。拆解前核对名称和返还预览，确认框不会帮你保留原机。重铸清除未保留无人机不算拆解，不发拆解奖励。

十二、常见操作顺序
先选适合当前武器与用途的无人机，补需要的词条／挂设，再决定替换、升阶和锁定；确认长期保留后再考虑昂贵保底、传说化与究极化。现代化前先比较等级收益与材料成本。不要仅为追T3或更高阶牺牲所有成长资源。

失败提示怎么处理
材料不足：回对应路线获得材料，或改选较便宜操作。没有未锁词条：当前可修改目标已用尽。已达上限：检查品质容量。记录不足：先通对应异空间路线。报价失效：重新预览。究极禁止改造：先还原。仓库或保护限制：检查装备、收藏、预设和空位。
