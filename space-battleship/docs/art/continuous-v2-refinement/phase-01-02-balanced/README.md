## 实际修改

使用ImageGen离线局部重绘：抬起船坞蓝灰金属大面的中间调，恢复行星表面和远景雾层；灯点保持小而克制，没有恢复长灯带、密集亮星、白色金属锐边。第一张修改图中央银河仍太醒目，没有接入；第二次局部重绘将其收敛成低频雾层。不是运行时曝光或全图遮罩。

构图和取景意图保持，生成式细节并非逐像素锁定。工具返回747×2104，比原版少2行：原生裁取(87,0)-(659,2104)，仅在最底部复制2行边缘补齐572×2106，不缩放、不纵向拉伸。父可直接核对完整源图；不能将本次结果称为已获用户验收。

出坞位移沿用e060c439：第一关从母图y=1146移动至426，第一关末窗口覆盖426..1386，已越过船坞及出口桅杆；第二关从426至0，以太空为主体。与亮度调整分开核查，不改实际distance、length、时间或战斗状态。
