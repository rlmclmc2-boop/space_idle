## 本次改变

重新绘制灯带、金属、星点和行星边缘：船坞以低对比大块结构居两侧，小灯取消亮条/泛光；中央星点大幅减少，银河细节压低，避免模拟弹体。不是运行时全图黑色遮罩。原有动态星点路径未改。

重绘源实际为747×2106；工具没有按请求输出更长尺寸，因此没有冒称超长高分辨率图。使用原生像素中央裁区(87,0)-(659,2106)，得到572×2106连续画带，无放大、无纵向拉伸、无拼接。两侧裁掉87/88px，保留边缘船坞块面、行星弧和阵列；完整生成源可审。

第一关视口从母图y=1146移动至426，移动720px（0.75个960高视口）；第二关从426至0，移动426px（0.444屏）。第一关末的视口底边1386，在船坞及出口桅杆上方；第二关全段为太空。只改图像空间分配，进度仍读取现有distance/length；不改变实际航行速度、时长、距离或战斗状态。

第一关纹理572×1684，第二关572×1390；共享960可见行和各2px滤波支撑。RGBA8等价7,033,312 bytes（6.71MiB），比上一版增加1,546,688 bytes（1.48MiB）。GPU背景路径没有修改，仍为原quad单采样，关段变化才更新纹理及采样尺寸。

检查结果：400×671和572×960两种实际shader接缝截图均逐像素一致。隔离导入未检出脚本/导入ERROR；两关主界面状态保持检查通过。审稿夹具切换不同高度纹理时补齐了采样Vector3更新，生产路径原本已包含该更新。
