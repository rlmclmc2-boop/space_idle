## 接合修复的实际做法

原失败候选在边界上重复生成了阵列，桅杆轴线/粗细失配，且碎星和雾层纹理骤变。本次重新绘制未接入的新区域，移除重复阵列；既有阵列仍完整留在锁定首段。上端杆件改为独立SVG绘制，其底部15列截面颜色取自旧图切口，轴线沿旧杆方向向左上离开画面，避免再依赖生成器保证硬结构配准。该SVG只属背景，不参与任何舰体几何。

候选内靠近连接处的320px区域，以相邻段背景颜色场作平滑局部匹配；依据边界颗粒对照处理微细纹理。第2→3处由0逐渐过渡到2.5px离线平滑，仅作用新段背景，杆件在其后独立合成，旧段像素不改。其余连接按参考颗粒选择0或0.35px处理。不是全局压暗、均匀蓝雾或拉伸边缘像素藏缝。

新段高光采用离线柔和压缩，低于0.35通道值的暗部/中间调不变，避免月面、碟面与节点灯抢舰体对比。旧首段不参与此处理。所有生成源保留可核；新段均由更大源图向下采样到572×960，没有低清放大。最后把四次相邻延展组合成同一连续母图，再统一切候选纹理。新段共用同一光向、材质语言和地标顺序。
