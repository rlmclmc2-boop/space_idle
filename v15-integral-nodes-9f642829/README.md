# Integral-node orbital ring candidate

Source: `wip/planet-thread-resume-20261101@9f642829db66cffae843d6b2f06de98c14871465`. Blender 4.3.2, Godot 4.7.2.

This is a new structure candidate after rejection of the previous broad continuous foundation. The connection spans are narrow pressure beams, while the four owned facility sections expand into load-bearing nodes. Workshop and shipyard no longer use the universal broad socket platform: their load walls and dock yoke serve as their ring sections. The existing facility IDs, UI, business flow, independent construction, and sphere occlusion remain. Simplified faceted armor remains the visual language.

`stage-1.jpg` through `stage-4.jpg` show independent construction. `page-facilities-open.jpg` is the actual game page. `motion.mp4` is the existing 32-frame idle script at five frames per second; start/mid/end samples are alongside it. Logs show no GDScript parse/runtime errors. Godot's headless ALSA fallback reports `ERR_CANT_OPEN`. This is an author-made structure candidate for shared-host visual evaluation, not user approval.
