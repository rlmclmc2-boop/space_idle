# 自转优先的动态约束

[总入口](README.md)。用户已决定**自转优先**：建筑转到球缘或背面可被遮挡，工作动画不必始终可见，也不提供玩家拖动观察。运输船与管道让设施关系可理解。这里记录静态概念图的运动边界，不修改现有运行规则。

**同载体锁定。** 固态的地表建筑、地基和短管线跟同一地貌经纬转动，左右球缘渐遮、背面隐藏，再从另一侧出现；云层可另速流动，不能拖动地基。气态的云纹和风暴可流动，浮台是有自身姿态的实体，不随每一道云纹位移；若浮台进入背侧仍按实际深度遮挡。普通恒星／红巨星的光球和日珥流动不等于外部采集弧转动；白矮星屏蔽瓣及脉冲星安全弧同样有独立实体轨道，不能直接贴到表面纹理上。

**连接随相位成立。** 同一地表或同一浮台内部的短管、轨道可持续连接并共同运动。地表／云顶到独立轨道站体之间，主要由运输船在交会窗口往返，或由各端自带的短接驳头短暂对接；不画一条始终绷直、跨不同角速度物体的硬管。外侧船坞保持独立服务位，运输船沿可读航路接近。脉冲星运输只走极轴束流以外的安全扇区。

**相位复核。** 后续概念审查至少看正面、左右球缘、背面四相位：底座与管路一起转入／转出，不留空脚；背面建筑虽不可见，已建状态仍可由稳定 UI 入口读到；站体与船坞各自运动时不与地表设施相撞或被错误牵连；运输船不能凭空穿过天体。现有同机位分步图只表达施工前后构图，**不是整圈动画或遮挡验收**。无需为保证同屏四设施而暂停自转、偷换转速或取消真实遮挡。
