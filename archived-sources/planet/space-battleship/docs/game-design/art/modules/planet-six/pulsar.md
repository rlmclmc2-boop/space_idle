# 脉冲星：把极轴束流留空

[总入口](README.md) · [裸态／完整设施态修正版](images/pulsar-concept-b.png) · [初版留档](images/pulsar-concept-a.png)

**裸态。** 紧凑紫蓝核心、两束相反的窄极轴光束和倾斜磁环先建立可辨方向。设施态沿用同一束流角度；束流不是建筑出现后才添加的装饰。

**设施态与承载。** 两段断开的防护弧只占赤道安全扇区，束流走廊彻底留空。偏置的处理节点与工坊挂在一段弧的背束侧，空间站在另一段弧附近的独立巡行点，船坞更远地占一块无束流的服务扇区。小艇在各自安全扇区可见；跨扇区飞行应绕束流，修正版不以二维虚线假装一条穿过极束的安全直路。转接点需有实际受力和屏蔽几何；不能用完整环把束流和动线混在一起。

**作业与动态。** 两束光以同一轴相位扫过，弧上小型闸片按可见相位调整；只有在实际工作／转运时才显示相应动作。裸态由光束建立强方向性，建成后设施利用剩余扇区形成不对称构图。图中磁环亮度和小站数量是概念图偏多处，缩到 808×900 参照区域时应先简化。

束流避让目前只是视觉与空间提案，不附加危险结算、节拍加成、专属产出或新解锁门槛。

初版下极束流处的运输虚线穿过危险走廊；一次改图又把路线移到上极束流，均已排除。修正版撤去跨扇区连续虚线，仅保留两侧小艇与空束流走廊。实际三维绕行路径待运行设计验证，不从这张二维静图推断已解决。
