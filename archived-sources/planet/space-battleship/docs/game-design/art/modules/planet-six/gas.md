# 气态行星：在云顶建立压力层

[总入口](README.md) · [裸态／完整设施态概念图](images/gas-concept-a.png)

**裸态。** 青灰、灰绿和象牙色云带层层卷绕，明暗与风暴眼先建立没有固态地面的身份。设施态维持同机位和云纹方向。

**设施态与承载。** 环状浮台由分离的浮力节点和垂直系索支承在高云层，不能把地表建筑直接贴到气体球上。采集端与高轨处理节点通过受保护的上行管路连接；工坊在环外侧的稳定服务节点，船坞更远离云层，空间站在高轨航道。图中的环形结构是“当前四设施如何被气体世界承载”的造型候选，不代表增设第五种可建建筑。

**作业与动态。** 云带缓慢漂移而浮台保持自身稳定姿态；采集端伸缩、转运器沿外环通行，远端船坞独立服务。施工前是风暴与分层云顶，施工后环与系索框住风暴眼，形成从云层到高轨的运输方向。需审查环后半与云顶遮挡，避免像贴在球上的刚性地表圈。

现行规则没有气态专属采集、压力或燃料产出。若要这些功能，属待定玩法提案；本图仅规定可讨论的视觉语言。

## 分步对照

下列同机位图示一条可行领取路径。气态没有固态地面，浮台与系索必须由当步设施自带。

| 步骤 | 图 | 当前已建结构 |
|---|---|---|
| 0 裸态 | [完整概念图左侧](images/gas-concept-a.png) | 云带与风暴，没有预铺环 |
| 1 空间站 | [01](stages/gas/01-station.png) | 上方独立轨道站及自带泊口 |
| 2 精炼厂 | [02](stages/gas/02-refinery.png) | 自带双浮力节点、短吸入口与处理台；与空间站用运输船联系 |
| 3 工坊 | [03](stages/gas/03-workshop.png) | 相邻但各自支撑的浮台工坊；仅此时出现两座已建浮台间的短桥 |
| 4 船坞 | [完整概念图右侧](images/gas-concept-a.png) | 高轨外侧独立船坞及服务位 |

气态云纹流动与浮台姿态分层；浮台可随自身运动进入背侧遮挡，空间站和船坞独立绕行。阶段图不保证云纹逐像素相同，也不代表所有浮台必须串成完整刚环；[自转约束](rotation.md)优先于静态正面关系。
