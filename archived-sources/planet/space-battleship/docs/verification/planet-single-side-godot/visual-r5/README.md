# 星球 R5：设施简化设计稿与整屏尺度配合（待用户确认）

用户已认可当前六星球贴图；本轮保留原贴图、球面 shader 与业务。用户退回 [R4 四座建筑稿](../visual-r4/README.md)：高细节重工业写实风格不适合当前游戏，而且在游戏小尺寸下无法体现细节优势。本页改用当前正式战舰的大轮廓、大奶油/深蓝色块、少数青色发光件，提供**四张独立设计稿**及**四张逐项整屏配合图**，另有一张四设施同屏概念图。全部为 imagegen 原图，尚未建模、接入 Godot 或获得用户确认。

直接对照的当前正式舰图为 [护卫舰](../../../../assets/ships/fleet_20261019/player/01-frigate.png)与 [战列舰](../../../../assets/ships/fleet_20261019/player/04-battleship.png)；整屏母图为 [R3 官方 4.7.2 实机 1440×900](../visual-r3/evidence/final-01-default-planet1.png)。[完整提示词及源图对应](prompts.md)与 [字节散列](SHA256SUMS)已存档。设计遵守 [唯一入口](../../../game-design/README.md)与 13/M7 的观看主导、建筑纯观看、操作留稳定侧区的方向，不自行改共享宿主。

[四设施同屏概念配合图](fit/all-four.png)用于比较色块、轮廓与左右场景关系。五张 `fit` 图均以真实 1440×900 实机截屏作 imagegen 编辑参考，输出原图为 **1586×992**，保持约 1.60:1 整屏比例，等比例放回 1440px 宽时，设施目标约 80–120px。它们是**概念合成**：生成器可能重绘少量 UI 字形、星云、表面细节和边缘；不能称作 Godot 运行截图、精确像素叠层、六星球设施效果或轨道净空证明。原始实机截图单独链接在上方，当前真正运行的仍是 R3 设施 GLB。四张逐项配合图只替换目标设施，其余保持旧视觉供比较；同屏图才同时展示四张新稿。

设计取舍：去掉 R4 的铜管、真实金属粗糙度和大量细碎结构；留一个强主形、一个辅助功能形及最多几处工作灯。当前战舰并非纯白模，奶油装甲与深蓝空隙、清楚黑色描边一起构成风格，因此建筑也不能只换成白色块。图稿主视较大，辅助视角非工程正交图；建模时必须在游戏实际小尺寸复核轮廓、地表切线和遮挡。

用户尚需逐稿确认风格、四座设施功能轮廓及工坊/船坞位置。旧空间站轨道与船坞屏幕包围盒在 R3 361 帧中有 37 帧相交；本轮静态概念图不能关闭这个问题。确定放置后，须对新模型做实际连续轨道/净空采样。星球画面偏左和背景空旷也仍是待解的整屏构图问题，本轮没有借建筑稿冒称修好。
