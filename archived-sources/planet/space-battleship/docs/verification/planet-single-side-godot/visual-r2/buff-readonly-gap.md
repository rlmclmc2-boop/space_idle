# 累计征服 Buff 的最小只读缺口（未实施）

当前已审 `facility_facts` 只提供单设施状态/来源因子，`visual_snapshot` 没有当前星球 conquered 或累计征服奖励摘要。`prepare_reforge` 是既有预览准入，不能替代累计 Buff 读数；UI 也不能为了显示调用会更新贡献缓存的 `contributions()`。

建议由 Planet 所有者评审一个最小只读输出：当前星球已接纳的征服标记，以及现有已接纳累计征服贡献的奖励摘要（效果身份/目标和显示值，区分装备有效等级、强化额外等级、免费充能及幸运等既有项）。只复用现有 Buff 求值或已发布贡献，不另建奖励账本、不开放配置/私有缓存、不改叠加规则。具体字段与失效边界由接口所有者收口，不在本轮前端自行实施。

在该输出审定并交付前，累计 Buff 详情保持未完成，不以来源因子或重铸按钮冒充 M7 完整交付。
