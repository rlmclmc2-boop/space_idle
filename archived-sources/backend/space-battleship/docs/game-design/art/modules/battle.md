### M1 导航、航行、战斗与资源

**场景/布局/控件：** 以敌我舰交火及已有场景背景组织战场，让待命、航行、战斗中的环境连续可见，保留当前背景资产与采样修复。HUD 紧凑地提供即时判断所需的盾甲余量/危险状态、关键战况及暂停/驻守状态；不以大防御面板、空框或常驻说明占据观看区。当前值/上限、资源明细、完整统计及策略设置按需查看，不能靠缩小文字或隐去必要盾甲信息换取空间。出航与驻守控制可达；导航只按[全局2.2](../../13-art-interaction.md#22-全局信息层级与适配)，具体布局服从下列空间预算。

**舰体层级与空间设计准则：**

| 类别 | 准则 |
|---|---|
| 设计目标 | 巡洋舰、战列舰、重型战列舰在正常战斗视图中具有可辨的体量层级。保留已确认模型与美术，通过相对尺度和布局适配实现，不靠持续放大高档舰拉开差距。 |
| 空间约束 | 先划定我舰最大完整占用、敌方编队、交火通道、无人机及未来扩展留白，再分配舰体尺度。普通敌舰占 1 格、精英占 2×2、首领居中占 3×2；占位包含舰体、转动炮台、护盾外缘、顶部盾甲条及间距，不拉伸舰图填格。完整包络取全部合法炮台朝向的扫掠范围与舰体、护盾的并集，并单列盾甲条范围；不得挤占相邻占位、画面边界或 HUD/导航遮罩。 |
| 当前参数事实 | 五舰基准高、全局/分舰倍率、逻辑尺寸及敌方适配框见[舰船尺寸参考](../../reference/ship-scale.md)。这些是实现快照，不是本轮新批准尺寸；源图画布、UI 预览和舰体 alpha 框均不能代替完整装配包络。尺寸适配须继续使用共享几何和真实挂点/炮口，不另设命中尺寸。 |
| 待定参数 | 最大占用宽高、净空与留白预算、五档相对尺度及具体倍率尚未定。预算确定后，用同一逻辑单位和展示比例对比五舰，重点检查后三档；候选列宽高、统一 alpha 口径的可见面积、完整包络和剩余净空，并注明与当前值的差异。不得以外接框/透明画布面积冒充可见面积，也不能将当前尺寸或候选值默认为批准值。 |
| 验收标准 | 在预算内同时证明高级舰体量可辨与最大完整占用受控。覆盖各档我舰合法装配、敌方各阶及最密合法编队，记录最小净空及对应舰型/装配/朝向/编队；舰体、炮台、护盾和盾甲条完整可见，无相邻、敌我、顶边或 UI 重叠/裁切，交火、无人机及扩展空间保留。静态复算或已有背景/炮口专项不能替代这些画面证据；通过后另行批准参数实施。 |

**状态/反馈：** 保留空格暂停、G 驻守及点击掉落的操作能力，首次需要时给出相应短教学，之后在手册或按需说明中可查，不常驻占位；临时反馈结束后归还画面空间。输入框/弹层中不误触全局操作。敌我炮口、转向、光束连接与实际目标一致，环境随待命、航行、战斗状态衔接，背景随航程连续移动而不灰蓝跳变，不因停下或交战而丢失已有场景。护盾为零但装甲仍存、装甲为零但护盾仍存都仍显示存活，不能把一条空条表现为死亡。拾取用同一资源身份显示来源、数量与入账反馈，定时物数量按生成时确定，不能因领取时倍率变化跳数。教程覆盖时说明继续动作，暂停与恢复遵守 [01](../../01-runtime.md)。

**可见验收 V1：** **画面核对：** 交火和环境为主体，HUD 紧凑，盾甲/战况清楚，无大信息块、空框或常驻快捷教学；舰体层级、占位与净空按 [M1](battle.md) 表记录。**操作核对：** 首次需要时教学暂停/驻守/拾取，退出后可主动回看；实际走待命→航行→战斗及撤退/再航行，背景连续且无整片闪变，炮台/活光束跟随真实目标；切换/收起面板后暂停/驻守及按需详情一致，拾取提示与入账一致。完整品质和已专项通过项按 11 区分。来源 S1/S2/S3。
