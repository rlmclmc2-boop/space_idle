## 模块复用

设备舱步长 220；左侧分配行步长 110。两侧按模块序号同步滚动，视窗均容纳三行。新增模块复用通用舱、分配行、控件绑定及主管；只选择设备纹理与专属局部动效。

设备舱局部坐标：外框 (64,4,628,204)，设备视窗 (80,15,223,180)，名称 (369,24)，增益 (324,83)，清零 (561,25)，能源文字 (327,144)，分段条 (500,151,159,20)。设备及动效裁切在设备视窗内。module-coupling.svg 固定穿舱接头位于舱内 x=56..83、y=71..117；支管轴线 y=94，从 x=17 延伸至 x=130，并压在设备机体下。底部支管在页内 (733,1136) 终止于金属盲板，不伸入加号。扩展区域只显示“待扩展”。

左侧分配行：图标 (14,28,42,42)，名称 (76,6)，占比 (403,6)，滑杆 (124,43,360,20)，输入命中区 (124,34,360,34)，能源 (124,72)，增益 (332,72)，减/加按钮 x=78/495、y=39。全部数值读取原有业务状态；加减使用原有配置步长。

静态资产和动态层分离。刷新只写变化属性；隐藏、暂停和离开视窗的模块停止动效。页面根节点不参与逐帧重绘。功能或运行验收须遵守用户当次授权。
