# Orbital artwork

Current facility models and matching card icons: [models/README.md](models/README.md). Godot owns orbital motion, depth ordering and independent body spin; authoritative building ownership is unchanged.

The original facility PNGs below are retained as concept sources. They were generated with built-in ImageGen, 2026-09-29, using navy/ivory construction, cyan lamps and upper-left lighting. Their prompts remain here for provenance.

`scout-v1.png` remains active: transparent top-down, bow-up artwork, displayed at 24x48 logical pixels and rotated along the flight tangent. Import with mipmaps and alpha-border fixing.
